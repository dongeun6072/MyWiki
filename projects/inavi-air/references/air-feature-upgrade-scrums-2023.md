# 에어 기능 고도화 스크럼 #1~#5 (2023-05~06)

2023년 5~6월에 열린 에어팀 주제별 스크럼 "기능 고도화" 5회분을 회차별로 옮긴 문서다. 모든 회차가 10:30~12:00 회의이고 같은 템플릿(Agenda / Done & Doing / ToDo / Issues & Request)을 쓴다. #1~#3은 날짜가 비어 있고 #4는 2023-06-20, #5는 2023-06-28이다. 이어지는 후속 스크럼은 [[air-ai-crosswalk-scrums-2023]]이고 전체 목차는 [[air-scrum-records-hub]]다. 요약본은 [[air-confluence-scrum-and-voice-2023-2024]], 에어캐시 설계는 [[air-cash-reward-design-2023-2024]]를 본다.

## 공통 사항 (전 회차 반복)

- 회의 시각 10:30~12:00. 참석: #1~#3 각 13명 수준의 멘션 목록(#1 참석 13명, #2 참석 12명, #3 참석 12명), #4/#5는 멘션 없음. ^[inferred]
- 영역 구분: 기획 / 디자인 / Agent(서버) / App / PM / ALL(#1~#3) 또는 기타(ToDo 영역).
- **Issues & Request에서 #1부터 #5까지 계속 남아 있는 항목**
  - 기획: 음성광고 단가 및 하루 최대광고수 정리 (#1 최초, #5까지 미해결)
  - Agent: 멜로펀치 광고 음성 적용, Tag 별 음성 광고 결정 (#1 최초, #5까지 미해결)
  - PM(#2부터): WBS work days가 최대 3d가 되도록 항목 정리 (#2 최초, #5까지 유지; #1에는 없음)
  - PM(#2부터): Jira 이슈 진행 프로세스 — 진행 중으로 변경 시 시작/완료/최초 추정치를 기입한 후 상태를 변경하고, 해결됨 처리 시에는 실제 기간을 명시
- **ToDo에서 #1~#5까지 계속 남아 있는 항목**: 기획 "스토어 문구 작성", 디자인 "스토어 이미지 현행화", PM "TC 작성" (#5에서도 미완료).
