# 에어 서버 데이터 상관관계 분석 2024-09

[[air-server-data-analysis-2023-11-2024-11]] 페이지의 "상관관계" 절을 분리한 문서다. 2024-09-01~30 한 달 일별 데이터를 ChatGPT에 질문해 얻은 결과로, 활성사용자 증가 가설([[air-hypothesis-phase1-phase2]])의 근거로 쓰였다. 맥락은 [[air-growth-strategy-and-metrics-2024]]와 [[air-data-analysis-2023-10-2024-09]]를 본다.

## 결론 (질문별)
| 질문 | 결과 | 피어슨 r (p-값) | 예상 효과 |
|---|---|---|---|
| 로그인 사용자가 늘면 DAU가 늘까? | 9월 한 달 데이터로는 상관관계 확인 불가 | - | - |
| 주행 DAU가 늘면 DAU가 늘까? | Yes (강한 양의 상관) | 약 0.753 (0.00000158) | 주행 DAU +10% 시 활성 사용자 약 +6.49% |
| 로그인 사용자의 주행 DAU가 늘면 캐시 적립자수가 늘까? | Yes | 약 0.832 (0.0000000117) | 주행 DAU +10% 시 적립자수 약 +10.69% |
| 캐시 적립자수가 늘면 DAU가 늘까? | Yes ("상당히 높은" 상관) | 약 0.669 (0.000052) | 적립자수 +10% 시 DAU 약 +4.49% |
| 캐시 적립자수 +10% 시 캐시 적립 금액은? | - | - | 약 +9.96%(약 36만 원/월). 8%가 쿠폰을 구매한다고 가정하면 실제 쿠폰 비용 추가 지급은 월 3만 원 수준 |
| 캐시 적립자수가 늘면 광고 매출이 늘까? | Yes | 약 0.650 (0.0001) | 적립자수 +10% 시 광고 매출 약 +6.56% |
| DAU가 늘면 광고 매출이 늘까? | Yes | 약 0.747 (0.000002) | DAU +10% 시 광고 매출 약 +11.24% |

모든 p-값이 매우 낮아 통계적으로 유의하다고 서술. 원문에 "주행 DAU와 DAU의 r=0.753" 등 ChatGPT 답변 문장이 그대로 붙어 있고, 상관관계를 인과로 해석한 예상 효과라는 점은 원문이 구분하지 않는다 ^[inferred].
