## 내가 한 작업 (커밋)

- **seoul-donghaeng**: GUI 시안 대조 반영(☆ 제목 행 이동, 조회 실패 문구, 경로 막대·도착 시간 색, 07-1 대화 카드, 하차 정류장 시트 낭독, 택시·예약 내역·시간표 정합)으로 릴리즈 브랜치 PR #43을 병합했다. 이어 규격 1.0.48의 `ROUTE_NOT_FOUND` 오류 매핑을 추가하고 `ResponseCode` 개수 테스트를 20→21로 고쳤다. 저녁에는 개발자 옵션 실내지도 테스트(판교역 도면 1F·B2·B3), 실내 내비 화면, Papaya Fusion SDK 측위·길안내(mtech-demo 실내 앱 이식), core/map 도형(Polygon·Line) API를 Appsource에 적용했다.
- **mtech-demo-delivery**: 권한 요청 이력으로 막힘 여부를 판정하도록 core를 고쳤다.

## 채널 논의

- **컨소시엄 협업**: LBS테크가 앱 시연 수준(실외 보행+대중교통인지, 실내 포함인지) 확인을 요청했다. 메인앱과 SDK 통합 시간이 필요해 1차·2차 전달일을 하루씩 당기는 것으로 정리했다(1차 10/29, 2차 11/12 요청). 디자인 시스템과 디자인 가이드 문서를 전달했고, 브로디언이 개발용 ODSay API 키를 요청했다. 지원 가능 항목 표를 받았고 백엔드는 1차 명세서, 2차 API 순으로 전달받기로 했다. 자세한 내용은 [[seoul-donghaengmap-consortium-slack-2026]].
- **서울동행맵 고도화**: 보안·인증서 관련 서울시 회신 정리(UUID 4개 등록, 인증서는 서울시 계정으로 매년 5월께 발급), 실내 측위 협력 건 NDA 체결 공유.
- **서울동행맵 dev**: 판교역 실내 내비 테스트 결과 공유(개찰구 통과 길안내, 층 전환 지연 등). [[seoul-donghaengmap-papaya-slack-2026]]
- **에어**: 에어 규격서를 모두 Confluence로 이관했다는 공지. [[air-channel-slack-2026]]
- **모빌리티개발셀**: Confluence·Jira 라이선스 조정(개발 부문은 Confluence만 대상), Notion 유료 구독이 10-28까지 유지된다는 공지, 클로드 표준 시트 추가 할당.
