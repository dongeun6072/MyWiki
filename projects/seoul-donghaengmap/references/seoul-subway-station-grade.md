# 서울 지하철역 실내내비 난이도 등급체계

실내 내비게이션 데이터 구축은 **현장 작업 난이도가 역마다 크게 달라** 작은 단독역과 거대 환승역을 같은 비용·일정으로 다룰 수 없다. 그래서 310개 역을 난이도로 나누고 등급별 표준 단가의 토대로 쓴다. 정의서는 2026-06-24 작성, 06-25 개정(면적 절대기준과 5등급)이다. 착수보고에서 서울시가 "10개 역 시범 후 확대" 범위를 1단계 평가 뒤에 정하겠다고 한 것([[seoul-donghaengmap-negotiation-kickoff]])의 근거 자료다. 프로젝트는 [[seoul-donghaengmap]]이다.

## 등급 체계: 두 단계

1. **1단계 — 복합역사 분리**: 백화점·터미널·공항과 일체화돼 경계를 긋기 어려운 **특(복합역사) 10역**은 따로 분류해 역별로 단가를 산정한다.
2. **2단계 — 일반역 300개**: 면적 + 환승 + 지하상가 점수 합으로 A~E 5등급

| 등급 | 의미 | 역 수 |
|---|---|---|
| 특 | 복합역사 별도 분류 | 10 |
| A | 큰 면적 + 다환승 + 대형 상가 | 17 |
| B | 두세 인자가 높음 | 29 |
| C | 한두 인자가 중간 이상 | 45 |
| D | 한 인자만 최소 초과 | 110 |
| E | 작은 단독역 | 95 |

(합계 306. 면적 미산정 4역(반포, 불암산, 장암, 지축)이 등급표에서 빠진다.)

특 10역: 서울, 영등포, 왕십리, 고속터미널, 수서, 김포공항, 용산, 신도림, 청량리, 잠실. A급 예: 공덕, 디지털미디어시티, 동대문역사문화공원, 강남, 종로3가, 홍대입구, 시청, 사당.

## 점수 변수

| 변수 | 정의 | 점수 |
|---|---|---|
| 면적 | 역사 + 연결 지하상가 연면적(전 노선 합산) | 만㎡ 절대 기준: <1=1, 1~2=2, 2~3=3, 3~4=4, ≥4=5 |
| 환승 | 갈아탈 수 있는 노선 수(KTX·SRT 제외) | 단독 1 ~ 5개 이상 5 |
| 지하상가 | 연결된 지하상가 규모·활성도 | 없음 1, 소규모 직결 3, 대형 직결 5 |

개정 이유: 처음의 역 개수 균등 5분위는 상위 압축과 경계 절벽 문제가 있어 만㎡ 절대 기준으로 바꿨다. 점수가 하위에 쏠리는 것은 왜곡이 아니라 난이도의 사실이라고 설명한다. 출처는 서울교통공사 역사면적정보, 환승유입순위(공공데이터포털), 서울시설공단 지하도상가 목록(25개).

## 등급별 구축 단가 (실내내비 기준, 1개 역)

| 등급 | 작업일 | 비용 |
|---|---|---|
| 특 | 101일 | 약 1.07억 원 |
| A | 56일 | 약 5,924만 원 |
| B | 28일 | 약 2,962만 원 |
| C | 22일 | 약 2,370만 원 |
| D | 11일 | 약 1,185만 원 |
| E | 6.7일 | 약 711만 원 |

작업일당 비용은 105.6만 원(인건비 40만 원 + 사업비 65.6만 원)으로 계산한다. 구성은 실내지도 DB 제작, 현장조사, 현장조사 DB 반영, 실내지도 서비스, 실내 측위 DB·기술, 실내내비 서비스다. 306개 역 전체를 하면 약 59.8억 원(5,660 작업일), 단계 1(실내지도 DB 제작만)은 약 10.7억 원이다.

## 시범 10개 역 선정 안 (협의안)

| 안 | 구성 | 총비용 |
|---|---|---|
| 안1 | 8개 선정기준 + 역사 등급 고려 → 10개 역(예비 포함 12) | 약 4.32억 원 |
| 안2 | 제안서 안(안1 + 장애단체 의견): 특 4(서울역, 고속터미널, 신도림, 잠실), A 3(강남, 홍대입구, 사당), B 2(합정, 교대), C 1(건대입구) | 약 6.87억 원 |
| 안3 | 안1·2 + **연속 위치**(잠실, 강남, 종합운동장, 사당, 남부터미널, 선릉, 석촌, 교대, 삼성, 역삼, 서초, 방배) | 약 4.22억 원 |
| 안4 | 안3 + 서울시 제공 참조자료 기준 실내지도 DB 제작(현장조사 제외, 서비스 미적용). 26·27년 단계별 확대 | |

안3은 강남을 중심으로 **한 노선을 따라 이어지는 역**을 고른 것으로 보이며, 연속 이동 시 실내외 전환(seamless)을 검증하기 좋다. ^[inferred] ([[seoul-donghaengmap-screen-design]])
