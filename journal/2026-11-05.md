LBS테크 API 담당은 백엔드 멀티모달 개발은 LBS테크 담당이 맞고 쟁점은 지하철 안내를 SDK에서 할지 메인 앱에서 할지이며, SDK에 지하철까지 넣으면 SDK 도보 → 실내 내비 → SDK 지하철 → SDK 도보로 화면이 오가 오히려 부자연스러워 SDK는 도보(와 버스)만 맡는 게 맞다는 의견을 냈다. PM은 과업 범위를 확인하겠다고 했다.
