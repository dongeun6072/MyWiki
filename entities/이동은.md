# 이동은

㈜아이나비시스템즈 모빌리티개발셀(2023년에는 모빌리티Tech그룹, 2026년에는 MX그룹 소속 표기)의 Android 개발자이자 이 vault의 작성자다. 2026년 기준 직급은 주임(연구원 → 주임 연구원)이다. 생년이나 입사일 같은 인적사항은 이 페이지에 적지 않았다.

## 역할

Android/KMP 개발자. 아이나비 에어 앱 정기 업데이트를 4년째 맡고 있고, 2025년부터는 해외향 Navi/Maps SDK를 KMP 기반으로 설계·개발·배포한다. 2026-06부터 서울 동행맵 앱을 CMP로 개발한다.

## 경력 타임라인

| 시기 | 프로젝트 | 역할 |
|---|---|---|
| 2022-03 ~ 04 | 온보딩 프로그램 | GPX 산책 코스 앱 |
| 2022-04 ~ 2023-01 | iNavi 3D Streaming | AOS 외부포팅(MXI, 아트뷰) 유지보수, 주요 오류 해결로 서비스 안정성 개선 → [[inavi-hybrid-navi]]. 2022년 메일 기록: 서울시설공단 현장 방문(6월 7일), MXI 앱 발행 정보 전달과 OTA 가오픈 테스트, 로그 분석(GPS null NPE 원인 확인) → [[mxi-field-incidents-2022]], [[mxi-where-release-ota-2022]] |
| 2022-09 ~ 현재 | 아이나비 에어 | 앱 유지보수, UI/UX 리뉴얼, 신규 서비스(AI 안전통합 횡단보도, HUD 등) → [[inavi-air]], [[inavi-air-feature-history]] |
| 2024-01 ~ 2024-07 | TomTom(TSD-A-01) | NaviService와 ISAService 개발 작업, 전반적인 테스트와 검수. 관련으로 보이는 단말 설정 메모: [[st1-device-network-activation]] ^[inferred] |
| 2025-01 ~ 2025-10 | 해외향 Navi SDK | WBS 수립, 핵심 기능 구현, 대만 실주행 테스트, 전시회 대응, KMP 전환 → [[orbis-sdk]] |
| 2025-12 ~ 2026-03 | 해외향 Maps SDK | MapLibre 기반 지도 SDK 출시 |
| 2026-03 ~ 07 | 삼성생명 POC → 드로잉런 SDK | KMP Android/iOS 동시 배포 → [[drawing-run-sdk]] |
| 2026-04 ~ 05 | Flutter Plugin | 스펙·ADR 선작성 후 Navi/Map Flutter Plugin 배포 |
| 2026-06 ~ 진행 중 | 서울 동행맵 앱 | CMP 단일 코드베이스, 접근성 요구 대응 |

2025년 정기승진 추천서(승진 추천 직급: 주임 연구원)에는 위 중 2022~2024년 프로젝트가 대표 실적으로 적혀 있다. 등급과 직책자 의견 칸은 비어 있다.

## 기술 역량 (2026-09 자체 평가)

- Kotlin/Java [상], KMP·CMP 아키텍처 이해와 적용 [상], Android Studio와 Git/GitHub [상]
- 지도/내비게이션 SDK 도메인 [중], Jira/Confluence/Slack과 Figma [중]
- AI Tool 활용 3~4단계 → [[ai-doc-first-development]]
- 보완 과제: CMP 애플리케이션 경험 → [[kmp-cmp-adoption]]

## 2022년 업무 메일

입사 첫해(2022-03~12)의 받은편지함은 [[inavi-2022-mail-overview]]에 정리했다. 온보딩 프로그램(GPX 산책 코스 앱, [[inavi-2022-new-services]]), 하이브리드 내비·MXI 장애 대응, 에어 스크럼과 신호등 연동([[daegu-traffic-light-protocol]])이 이 시기 업무다.

2023년 업무 메일은 [[inavi-2023-mail-overview]]에 정리했다. 이 해에는 HUD 연동(Bluetooth) 적용, 대구 신호등·AI 횡단보도 확인(교차로 정보가 GUI에 표출되는지 점검), Android Auto 로그 확인 요청을 받았다. ([[air-hud-integration-2023]], [[air-daegu-crosswalk-signal-2023]])
