# 에어 AOS 작업 이력 2022

본인이 작성한 iNavi AIR Android 앱(Bitbucket `inaviair_aos`) 커밋 236건(2022-07 ~ 2022-12)을 주제별로 묶은 이력이다. 주요 주제: 에어캐시 화면 개편, 신호등 안내, 음성 광고, 경로설정·전체경로 화면. 전체 허브는 [[air-aos-commit-history]], 서비스 개요는 [[inavi-air]], 기능 연표는 [[inavi-air-feature-history]]를 본다.

> [!warning] 커밋 메시지 기준, diff 미검증
> 이 페이지는 커밋 메시지만 근거로 한 요약이다. 메시지와 실제 변경이 다를 수 있다. 주제 분류는 메시지 키워드와 Jira 키로 한 1차 분류라 경계 사례가 있고 ^[inferred], 메시지가 모호한 커밋은 별도 섹션에 모았다 ^[ambiguous]. 각 항목의 해시로 `git show <해시>`를 실행해 확인한다. 동기와 효과는 메시지에 있는 것만 적었다.


## 기간 개요

2022년 날짜 행은 총 236건이며 기간은 2022-07-07~2022-12-28이다. 월별 건수는 2022-07 5건 → 2022-08 27건 → 2022-09 26건 → 2022-10 43건 → 2022-11 40건 → 2022-12 95건로, 7월 이후 8~9월은 비슷한 수준이다가 10월부터 늘고 12월에 가장 많다. 커밋 메시지상 8~9월은 에어캐시 화면 관련, 9월 말~10월은 신호등 안내(AIR-633), 11월은 음성 광고(AIR-694), 11월 말~12월은 경로설정·전체경로 화면(AIR-567 및 후속) 관련 작업이 중심으로 보인다. 12월 건수는 95건으로 전체의 약 40%이다.

## 1. 에어캐시 화면 UI 개편·Lottie 적용

- 기간: 2022-08~2022-09
- 건수: 37건
- Jira 키: AIR-590, AIR-591, AIR-598, AIR-603, AIR-613

커밋 메시지상 에어캐시 메인 화면의 상단·중간·하단 UI 변경, 주행이력 이미지·위치 변경, 프로그레스바의 Lottie 전환, 코인 적립 애니메이션 관련 작업이 대부분을 차지한다. 원형 프로그레스바 라이브러리 제거(저작권 정보 제거 언급), 코인 적립 최댓값 하드코딩 제거, 오퍼월 미지원 시 버튼 클릭 방지 등 동작 관련 작업도 일부 있다. AIR-590(금액 표시·위치), AIR-598(문구·마진), AIR-591, AIR-603, AIR-613(그래프 표출값) 키가 보인다. 키의 의미는 메시지 외에는 알 수 없다.

## 6. 음성 광고·온에어 (AIR-694)

- 기간: 2022-11~2022-11
- 건수: 31건
- Jira 키: AIR-694

31건 중 30건이 AIR-694 키이고 1건은 키 없는 음성 광고 관련 메시지다. 음성 광고용 MediaPlayer·Manager, 온에어 ON/OFF·음성 파일 조회·수신 시작/완료 I/F, 온에어 버튼 UI, 오디오 progressbar 구현, 표출 조건(안전운전·안내 시작 2초 후, 30km 이상, 15분 간격, 속도 0 5초 이상 등) 관련 작업이 메시지에 나온다. iOS와 동일한 사양을 위해 Manager 구조를 변경했다는 메시지가 있다. 키 없는 건(7e3b28fc2)은 속도 0일 때마다 광고음성 발성하는 이슈 해결로 적혀 있다.
