# 에어 지도 데이터와 안전운행 안내 변화 (2023)

지도 데이터 팀(모빌리티Map, GIS, 지도기술개발)과 앱 팀이 주고받은 2023년 메일에서 **데이터 형식이 앱에 영향을 준 사례**만 추렸다. 에어 앱은 [[inavi-air]], 지도 포맷은 [[inavi-mr-format-spec]], 월별 지도·탐색 엔진 갱신은 [[inavi-2023-mail-overview]]에 있다.

## 후면 번호판 단속(후면 무인 교통 단속) 신규 카메라 타입

| 항목 | 내용 |
|---|---|
| 배경 | 2023년 도입된 **후면 번호판 단속**. 자사 서비스 검토 요청(05-03) |
| 신규 종별 코드 | `016` 후면고정식 과속단속, `017` 후면고정식 신호과속단속. 조사 툴 입력은 안전운행(F1)의 후면과속(8), 후면신호과속(9) |
| 산출물 | 데이터 `newguidepoint.mdc`, 음성 파일, 음성 인덱스 |
| 도구 일정 | 원도 가공 툴(Mario) 테스트 배포 5/10, 원도 취득 툴(Romeo)/편집 툴(Juliet) 5/12, 정식 배포 5/19 이후. 버전 분기 대상(3DS 4.0, Hybrid, Air, 쌍용)은 아직 미구현이던 시점 |
| 음성 | 신규 인덱스 **343**("후면 번호판 과속 단속에 주의하세요"), **344**("후면 번호판 과속 신호 단속에 주의하세요"). 성우가 두 명이라 한 성우의 음성으로 통일해 `svoiceguide.dat` 구성. 음성 시나리오는 CX셀(기존 단속 안내에 후면 단어 추가)과 지도팀(후면 단어만 추가) 의견이 갈렸다 |
| 에어 | 9월 패치에 후면카메라 안내 기능 추가. 10월 1차 안전운행 데이터에 **후면 단속 종별 110건** 추가 발행. **에어만 후면 종별을 입력하고 나머지 단말군은 같은 위치에 일반 카메라**를 넣는다. 에어에서 후면 안내가 나오지 않는 문제가 보고됐고, "안내엔진과 정리된 DB만 맞으면 앱 패치 없이 DB 교체로 동작해야 한다"고 정리 |

## 통행료 할인 요금 테이블

- **부산 연속통행할인제**(01-18): 할인 코스(벡스코역 > 광안대교 > 부산항대교 > 천마터널 > 을숙도대교 등)와 미할인 코스(역방향)를 로그로 시험. 할인되는 로그를 먼저 받고, 같은 지점의 로그를 복사해 **한 지점에 오래 정차**하는 로그를 만들어 미할인 케이스를 생성하자는 방법이 제안됐다. MR의 연속통행 테이블([[inavi-mr-format-spec]] `ctstolltable.bin`)과 연결된다. ^[inferred]
- **마창대교 출퇴근 통행료 할인**(07-10): 1종 통과 결과 기준으로 7월 지도 요금 테이블 적용. 에어와 Hybrid(통신형)에 반영, PND는 패치 일정 없음, KG모빌리티 일정 검토, 에어는 **8월 패치 목표**. 탐색 엔진에는 **MR 데이터 포맷의 할인율 자릿수를 7~8자리로 늘릴 수 있는지** 검토 요청

## MR 포맷 v5.1: 도로급수 필드

2023-10-20, 경로기술개발팀이 MR 포맷 v5.1을 공유했다. 문서에는 **도로급수**가 있지만 MR 컨버터가 해당 데이터를 채우지 않고 탐색엔진도 쓰지 않아서, 각 엔진이 쓰지 않으면 **rank1, rank2 테이블에서 필드를 제거**하려 한다는 내용이다(`mrrank0/1/2.bin`). 메인 앱이 MR을 직접 읽지는 않을 것이라는 판단이 붙었지만 영향도 확인을 요청했다. 이력을 아는 사람이 팀에 없어 확인이 어렵다고도 적혀 있다. ([[inavi-mr-smr-network-data]])

## 행정구역 명칭 변경

| 변경 | 에어 영향 |
|---|---|
| 강원도 → 강원특별자치도 (2023-05) | 앱은 세종시(36) 예외 처리만 있고 나머지 AdminCode는 서버 값을 쓴다. 안내 엔진은 쓰지 않는 소스에서만 사용. **서버 작업만 하면 된다.** |
| 전라북도 → 전북특별자치도 (2023-12) | iOS/Android 모두 특이사항 없음. 이전 특별시 추가 때 텍스트 표출 사양을 통일해 둔 덕분 |

## 도로명 검색 1,000건 제한 버그 (03-23)

충북 충주시의 도로명 목록이 실제보다 적게 나온다는 택시 기사 VOC에서 확인됐다. 검색엔진 요청 개수 파라미터 `reqcount`에 0(최대)을 주면 **전 API 공통 1,000개**로 제한되는데, 해당 지역 도로명은 1,665건이라 **665건이 누락**됐다. 해당 API의 최대 요청 개수를 10,000으로 올려 반영하고, 전체 API의 적정 최대값은 이후 정리하기로 했다. 에어와 Hybrid 공통 이슈였고 쌍용 단말에서는 정상이었다. ([[mxi-taxi-version-2023]])

## 기타 데이터 이슈

- **항공지도 축소 시 Android만 표출 실패**(07-11): iOS는 정상. 상용과 개발 서버 모두에서 재현
- **경로 내 주유소 유가 핀 미표출**(10-26): 유가 데이터는 정상 유입, 표출 문제인지 앱 확인 요청
- **교통 통제 우회 안내 불가**(07-17): iOS에서 탐색 요청의 `forced`(도로상 통행 제한지점 강제 통과)가 기본값 `true`로 전달되고 있었다. 과거 "목적지 통제 팝업"이 사양에서 빠지면서 팝업이 정하던 값이 기본 `true`로 남은 것. `false`로 수정 (Neon 프로토콜의 부가정보1 비트 "도로상 통행 제한지점 강제통과"에 해당. [[inavi-routing-neon-protocol]])
- **도로위험기상정보**(09-13): 기상청이 고속도로 살얼음·가시거리 위험 정보를 중부내륙고속도로까지 확대하고 내비 사업자 설명회(9/14)를 열었다. 티맵과 카카오내비가 이미 적용 중(300m 전방 안내). 참석 여부는 올해 적용 가능성에 따라 결정

## 2310a 지도 반영 리스트 (보강)

2023-10 지도 업데이트(2310a)에 대한 모빌리티Map1팀의 반영 보고 슬라이드와 위치 공유 자료다. 지점 이름은 옮기지 않고 유형만 적는다.

| 문서 | 내용 |
|---|---|
| VOC 반영 리스트 | 사용자 VOC로 들어온 **신설 도로 5건**(회전교차로 신축, 도로 건설·개설, 우회도로, 교량 신설)을 출발지·목적지 쌍과 거리(0.2~1.6km)로 확인한 지도 반영 결과. |
| 안전운행 반영 리스트 | 단속 추가 8건(30·50·60km 고정식·신호·박스형 과속단속), 제한속도 변경 1건(30에서 40km), 삭제 1건. 신호과속과 어린이 보호 성격의 지점이 많다 |
| 마을주민보호·장애인보호구역 위치 공유 | 마을주민 보호구역 3곳, 장애인 보호구역 3곳(전국 각지)의 위치 확인용 슬라이드 |

- 보호구역 속성은 MR v5.1에 들어갔고([[inavi-mr-format-spec]]), 안내 카메라 종류 확장은 위 "후면 번호판 단속" 절과 이어진다. ^[inferred]
