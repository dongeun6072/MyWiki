# 에어 생성형 AI·Feature Ideation 문서 허브

- [[air-genai-model-research-and-cost-2024]] — ChatGPT 모델 가격, 토큰, 월 비용 추정, 시스템 프롬프트 시험, GPT-4o vs mini
- [[air-chatgpt-usecases-and-dev-spec-2024]] — UseCase 10종, 테스트 케이스 비용, 요청 JSON 구조, 에어봇 ver 0.5 스토어 문구
- [[air-perplexity-and-llama-evaluation-2024]] — Perplexity Sonar 가격·비용 테스트·응답 비교, Llama 제공 방식
- [[air-genai-scrum-2024]] — 생성형 AI 스크럼 #1, #3, #4 (8~9월)
- [[air-feature-ideation-scrum-2024]] — 신규 Feature Ideation 스크럼 #1~#8 (5~7월)

## 시간순 흐름

1. 2024-04: LLM AI 활용 서비스 기획(음성인식 제외, OpenAI로 가능한 영역 중심).
2. 2024-05~07: Feature Ideation 스크럼에서 "LLM AI 활용 UseCase"가 기획 항목으로 상시 등장.
3. 2024-07-31: Llama 자료 정리. 08-06 ChatGPT 조사, 08-28 활용 방안.
4. 2024-09: 개발 사양 확정(09-19), 스크럼에서 AI 타당성 검토 완료와 품의 완료(09-11, 09-24).
5. 2024-10: 에어봇 ver 0.5 스토어 문구(10-10), GPT-4o vs mini 비교(10-23).
6. 2024-11-08: Perplexity 검토 결론(상용 반영은 추가 안정화 필요).
