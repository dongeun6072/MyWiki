# MXI Where 택시용 버전 개발과 2023 패치 이력

[[inavi-hybrid-navi]]의 2023년 기록이다. 2022년 배포 절차와 장애 이력은 [[mxi-where-release-ota-2022]], [[mxi-field-incidents-2022]]에 있다. 이 해에는 **택시 기사용 사양**(고객: 아이나비M/서울 장애인 콜택시와 지방 택시 단말)이 개발의 중심이었다. 이름과 접속 정보는 적지 않았다.

## 택시용 사양 (Mobility 버전)

2022-09 회의에서 정리하고 2023-02에 확정한 내용:

| 항목 | 내용 |
|---|---|
| 탐색 옵션 | **택시용 탐색 옵션 추가(UI/UX 변경 없음)**: 추천경로(택시용 탐색)와 최소시간. 기본값을 추천경로에서 **최소시간**으로 변경(2022-10 핫패치에서 적용) |
| 추천경로(택시용) | **통행료와 택시 예상 요금을 합산해 최소 요금**인 경로 제공. 예상 시간과 탐색 거리는 고려하지 않는다(MXi Where 전용 사양). 요청에 `carUsage` 필드 추가 |
| POI 승하차 지점 | 검색 결과에 **택시 승/하차 입구점(EP) 좌표**를 넣어 POI 선택 시 승하차 위치로 기본 탐색. 경주, 순천 EP 데이터를 2022-12 중순까지 구축(완료), **Where 택시용 POI 데이터 발행 프로세스**(v23.01 테스트 데이터, v23.03 정식) |
| 주소 | reverse geocoding 시 **아파트 동·호수** 같은 상세 정보 표시, 신규 주소 검색 API(`/addressNearby`), 검색 결과에 EP 좌표 규격 추가(엔진이 이미 주는 값을 Agent 규격에만 추가) |
| 검색 엔진 | 신규 검색엔진 연동(2023-03) |
| 일정 | 로드맵상 1월 테스트 데이터, 3월 정식. 아이나비M 쪽 지도·탐색 이슈 시트가 2022-11 이후 올라오지 않아 프로젝트가 진행 중인지 불분명하다는 코멘트가 있었다. |

(Agent 쪽 처리 항목: ① 탐색 요청에 `carUsage` 추가(1/17 완료) ② `/addressNearby` 신규 규격 ③ 검색 결과 EP 규격)

## 이슈와 원인

| 시기 | 증상 | 원인·조치 |
|---|---|---|
| 02-15 | 특정 주소 검색 시 **고속도로 한가운데에서 안내 종료** | 해당 주소에 진입 도로망이 없어 목적지에서 가까운 고속도로로 프로젝션됨. 세도로 선형 작업은 끝났지만 3월 지도 일정상 차기 지도에 반영 |
| 03-07 | V2.4.2 업데이트 후 **즐겨찾기를 누르면 Where 중지**(100% 재현), 업데이트 후 내비 볼륨 설정 초기화 | VOC 번호 36번으로 관리, 검토 |
| 03-16 | 주소 검색 시 "WHERE이(가) 중지됨", **이전 목적지 데이터가 없는 상태(최초 설치)** 에서 이전 목적지를 누르면 중지(VOC 38번) | **검색엔진 패치로 `CateName` 항목이 삭제**되어 기존 규격의 `CateName`이 null로 전달됨. 지난 패치에서 새로 만든 **"아파트 동·호수 표출 기능"** 에 null 예외 처리가 없어 발생. 내비에 방어 코드를 추가해 차기 패치에 반영하고, 검색엔진 쪽에는 패치 전처럼 `CateName`을 유지해 달라고 요청 |
| 03-20 | **"경로정보 설정에 실패했습니다"** 팝업 | `-6` 코드는 경로 탐색 후 안내 시작 때 **탐색된 경로 파일 읽기 실패** 시 발행. 길안내 → 비통신 전환 → **통신 전환** 순서에서 발생하는 것으로 재현 |
| 04-18 | 승차 → Where 길안내 API 호출 → 미터기 빈차 → **길안내 취소 API** 호출 시 에러 | 경로선은 취소되지만 우측 레이어(교통정보 영역)는 취소되지 않음. 비정상 종료는 메모리 이슈로 추정되어 메모리 테스트 진행 |
| 03-23 | 도로명 목록이 실제보다 적음 | 검색엔진의 기본 최대 1,000건 제한 → 10,000으로 조정. [[air-map-data-and-safety-guidance-2023]] |

## 패턴

- **검색엔진 응답 규격 변경이 클라이언트 NPE로 이어졌다.** 필드가 사라지거나 null이 되는 경우를 앱이 방어하지 않으면 100% 재현 크래시가 된다. 2022년 GPS null NPE와 같은 계열이다. ([[mxi-field-incidents-2022]])
- 택시용 기능(EP, 최소 요금, 아파트 동호수)은 지도·검색·탐색·앱·Agent가 **함께 바뀌어야** 해서, 각 팀이 따로 발행하면 시점 불일치가 이슈가 된다. ^[inferred]
