# 내 장소 리뉴얼과 내장소 개선/에어 사용자 분석 스크럼 (2023 하반기)

2023년 9~11월 진행된 "내 장소" 리뉴얼의 기획, 리소스 배포, 정식 오픈 문구와, 같은 기간의 "내장소 개선 / 에어 사용자 분석" 스크럼 #1~#7을 정리한다. 제보하기 ver.2 정식 오픈이 같은 릴리즈에 묶여 있어 [[air-lab-and-report-renewal-2023]]와 함께 본다. 목차는 [[air-feature-planning-hub]].

## 1. 기획 — "내 장소 리뉴얼" (pageId 230490137, 2023-10-11)
- 기획서를 피그마 작업으로 전환해 검토 중이며, 링크는 `<링크 생략>`.
- PDF 파일로도 공유하지만 피그마에서 최신 버전을 계속 확인할 수 있어 의견 공유와 문서 업데이트가 기존 방식보다 원활할 것으로 판단.
- 주의: 피그마에서 PDF로 저장하면 용량이 크다.
- 부모 페이지 "내장소 개선 / 에어 사용자 분석"(pageId 234029307)은 본문 없음.

## 2. 폰트 변경 적용 (pageId 270925825, 2023-11-07)

## 4. 스토어 문구 — "내장소 리뉴얼 & 제보하기 정식 오픈" (pageId 260997422, 2023-11-22)
### AOS v03.05.32
```
[v03.05.32]
• 제보하기 ver.2 정식 오픈!
  - 연구소에서 통과된 제보하기 기능이 정식으로 오픈합니다.
  - Best 제보 선정 시 캐시적립까지! 많은 제보 부탁드려요!
• 한눈에 쏙! 내 장소 리뉴얼!
  - 메인화면에서 내 장소를 바로 확인하세요.
  - 저장된 장소를 지도에서 한눈에 보고, 검색도 가능해요!
• 최근장소 관리 및 메인 상단 고정도 쉽게!
  - 메인화면에서 꾸-욱 롱터치 해보세요!
최신 버전으로 지금 업데이트 해보세요!
더 좋은 서비스를 위해 에어팀은 항상 귀 기울이고 있습니다.
```
### iOS v03.05.11
AOS와 같은 세 항목에 더해 "운전석 계기판에도 아이나비에어! - 카플레이의 계기판 연동을 제공합니다."가 추가된다.

## 5. 스크럼 #1~#7 — 내장소 개선 / 에어 사용자 분석 (보관)

### 회차별 특이사항
- #1: Agenda는 내 장소 개선, 에어 사용자 분석. 이슈로 차주 스크럼(19일) 장소를 path-1 회의실에서 대회의실로 변경. Request: SK 광고 이미지 제작 계획(매달인지 일정 확인) — 완료, 1회성 이벤트였고 이후엔 계획을 공유받고 진행하기로 함.
- #2: 이슈 — 차주 스크럼 장소 변경(완료), 신규 음성 선호도 조사(슬랙).
- #3: 구간단속 평균속도 디자인 개선, Push 팝업 이동, 하단 팝업 아웃링크가 ToDo로 신규 등장.
- #4(2023-10-10): Agenda에 AI 횡단보도 추가.
- #5(2023-10-17): AI 횡단보도 "이슈 대응"이 Agenda에 추가. PM 이슈: 10월 28일~11월 4일 출장(독일 → 프랑스 → 벨기에).
- #6: 출장 일정 변경 — 앞선 출장은 취소선 처리, 11월 11일~11월 19일(독일 → 프랑스 → 벨기에).
- #7: 출장이 11월 14일~12월 2일(독일 → 프랑스 → 벨기에 → 기타)로 다시 변경. 차기 패치는 앱 개발 책임자 담당: HUD(로드피아) 연동, SKP 광고 쿠폰 이벤트.
- 모든 회차의 공통 ToDo: 공지 팝업 문구/이미지, 스토어 문구/이미지 현행화, TC 작성.
