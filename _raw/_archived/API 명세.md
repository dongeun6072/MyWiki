## 2. Push 관련

### 2.1 Push Type 정보

| Type | Definition |
|---|---|
| A | 일반 실행 |
| B | 모바일 웹 연동형 (외부 브라우저 URL 연동) |
| C | 탐색 |
| D | 내부 WebView 연동형 |
| E | 앱 특정 화면 표출 |

### 2.2 Push 정보 (Notification Message 정의)

Push 메시지는 다음 유형으로 구분된다.

1. **일반 실행형** (type: "A") — 공통 필드: `nt`(Notification 제목), `pt`(팝업 제목), `pc`(팝업 내용), `iu`(image url). iOS는 `aps.alert` 사용.
2. **모바일 웹 연동형** (type: "B") — `url` 추가 (외부 브라우저 연동).
3. **내부 WebView 연동형** (type: "D") — `url` 존재 시 해당 URL 웹뷰 연결, Empty String 시 이벤트/공지사항 연결.
4. **앱 특정 화면 표출형** (type: "E") — `subtype`(예: "CI": 자정 전 캐시정보 조회 화면, 자정 후 적립 스탬프 조회 화면).
5. **티머니onda 목적지 탐색** (type: "S") — `callID`, `startLoc`, `endLoc`, `viaLocs`, `status`(1/2/4), `payType`(A/D), `routeType`(recommendation/time_priority/real_traffic_freeroad).
6. **티머니onda 목적지 탐색 취소** (type: "X") — `callId`, `status`(1/2), `cancelType`(D: 일반 취소, P: 지불 취소, C: 승객 신고).

### 2.3 Popup 정보

팝업 정보 정의 (상세 내용 별도 정의).

## 26. 전기차 충전소 정보 (응답 파라미터)

| parameter | type | description |
|---|---|---|
| agency | String | 충전소기관 (DE:대구환경공단, KN:부산울산경남, GN:지엔텔, KT:케이티, EV:에버온, ST:에스트래픽, BG:비긴스, JE:제주전기차서비스, KP:한국전력, HE:한국전기차충전서비스, PI:포스코ICT, SE:서울시, PW:파워큐브, CT:씨티카, ME:환경부, CV:대영채비, JD:제주도청, TM:티맵) |
| station_id | String | 충전소 고유 ID |
| fee | String | 충전가격(Kwh) |
| free_parking | String | 주차비 유료여부 |
| operating_hour | String | 운영시간 |
| opagency | String | 운영기관 |
| opagency_contact | String | 운영기관 연락처 |
| reservation | String | 예약여부 |
| membership | String | 멤버쉽여부 |
| serviceable | String | 사용가능여부 |
| update_timestamp | String | 업데이트시각 |
| charger_count | Integer | 전기차 충전기 개수 |
| evcharger | Array | 충전기정보 (chargerid, agency_mangeid, type_1, type_2, status, fee_type, cable_type, display_type, update_timestamp, manufacture 등) |
| type_1_info | Array | 충전기 타입_1 별 정보 (name, charger_count, charger_ok_count) |
| type_2_info | Array | 충전기 타입_2(상세타입) 별 정보 (name, charger_count, charger_ok_count) |
| summary | Object | 충전소 요약 정보 (charge, feetext, simple[name, charge], detail[name, charger_ok_count, charger_total_count]) |

**충전기 상태(status)**: 0:알수없음, 1:통신이상, 2:충전대기, 3:충전중, 4:운영중지, 5:점검중, 6:예약중, 7:표시안함
