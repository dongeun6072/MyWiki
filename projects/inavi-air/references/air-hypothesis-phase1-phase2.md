# 활성사용자 증대 가설 수립

"에어의 성장" 프로젝트의 두 번째 스프린트(가설 수립, 2024-10-28 ~ 11-08)에서 나온 가설과 평가 결과를 모았다. 회의 흐름은 [[air-growth-sprint-minutes-2024-q4]], 앱테크 시장 조사는 [[air-app-tech-research-2024-11]], 선택된 가설의 실험은 [[air-login-induction-experiment-2024-q4]], PRD화는 [[air-prd-v1-v2-app-tech-navigation]]을 본다.

## 1. 구성원별 가설 공유 (10/28, 10/31)
티켓별로 각자 올린 아이디어(티켓 번호 AIR-1754 ~ AIR-1760):

| 티켓 | 아이디어 |
|---|---|
| AIR-1758 | 추가 보상, 게이미피케이션 요소 추가(자동차 키우기) |
| AIR-1759 | 커뮤니티 기능(제보하기 등 관심 콘텐츠 공유 채널), 도보 사용자를 위한 기능 |
| AIR-1760 | 4050 여성 신규 사용자 획득 아이디어 위주 (10/31 추가: 4050 남성 기존 사용자에게 먹힐 아이디어도) |
| AIR-1754 | 주행 DAU를 높이는 아이디어, 게이미피케이션(게이지, 고양이), 미션 완료 후 캐시 보상 |
| AIR-1756 | 주행 외 미션, 친구 초대 |
| AIR-1755 | 만보기, 출석체크, SNS 로그인 귀찮게 하기 |
| AIR-1757 | 로그인 유도 푸시, 저렴한 상품군 추가 |

### 수집된 가설 리스트 (10/28 작성, 10/31 확정)
1. 게이미피케이션: 자동차
2. 커뮤니티: 사용자 간 소통
3. 미션 완료 후 캐시 보상: 즐겨찾기·자주 가는 곳 탐색, 만보기, 출석체크
4. SNS 로그인 전환 높이기: 귀찮게 하기(로그인 푸시), 강제하기
5. 앱테크 앱 강조: 메인화면 리뉴얼, 스플래시 등 전체 시나리오 확인
6. 상품군 추가: 저렴한 것=추파춥스, 현금화 가능한 것=네이버페이
7. 가족을 공략하는 선물 아이템으로 기존 남성 사용자의 앱테크 참여 유도
   - 선물하기: 포인트를 모아 아내/자녀에게 선물(예: 5,000원 모으면 아내에게 꽃)
   - 응원하기: 선물받는 당사자가 포인트 모으는 사용자에게 응원하기로 포인트 추가 적립
8. 지도에서 캐시 줍기(주행 모드에서는 불가)

일정: ~11/4 구글 폼 점수로 우선순위 높은 가설 선정, ~11/7 핵심 기능 선정, 11/9 스프린트 리뷰·회고.

### 회의록 (11/6, 2024-11-06 14:00, 본사)
- 미션 가설: 미션 제공·캐시 적립 시 자연스러운 광고 노출 시나리오 확인, 미션에 대한 추가 리서치 필요
- 만보기: 도보 지도 적용 시점과 별도로 적용해도 의미 있을 것이라는 의견(미션 중 1개). 다만 인당 적립 캐시 최대가 주행 포함 50원인 상황에서 만보기만으로 신규 사용자를 획득할 수 있을지 의문 → 주행 외 만보기로 추가 캐시 적립이 같이 이루어져야 의미
- 선택 로그인: 로그인 미션이 우선 필요(비로그인 사용자가 다른 미션에 참여할 확률이 낮다고 봄). 현재 "팝업 다시 보지 않기" 이후 로그인 유도가 부족 → 더 적극적인 미션·유도 시나리오 기획 필요
- 온보딩: 메인에서 앱테크 강조(쇼핑하기 노출 등), 앱 아이콘 교체, ASO 최적화(안드로이드도 별점 팝업, 스토어 소개 문구 변경)
- 다음 일정: 11/9 15:00 스프린트 리뷰·회고, 11/11 13:00 스프린트 플래닝(목표: 로그인을 유도할 핵심 기능 기획/디자인). 다음 스프린트 중 사업부 미팅 필요 → 추가 포인트 정책 등 시뮬레이션 데이터 준비
- 가설별 핵심 기능 예시: (1) 미션 가설 = 미션 수행, 광고 조회, 추가 캐시 적립 (2) 선택 로그인 = 로그인 유도 앱푸시, 특정 페이지 로그인 유도 버튼 (3) 온보딩 = 스토어 소개/메인/스플래시에서 앱테크 정보 강조 노출
- Appendix: 11/4 기준 활성 사용자당 평균 참여 세션수 2.23회(참여 세션 = 10초 이상 지속, 주요 이벤트 1회 이상, 또는 페이지/화면 조회 2회 이상)

## 3. 서비스 기획자의 가설 수립 문서
### Phase 1. 기존 사용자 대상 DAU 증대 가설
#### 문제 인식
- 4050 남성 사용자는 앱테크에 관심이 적다
- SNS 로그인 비율이 낮다
  - SNS 로그인 사용자의 캐시 적립율이 높다
  - 9월 신규 사용자 중 회원가입한 비율은 6%. GA 기준 로그인 완료 페이지에 1회 이상 진입한 사용자 1,500명 / 신규 사용자 24,000명
- 매일 앱 푸시를 약 4천 명에게 발송하고 약 400명이 연다(일 주행 사용자 16,000명 중 25%만 푸시 수신). 이미 적립했거나 알림을 껐을 가능성

#### 가설
- 가족을 공략하는 선물 아이템: 아빠 50원 + 가족 50원 = 100원까지 획득 가능
  - 선물하기, 응원하기(위 7번 참고)
- 4050 남성이 관심 가질 게이미피케이션
  - 자동차 키우기: 원하는 자동차를 골라 키우며 내 자동차 마커를 교체. 주유, 세차, 엔진오일 등으로 키우고 친구와 함께 키우면 더 빠름. 다 키운 자동차는 캐시로 교환(판매) 가능
  - 주변에 에어 사용자가 있으면 앱푸시를 보내 하이파이브로 캐시 지급(토스와 유사)
  - 캐시를 지도에 뿌려 놓고 줍게 함(스텝어스)
- 앱 첫 실행 시 SNS 로그인 필수(추가 정보 획득은 추후)
- CRM 앱푸시 시나리오(마케팅 앱푸시 동의자 전원)
  1. 앱 최초 설치 및 약관동의 즉시: "24시간 이내 로그인 즉시 100% 500캐시 지급, 24시간 이후 500캐시 소멸"
  2. 7일 뒤에도 SNS 가입 안 한 경우 추가 발송, 이후 주기 발송: 같은 형식으로 1000캐시

### Phase 2
#### 문제 인식
- 경쟁사 대비 내비 본연 기능의 경쟁력 부족 → 장기 개선 사항
- 4050 남성은 앱테크에 관심이 적다: 여성 사용자의 캐시 페이지 방문 전환율(실행 대비)이 남성보다 21% 높고, 여성 활성사용자당 캐시 페이지 조회수가 남성보다 13% 높다

#### 앱테크 분석
- 앱테크 열풍: 성인 남녀 앱테크 사용 75%, 2023년 들어 더 가파르게 성장, 5년간 40대 이상 연령 비중 증가, 여성 사용자 중심
- 기존 플랫폼에서 이용률 증대 또는 이탈 방지(록인) 효과 기대: 토스 만보기, 신한 SOL 출석체크 같은 기능
- 에어의 간접 경쟁사는 다른 리워드(앱테크) 앱. 내비게이션 앱테크 앱 중 1위로 독보적. (나이키의 간접 경쟁사는 닌텐도라는 사례 인용)

#### 타겟
- 4050 여성 사용자 / 운전자(경쟁사 내비 사용자) / 가성비 소비자(앱테크·리워드 앱 사용자)

#### 페르소나
서울 거주 40대 주부, 초등학생 자녀 2명. 초행지는 주로 티맵을 쓰지만, 루틴한 주행(자녀 픽업, 마트 장보기 등)에서는 에어로 캐시를 적립해 소소한 절약을 실천한다.

#### 가설 (가성비 좋은 순 정렬, 앱테크 리서치 보완 후 지속 업데이트 예정)
1. "앱테크" 카테고리 겨냥 ASO 최적화
   - ASO로 하이핀의 "위치추적" 키워드 검색 시 구글 플레이스토어 100위 밖 → 2개월 뒤 10위권 진입(원문 표현 그대로)
   - "앱테크, 리워드" 키워드로 앱스토어 검색 시 상위 10위권에 들면 MAU가 상승할 것이다. 현재는 해당 키워드로 검색 결과 리스트에서 에어가 조회되지 않음
2. SNS 회원가입 허들 낮추기: (a) 주행 없이 SNS 첫 로그인 시 500캐시, (b) (a)가 불가하면 모의주행 튜토리얼 1회 후 500캐시
3. CRM 앱푸시 시나리오 추가(Phase 1과 동일 문구)
4. 친구 초대: 초대·가입 시 n캐시 즉시 지급(2024년 신규 사용자 획득 광고비는 인당 183원). 친구에게 공유해 얻는 캐시(토스 이벤트 참고)
5. 리뷰 작성 시 캐시 적립: 앱푸시·배너로 상시 안내(블로그, 카페, SNS 등), 작성자가 구글 폼에 링크+아이디 제출 시 전원 소액 적립, 베스트 사용자 추가 적립
6. 캐시 할증 적립 시간대: 여성 사용자 겨냥, 주행 사용자가 적은 시간대에 할증 적용, 할증 시간에 여성 대상 앱푸시
7. 상품군 추가: 타겟 참여를 유도할 상품군
8. 게이미피케이션: 주행 전 목표 상품 선정(고등어) 프로세스, 주행 시 지도에서 해당 상품 획득을 향해 주행하는 요소, 약속 장소·시간 공유(위치추적) 기능

### Appendix: 참고 앱
#### 캐시워크
- 만보기 기반 건강 관리 앱. 100걸음당 1캐시
- 촉진 네트워크 모델: 친구·가족끼리 걸음 수를 공유하며 경쟁
- 수익: 초창기 구글 애드몹, 이후 광고주 수주 광고
- 신규 유입: 초대/추천 기능, 유명 연예인 사용 장면, SNS 콘텐츠로 자연 바이럴

#### 발로소득 (챌린지 앱테크)
- 리워드 규모가 큼: 걸음 수 최대 월 630원, 챌린지 참여 수익 140~8,400원(개당 140~700원, 월 최대 12개), 이벤트 수익, 친구 초대 1명당 5,000원(초기 이벤트)
