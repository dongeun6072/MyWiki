# 기존 서울동행맵 앱 v2.2.1 기능 정의

[[이동은]]이 2026-08-06에 기존 앱 **v2.2.1**을 실기기로 전수 탐색해 정리한 문서다. 비회원 모드로 전 화면을 조작하고, 로그인 계정으로 회원 전용 화면을 모두 조작했다. 저상버스 예약 실행과 신고 제출은 하지 않았고, 그 이후 화면은 앱 내 튜토리얼 10페이지를 근거로 해서 `(튜토리얼)`로 구분했다. 신규 앱의 출발점으로, [[seoul-donghaengmap-functional-spec]]과 [[seoul-donghaengmap-screen-design]]이 이 AS-IS 위에서 만들어졌다. 사업 전체는 [[seoul-donghaengmap]]이다.

## 기술 스택 (실측)

| 항목 | 값 |
|---|---|
| 패키지 | `kr.go.seoul.mydata`, v2.2.1(versionCode 102), compile/target SDK 35 |
| UI 프레임워크 | **Flutter** (logcat의 `libflutter.so`) |
| 앱 보안(RASP) | **AppSuit**. 에뮬레이터를 탐지하면 앱을 강제 종료하므로 실기기 전용 |
| 지도 | 카카오맵 |
| 튜토리얼 | v2.0.4 기준이라 실제 앱보다 구버전 |

## 전역 구조와 제약

- 지도 단일 화면과 바텀시트, 하단 탭 4개(홈, 교통약자서비스, 엄마아빠서비스, 즐겨찾기)
- **서비스 지역은 서울 한정**. 서울 밖에서는 토스트가 뜨고, 경로 탐색도 출발·도착이 모두 서울 안일 때만 결과가 나온다. 데이터가 서울시 공공데이터이기 때문이다.
- 로그인: 카카오, 네이버, Google, 이메일 + 비회원. 비회원은 저상버스 예약, 커뮤니티맵 신고, 즐겨찾기, 집으로 기능이 막힌다.
- 교통약자 여부는 가입 때 정하고 설정에서 바꾼다. 길안내 프로파일과는 **별개 값**이다.

## 주요 기능

| 영역 | 내용 |
|---|---|
| 지도 필터 칩 6종 | 보행 불편, 휠체어 충전소, 엘리베이터, 에스컬레이터, 역 내 수유실, 장애인 화장실 |
| 길안내 | 프로파일 3종(노약자·임산부 / 휠체어·유모차 / 비장애인). 전환 시 즉시 재탐색. 결과는 후보 목록(총 소요, 도보 시간, 구간 바, 혼잡도). 대중교통 구간마다 승하차 예약 버튼 |
| 버스정류장 | 반경 200m 근처 정류장, 저상버스만 표시 토글(기본 ON), 노선별 도착 2건, 저상/일반 배지 |
| 지하철역 | 반경 1.5km, 교통약자 내부환승 가능 표시, 방면별 실시간 도착, 역무원 전화 연결 |
| 교통약자 서비스 7메뉴 | 버스정보, 장애인 콜택시, 복지콜, 지하철 도우미, 휠체어 길안내, 청계천 이동약자 시설물, 이동약자 접근성 정보 |
| 엄마아빠 서비스 5메뉴 | 버스정보, 엄마아빠택시(타다, 파파), 지하철 수유실, 유모차 길안내 |
| 즐겨찾기 | 회원 전용. 집·회사 고정 2슬롯 + 일반 |
| 커뮤니티맵 신고 | 회원 전용. 유형 4종(단차 2cm 이상, 경사 1/8 이상, 보도폭 1.2m 이하, 기타), 사진은 카메라 촬영만, 위치는 현재 위치 고정 |

## 저상버스 예약 규칙

- 노선 상세에서 "현위치"로 잡힌 정류장 행에만 승차예약 버튼이 붙는다. 이때 현위치는 GPS가 아니라 **사용자가 검색해 들어온 정류장**이다.
- 정류장 50m 이내 접근 시 확정, **예약 후 30분 안에 접근하지 않으면 자동 취소**, 승차 정류장 접근 전이나 저상버스가 직전 정류장에 도착하기 전까지 취소 가능
- 승차예약 후 하차예약이 가능하다. 예약 대기 중에는 **앱을 실행 중이어야 메시지가 발송**된다(앱 종료나 화면 꺼짐 시 예약이 안 될 수 있음).
- 이 규칙이 [[seoul-donghaengmap-functional-spec]]의 기능 35번에 "현행 앱 규칙 기준"으로 그대로 들어갔다.

## 신규 앱과의 차이 (화면기획 v1.0 대비)

| 항목 | 기존(v2.2.1) | 신규(v1.0) |
|---|---|---|
| 첫 화면 | 지도 + 바텀시트 | 기능 진입 버튼 중심 홈 + 하단 3탭(홈, 길안내, 마이페이지) |
| 프레임워크 | Flutter, 카카오맵 | CMP 단일 코드베이스 |
| 접근성 | 별도 모드 없음 | 교통약자 유형 선택, 시각장애인(전맹) 전용 화면, 고대비, 글자 크기 |
| 예약 | 승·하차 예약 | 승차 예약 4단계, 하차 정류장은 선택 |

## Open Questions

- 신고 제출과 예약 실행 이후의 서버 검증 규칙은 확인하지 않았다(문서에 "미확인 범위"로 기록).
- 신고하기 버튼이 라디오 1건만 고르면 활성되는 점이 서버 검증과 어떻게 맞물리는지는 미확인.
