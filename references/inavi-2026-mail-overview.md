# 2026년 업무 메일 개요 (받은편지함 정리)

[[이동은]]의 2026년 Outlook 받은편지함(2026-01-01 ~ 10-26)에서 인증·알림·Slack·Notion·Jira, 경영지원·HR 공지, 일정 초대를 뺀 업무 메일 약 108통이다. 2025년은 [[inavi-2025-mail-overview]]에 있다. **이름, 연락처, 서버 주소(IP·호스트·포트), 계정·키·비밀번호, 공유 링크는 위키에 옮기지 않았다.** 원본에는 키·계정류가 있어 `_raw`에서도 가렸다(아래 "보안 처리").

## 2025년과 달라진 점

- **대만 경로 서버가 한 해 내내 이어진다.** v1.7(01-07)에서 v2.31(08-14)까지 릴리즈 메일이 계속되고, 2월 이후에는 트럭 제원·경유지 옵션이 붙는다. → [[orbis-taiwan-development-2026]]
- **서울 동행맵이 수주(06-25)되어 08~10월 메일의 큰 축이 됐다.** → [[seoul-donghaengmap-mail-2026]]
- 에어는 통합회원 분리, 크래시 대응, 파트너 SDK 개편, 안전운행 데이터 개편이 중심이다. → [[air-operations-2026]]
- 서명 부서명은 프로덕트전략부문 MX그룹 모빌리티개발셀, 프로덕트개발부문 MX그룹 서버플랫폼셀로 나온다.
- 출산·육아휴직 공백(2026-01-20 ~ 04-20)이 있어 개발 담당 업무를 나누는 방안이 공유됐다(01-07). 휴직 기간에는 국내 Navi SDK·TSD-A01 비정기 대응만 유지하고 Maps SDK는 이해 수준의 작은 과제와 스크럼 참여로 제한하는 안이었다. ^[inferred]

## 고객사 건

- **삼성중공업**: 전용 NaviSDK 초기 데이터 수정(03-23), 안전운행 도우미 SDK 버전 정정(04-02, 1.2.0을 1.20.0으로 바로잡아 latest 방식 유지), 출입 금지구역 추가 반영 요청(10-26). DriveThru 서버 이관(05-06, 07-07)에서는 서버플랫폼셀이 `/shiSdk/sendShiGps`에서 기존과 신규 서버 두 곳으로 동시 전송하도록 개발 서버를 설정했고, 신규 서버만 404를 반환했다. 삼성중공업이 매주 SFTP로 위치정보 동의 파일을 올리므로 해당 접속은 이관 후에도 필요하다.
- **삼성생명**: 앱 구축 PoC 미팅(02-23)과 개발 스크럼 반복 일정(04-15~12-31). 상세 메일은 없다.
- **트리포스**: 아이나비 내비 테스트 중 오류 문의(09-29). 본문이 짧다.
- **아바티**: 포인트홈 개편에 따른 SDK 업데이트 협조 요청이 02-02, 03-11, 07-29, 10-19에 반복된다. → [[air-operations-2026]]

## PND·통신형 지도 월별 갱신

- 04-06 메일: 2605a 에어·하이브리드 지도에서 엔진(MR)과 앱(SMR)의 Mesh 개수가 달라 모의주행이 되지 않던 이슈를 고치려고 `numOfMesh`를 5668로 맞췄다. 이후 지도 발행 메일에 같은 조치가 이어진다. → [[inavi-hybrid-navi]]
- 06-09 메일: 2607a 에어·하이브리드 지도 일정. 전남·광주 행정통합 특별법 국무회의 통과에 따른 행정코드 개편이 같이 다뤄졌다(통신형 지도 우선 제공 시 KGM·TMC 영향 검토).
- 07-08 메일: 팔룡·창원·녹산·광안대교 영업소 요금 조정에 따른 요금 테이블 전달. 통신형 7월 지도 반영 여부를 검토하고 탐색 서버를 재기동해 달라는 내용이다.
- 09-03 메일: 전남광주통합특별시 표출 사양과 앱·지도 발행 일정 공유(본문은 남아 있지 않다).

## 회사 맥락

- 비전 워크숍(2026-04-03, 판교): "모든 이동을 위한 파트너" 슬로건이 선정됐다(04-09 레터).
- 2026 국제물류산업대전(03-31~04-03, 킨텍스)과 STK 2026(6월) 참가: 물류 경로·적재 최적화, Geotab, iMPS, 로봇 배송 정밀지도를 선보였다.
- 07-01 레터: AI 기반 적재 최적화와 **iNAVI MCP 서버**(Claude Code, Codex 같은 MCP 호환 도구에서 API 탐색·연동을 돕는 도구)를 소개했다.
- 03-20 메일: 클라우드 서버 인스턴스 비용 절감 검토(Grafana에 사업 요청 수용, 웹서버·DB 서버 제거 시 데이터를 엑셀로 줄지 사이트를 유지할지 판단).
- 05-14 메일: Android SDK 배포 서버를 이전했고 기존 NHN Cloud 서버는 백업 후 중지했다.

## 보안 처리 (원본)

원본 `Outlook_2026.md`에는 서버 IP·호스트·포트, 구글 API 키, 앱 키, 계정 비밀번호, 팀즈 모임 암호, 전화번호·메일, 사내 공유 링크가 들어 있어 `_raw`에서 모두 가렸다. 그중 구글 API 키는 03-09에 구글이 "공개적으로 액세스 가능한 API 키"로 경고한 메일이었다(에어 앱 APK가 공개 저장소에 올라가 발견됨). 키 교체·제한 여부는 메일에 없다.
