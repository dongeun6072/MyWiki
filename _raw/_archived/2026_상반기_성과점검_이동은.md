## 셀프 평가 (이동은 작성)

### 성과 1. 고객사 프로젝트 요구사항 및 일정 준수
- **기여한 목표:** [이동은 주임 목표] 고객사 프로젝트 요구사항 및 일정 준수 (비중 20% · 진행 중, 진척도 50%)

**1. 목표 달성 현황 (정량·수치 중심)**

상반기 동안 MapLibre 기반 해외향 Maps SDK를 출시하고 API 레퍼런스, Demo 앱, IMPS 페이지 연동 가이드까지 구축하여 글로벌 서비스 확장 기반을 마련했습니다. 해외향 Navi SDK는 트럭향 API 추가(v1.0.2) 이후 탐색 엔진·맵매칭 업데이트(v1.0.3), 교통정보 색상 미반영 이슈 수정 및 Style 기반 다국어·setLanguage·Web 인증 Style 연동(v1.0.4 예정)까지 순차적으로 대응했으며, Maps SDK도 웹 인증 기반 Style 연동 및 다국어 동적 적용(v1.0.1 예정)을 진행했습니다. 삼성생명 드로잉런 SDK는 요구사항 기능 개발을 완료한 뒤 Android/iOS 배포를 완료했고, Flutter Plugin Step 1(Orbis Navi/Map SDK)도 배포했습니다. 목표 진척도 50%.

**2. 잘되고 있는 점**

해외향 Navi/Maps SDK에 신규 기능이나 추가 요구사항이 발생할 때마다 적절히 반영하며 안정적으로 대응하고 있습니다. 특히 초기 국내향 소스 제거, 플랫폼 로직의 공통 로직화 등 리팩토링을 병행하여 이후 고객사 대응 속도를 높일 수 있는 구조를 갖춰가고 있습니다.

**3. 어려운 점 또는 미흡한 부분**

해외향 SDK 배포 과정은 Android 서브모듈 빌드, Dokka 빌드, iOS XCFramework 빌드, SPM 등 여러 단계를 순차적으로 수행해야 해서 프로세스가 복잡하다는 어려움이 있었습니다. 상반기 중 공통 배포 프로세스를 개선·정비하여 비효율을 일부 줄였으나, 배포 안정성과 운영 효율은 지속적으로 높여갈 필요가 있습니다.

**4. 앞으로의 실행 계획 및 개선 방향**

하반기에는 개선한 공통 배포 프로세스를 안정화하고, Navi/Map SDK에 추가되는 요구사항에 신속히 대응할 수 있도록 공통 구조와 문서를 지속적으로 정비하겠습니다. 고객사 대응을 위한 적용 속도와 품질을 함께 높여 Phase-2 고도화를 차질 없이 진행하겠습니다.

### 성과 2. KMP/CMP 기반 멀티플랫폼 프로젝트 전환
- **기여한 목표:** [이동은 주임 목표] KMP/CMP 기반 멀티플랫폼 프로젝트 전환 (비중 20% · 진행 중, 진척도 50%)

**1. 목표 달성 현황 (정량·수치 중심)**

상반기 내내 KMP 관점을 우선하여 프로젝트를 진행했습니다. 삼성생명 POC를 빠른 iOS 대응을 위해 KMP 프로젝트로 구성하고 공통 기능을 KMP 라이브러리로 개발했으며, 이를 기반으로 삼성생명 드로잉런 SDK를 KMP로 Android/iOS 배포 완료했습니다. 해외향 Navi SDK에는 setLanguage 공개 API를 추가하고 공통 SDK 에러 처리 구조를 일원화하여 Android/iOS 공통화를 진행했으며, 드로잉런 SDK의 세션 종료(stop)·일시정지(pause) 분리 및 전체 초기화 reset() API를 공통 모듈로 구현했습니다. 목표 진척도 50%.

**2. 잘되고 있는 점**

프로젝트를 검토하거나 진행할 때 KMP/CMP 기반 멀티플랫폼 관점을 우선적으로 고려하는 것이 자리 잡았습니다. 플랫폼별 로직을 공통 모듈로 끌어올리는 작업을 반복하면서 유지보수 효율과 플랫폼 간 상호운용성이 개선되고 있습니다.

**3. 어려운 점 또는 미흡한 부분**

현재까지의 경험이 SDK 중심이어서 CMP 기반 애플리케이션 프로젝트에 대한 실무 경험이 부족합니다. Compose 역량은 드로잉런 데모/샘플 앱을 Compose UI로 전환하며 일부 확보했으나, UI 구성·구조 설계·운영 방식 등 실제 애플리케이션 관점의 경험을 더 보완할 필요가 있습니다.

**4. 앞으로의 실행 계획 및 개선 방향**

CMP 애플리케이션 개발 방식을 개인 학습으로 보완하여 이해도를 높이고, 관련 프로젝트 기회가 생길 경우 빠르게 적용할 수 있도록 사전 준비를 강화하겠습니다. 공통 모듈화 범위를 넓혀 멀티플랫폼 대응 역량을 한층 더 높여 나가겠습니다.

### 성과 3. AI 도입을 통한 업무 생산성 개선
- **기여한 목표:** [이동은 주임 목표] AI 도입을 통한 업무 생산성 개선 (비중 20% · 진행 중, 진척도 50%)

**1. 목표 달성 현황 (정량·수치 중심)**

Codex·Gemini 등 다양한 AI Agent를 업무에 도입하여 Global Maps SDK 개발, 국내향 Java 로직의 Kotlin 전환·리팩토링, 삼성생명 POC 기능 개발 등에 활용해 개발 시간을 단축했습니다. 드로잉런 SDK에서는 요구사항 명세를 기반으로 Jira 티켓 자동화를 진행했고, Flutter Plugin 개발부터는 기능 스펙·ADR·아키텍처를 docs 폴더에 사전 문서화한 뒤 AI와 협업하는 방식으로 전환하여 코드 정확도를 높였습니다. 나아가 AI 기반 스펙/설계 문서화로 개발 히스토리를 작성하고, 셀 공용 Wiki 서브모듈에 설계 문서·ADR·아키텍처 문서 이관을 진행했습니다. 목표 진척도 50%.

**2. 잘되고 있는 점**

다양한 AI 모델을 업무에 적용하면서 반복 작업과 검토 시간이 단축되어 개발 프로세스의 효율성이 증가하고 있습니다. 특히 코드를 바로 생성하던 방식에서 "선(先)문서화 후 AI 협업" 방식으로 전환한 이후, 코드 패턴 일관성과 요구사항 반영 정확도가 개선되었습니다.

**3. 어려운 점 또는 미흡한 부분**

AI Agent 팀 플랜 도입이 초기 단계인 만큼 팀 공통 Skills, MCP 등 표준화된 활용 방식이 공통으로 정착되지 않아 개인별 편차가 존재합니다.

**4. 앞으로의 실행 계획 및 개선 방향**

AI Team Skill 및 운영 방식 체계를 정비하고, 반복적이거나 비효율적인 작업을 줄일 수 있는 공통 워크플로우를 구축하겠습니다. 이를 통해 목표로 했던 비개발 Jira 티켓 유지보수 자동화, AI 기반 번역 프로세스 개선 등 자동화 프로세스를 실질적으로 개선해 나가겠습니다.
