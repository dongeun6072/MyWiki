## 채널 논의

### 서울동행맵 dev → [[seoul-donghaengmap-dev-slack-tech-2026]]

- **실내내비 동작 시나리오 v0.1**: 기획이 상세 시나리오 PDF를 공유했다(파일 미수록). 화면기획서에 넣을지는 개발이 "가능함"을 확인하면 넣기로 했다. 앱 리드 검토로 휠체어 탑승 편의 객차 정보가 아로·LBS테크 규격에 없음, 설비 운행 중단 정보 출처(파파야/아로) 확인 필요, 고령자/임산부 하차역 엘리베이터 문 케이스 UX 추가가 나왔다.
- **실외내비 SDK 검토**: PM이 컨소시엄 채널 LBS테크 SDK 건의 검토 내용과 질문 정리를 요청했다. 앱 리드는 배포 버전으로 기획·디자인이 UX를 확인하도록 안내했다(판교역 검색, 개발자 옵션 모의주행).

### 컨소시엄 협업 → [[seoul-donghaengmap-consortium-slack-2026]]

- **실외 길안내 API camelCase 통일**: NAV-101·NAV-102의 요청 파라미터, 응답 키, 코드 값, geojson 키, 429 응답 키를 camelCase로 바꿨다. 주소·키·한도·응답 구조·단위·유형 코드는 그대로이고 SDK 0.1.0 연동에는 영향이 없다. 앱 API 연동 코드는 필드명을 맞춰야 한다. ^[inferred]
- **버스 하차 알림 우선순위**: LBS테크가 하차 전 정류장·하차 150m 전에 PUSH와 음성 안내를 SDK가 내는 안을 내며 메인 앱과의 우선순위를 물었다. 회신은 아직 없다.

### 아이나비 에어 → [[air-channel-slack-2026]], [[air-nsdk-dev-slack-2026]], [[air-prj-slack-2026]]

- **03.05.64 / 03.05.40 스토어 오픈(10시경)**: iOS 서비스, AOS 85% 출시. 업데이트 내용은 단속카메라 타입 추가, 친환경탐색 옵션, 아바티SDK 업데이트, 안정성 개선이다. 탐색 상용 서버가 신규 URL로 26.10(T29) 버전을 열었고, 안내엔진 상용 서버에 `CameraGuidePoint.zip`이 반영됐다. 판교역–서울역 로그 주행과 내부 테스트에서 이상이 없었다. 11-05(수)까지 모니터링 후 공지·선택 업데이트를 요청한다.
- **이동은 모니터링 보고(17:30)**: AOS 03.05.64는 아직 유입률이 안 잡혔고, SIGSEGV(사용자 5명, 이벤트 9건, `libairmaps.so` JNI null pointer dereference)가 나고 있어 추가 모니터링이 필요하다.
- **iOS 긴급 빌드**: CarPlay 대시보드에서 카메라 표출 시 비정상 종료(113건/14명)가 확인돼 iOS 03.05.41 (506)을 TestFlight와 App Store 심사에 올렸다. 친환경 옵션 때문에 탐색서버에도 이슈가 있다는 보고가 있었고, 고도 정보만 빼면 개발서버에서 문제가 없어 엔진팀에 공유했다.
- **CarPlay 클러스터 `setDpiRatio`**: 엔진 담당이 테스트 버전을 전달했다(기본값 폰 1.9, 패드 2.2). `dpRun`을 뺀 버전에서도 멈춤이 재현됐고, 로그는 아직 모으지 않았다.
