# 에어의 성장 (AIR x Reboot) 프로젝트 운영 계획과 스프린트 회의록

2024-10~12 에어 팀 전원이 데이터 기반으로 성과 지표를 정하고 제품 문제를 함께 개선한 프로젝트("에어의 성장")의 운영 계획과 회의록이다. 분석 자료는 [[air-data-analysis-2023-10-2024-09]], [[air-server-data-analysis-2023-11-2024-11]], 가설은 [[air-hypothesis-phase1-phase2]], 로그인 유도 실험은 [[air-login-induction-experiment-2024-q4]], 요약본은 [[air-growth-strategy-and-metrics-2024]]를 본다. 참여자는 PM, 서비스 기획자, 기획자, 디자이너, 앱 개발자 3명([[이동은]] 포함)이다.

## 1. 프로젝트 개요
- 배경과 목적: 데이터 기반 성과 지표 설정과 프로덕트 성장, 모든 에어 구성원이 함께 문제점 파악·개선
- 기간: 2024.10 ~ 12월(구현 범위에 따라 조정 가능)
- 구성원: 7명(PM, 서비스 기획자, 기획자, 디자이너, 앱 개발자 3명 등)

### 운영 계획
| 기간 | 스프린트 목표 | 백로그 |
|---|---|---|
| 1주 (10/22 화 10:00 스프린트 플래닝) | 목표 설정 | 각자 생각 공유·논의, 리서치, 데이터 추출, 데이터 분석·인사이트 추출, 중기 목표 설정 |
| 2주 | 문제 정의와 가설 수립 | 목표 달성을 방해하는 문제 정의, 해결 가설 수립, 우선순위 가장 높은 가설의 최소 핵심 기능 정의 |
| 2~4주 | 가설 검증용 핵심 기능 구현 스프린트 | 기획/디자인, 개발, 검증 |
| 2주 | 가설 검증 | 검증 여부 모니터링, 결과 분석, 회고로 다음 스프린트 목표 설정 |
- 주 1회 스크럼, 필요 시 상시 미팅

### Summary: 목표, 문제 정의, 가설 예시
| 목표 예시 | 문제 정의 예시 | 가설 예시 |
|---|---|---|
| 신규 사용자 유입 | 경쟁사 대비 USP 부족 | USP를 강조하는 신규 기능으로 신규 사용자 유입 / 앱테크 기능 개선으로 유입 |
| | 기존 사용자가 신규를 유입하도록 바이럴할 기능이 없음 | 바이럴 기능 구현으로 유입 |
| | ASO 미최적화로 앱스토어 "네비/지도" 카테고리 노출이 약함 | ASO 최적화로 노출 증가 → 신규 유입 |
| 리텐션 지표 개선 | 앱 사용에 불편을 느낌 | VOC(앱 내 제보하기, 스토어 리뷰 분석) 기반 우선 요구사항 개선 |
| | 광고가 기존 사용자에게 불편 | 광고 UIUX 개선 |
| | 앱 실행을 유도하는 기능 부족 | 앱 실행 유도 신규 기능 / 주행 전환율 향상 / 앱테크 기능 개선 |
| | 앱 실행을 유도하는 CRM 마케팅 필요 | 유저 시나리오별 개인화 앱푸시 |
| 광고 매출 증가 | 광고 노출수가 적음 | 광고 노출 지면 추가 |
| | 광고 전환율(클릭/노출)이 낮음 | UIUX 개선으로 광고 전환율 향상 |

### 단계별 가이드
- **목표**: 데이터를 기반으로 우선순위가 가장 높은 중기(1~3년) 목표 1개 설정. 필요 시 사업과 모빌리티 Tech 그룹의 공동 목표 협의. 예시: 신규 사용자 유입, 리텐션 지표 증대(의미 있는 리텐션 지표는 함께 발굴), 광고 매출 증가
- **문제 정의**: 목표 달성을 방해한다고 생각하는 항목을 모두 나열하고, 지표 기반으로 해결 가능한 최우선 문제 정의. 예시는 위 표와 같음(신규: USP 부족/바이럴 기능 부재/ASO 미흡, 리텐션: 앱 사용 불편/실행 유도 기능·시나리오 부재/광고 불편, 매출: 광고 노출수 적음/전환율 낮음)
- **가설과 검증 지표**: 최소 리소스로 목표 달성에 가장 큰 도움이 될 가설, 2~4주 스프린트로 검증 가능한 가설(최소 기능). 검증 지표는 현재 지표 기반으로 설정하고 목표 지표 달성 시 검증 성공. 예시는 외부 Jira 티켓 2건(링크만)

### Reference: 필요한 데이터와 분석
- 서버 데이터(신규 추출): 아이디, 성별, 연령 등, 고착도
- 앱스토어: 노출수, 방문자수, 설치수
- GA: 코호트 리텐션(기존 vs 신규 비교), 활성사용자수, 방문 페이지, 이벤트(클릭), 이탈, Funnel, 유입경로, OS, 고객 데모그래피, 체류시간
- 어드민: 설치자수, 가입자수, 탈퇴수, 탈퇴사유(확인 불가)
- 사업부 데이터: 광고 매출, 비용, 캐시 적립자수, 쿠폰 구매자수
- iGA웍스: 고객 데모그래피 등
- 리서치/고객 분석: SWOT(경쟁사 대비 우리 내비를 쓰는 이유), STP(강점, 타겟, 포지션), 기존·신규 사용자의 타겟과 페르소나

### Archive: 사업 R&R, 가설 리스트업, 데이터 요청
- 사업 R&R: 신규 유입(브랜딩 강화, 퍼포먼스 마케팅, 파트너십 프로모션), 광고 매출 증가(신규 광고주 확보), 리텐션 증대(CRM 마케팅)
- 가설 리스트업: 신규 유입(USP 강조 기능, 바이럴 기능, ASO로 스토어 설치 전환율 개선), 광고 매출(UIUX로 광고 전환율·노출수 향상, 주행 사용자의 캐시 적립률 향상), 리텐션(기존 vs 신규 중 어느 타겟에 집중할지 질문, 주행 전환율(주행DAU/DAU) 향상, VOC 기반 개선, USP 기능)
- 데이터 요청: 최근 광고 수익 데이터(ASAP, PM), 사용자 데이터(10/18까지 템플릿 전달 후 차주 추출 요청). 포함 요청: 캐시 적립자/사용자 데모그래프(어떤 사용자가 적립하나, 기존인가 신규인가), 적립률이 오르면 신규 증가·리텐션(접속 빈도)·매출·주행 전환율에 영향이 있는가, 광고 클릭 사용자 데모그래프

## 2. 스프린트별 회의록

### 10/22(화) 스프린트 플래닝: 목표 설정 & 생각 공유
- 장소: 패스트 파이브. 스프린트 목표: 에어의 성장을 위한 중기 목표 설정. 기간 10/22~10/28(1주, 목표 확정까지 FIX)
- 백로그: 서비스 기획자가 기간 내 백로그 생성 완료, 각자 목표 달성을 위해 할 일 생각해 보기
- 데이터 공유: 파악 가능한 1차 분석 → 서버·캠즈 데이터 파악 후 2차 공유 예정
- 각자 생각 공유 질문 3개: (1) 에어의 가장 중요한 목표는 무엇이며 이유는? (2) 목표를 방해하는 가장 큰 문제는? (3) 그 문제를 해결할 가설(방법)은?
- To-do: 주간 스크럼 일정(이번 주 10/24 10:00~11:30 공유·목표 설정, 이후 매주 수 14:00~), 프로젝트명 결정은 이후(취소선 처리), 데이터 확인
  - 유저 서머리 분석 추가(~차주 초): 연간 활성 사용자 리텐션(가입~마지막 접속 평균 기간), 신규 vs 기존 리텐션 비교
  - 캠즈 분석 추가(~차주 초): 캠즈 DAU가 맞는지 확인(캠즈 DAU 32,000 vs GA DAU 35,000), 캠즈에 MAU가 없어 GA와 비교 필요
  - 경쟁사 데이터 추가: 카카오맵, 아틀란, 원내비
  - 외부 자료의 MAU 9만과 GA MAU 16만이 왜 다른지 확인 필요 → 담당자에게 문의 완료
