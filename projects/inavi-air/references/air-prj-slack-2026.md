## 2. CAMS(에어 통계) 인프라와 이관 (1~4월)

- **2026-01-06**: 운영 담당이 "Air Cams 26년 1월 데이터가 조회되지 않는다"고 확인 요청. 서버 플랫폼 담당이 확인 필요로 보고, 개발 담당이 확인 후 조치 완료를 보고. 별도로 통계 담당이 "에어 통계는 1월 이후 정상 산출되어 DB에 저장된 것으로 확인된다"고 답변.
- **2026-02-11**: 앱 담당 수석이 "에어 CAM 통합 건은 담당자가 지정되었으니 이후 내용은 해당 채널에서 진행"한다고 알리고, AIR GCP 통계 생성용 인프라 구축 계획과 목표 일정 공유를 요청.
- **2026-02-12 인프라 계획(통계 개발 담당)**:
  - 현재 TMC 통계 전용 GCP 계정 안에 Compute Engine 인스턴스가 있고, 에어에도 같은 구성이 필요하나 신규 인프라 대신 TMC에 이미 구축된 내부 리소스를 활용해 구성할 예정.
  - 개발 계획: 기존 Batch Daemon을 확장해 논리 분리 DB(Toyota, AIR)를 구성해 에어 데이터를 적재, 기존 Grafana에 AIR 대시보드 추가. 1차 목표는 TMC에 구축된 항목을 에어에 동일 방식으로 적용, 2차 목표는 사업에서 요청한 항목 중 TMC 방식으로 집계하지 않는 항목을 추가 개발. 개발 일정은 3/5까지.
  - 서버 인프라 팀장 의견: AIR CAMS는 TMC와 완전히 분리해 별도 자사 계정에 구축해야 한다(TMC 계정을 지워도 AIR CAMS는 무관하게 동작해야 함). 필요 인프라의 수량/사양을 정해 생성 요청하라고 요청.
  - 서버 플랫폼 담당이 같은 날 14시 이전 통계 개발 담당을 통해 설계 의도를 전달받았고 내부 공유를 마쳤으며, 분리 구축 방향으로 이해하고 수량·사양을 정리해 요청하겠다고 보고.
  - TMC 컴퓨팅 사양 공유: CPU 2 Core, Memory 4GB, Disk 200GB. 인프라 팀장이 Compute Engine 한 대만 필요한지, RDS 등 다른 구성이 필요한지 확인 요청(DB·Grafana용 인스턴스가 추가로 필요해 보임) -> 서버 플랫폼 담당이 Compute Engine 한 대에 Grafana와 DB를 직접 설치할 예정이라고 답변.
- **2026-02-23**: 앱 담당 수석이 진행 상황 공유 요청 -> 통계 개발 담당이 GCP VM 인스턴스와 BigQuery 접속 정보를 전달받아 리소스 검토 중, 금주 내 MySQL과 Grafana 환경 세팅 예정이라고 답변.
- **2026-02-27**: 통계 개발 담당이 GCP VM 인스턴스 내 MySQL과 Grafana 설치 완료를 보고(접속 정보는 위키에 옮기지 않음). 대시보드는 Batch 데몬 개발 후 진행 예정이라 보이는 구성은 없다고 덧붙임.
- **2026-03-04**: 앱 담당 수석이 초기 계획상 목표일정이 3/5였다며 문제 없는지 확인 요청 -> 서버 플랫폼 담당이 전날 정리해 답변드렸어야 했다고 사과하고 정리 후 회신하겠다고 답변. 통계 페이지 오픈은 가능하나 1~2주 정도 일정기간 수치 비교 확인과 누락 항목 확인이 필요해 보인다고 의견.
