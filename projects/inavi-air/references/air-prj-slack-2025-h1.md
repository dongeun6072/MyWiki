# Slack #10_prj-inaviair 대화 (2025 상반기)

아이나비 에어 프로젝트 공개 채널 `#10_prj-inaviair`의 2025-01-02~2025-06-30 기록이다. 프로젝트 개요는 [[inavi-air]], 같은 기간 다른 채널 기록은 [[air-channel-slack-2025-h1]], 버전 정리는 [[air-app-version-notes-2025]], 연간 계획은 [[air-2025-plan]]을 본다.

이 구간 채널 메시지 71건(입장·퇴장 알림 8건 포함)을 모두 읽었고, 답글이 달린 스레드 55개를 전부 열어 답글 288건을 읽었다. 사람 이름은 역할로, 서버 주소·계정·연락처·링크는 `[HOST]`, `[LINK_REMOVED]` 등으로 가리거나 생략했다. 첨부는 파일명·종류만 적었다. 스레드에 따라 구간 이후(7~9월)에 달린 답글이 섞여 있어 해당 부분에 날짜를 표시했다.

## 1. 2025-01

- **01-02 쇼핑하기 신규 상품 괄호 코드 표기**: 서비스 운영 담당(에어 마케팅·운영)이 쇼핑하기에 신규 추가한 상품 2건(파리바게뜨 햄치즈 베이글 샌드위치, 버거킹 와퍼세트)에서 괄호가 문자 코드로 표기된다고 수정을 요청했다(메모장에 붙여도 동일). 서버 개발 담당이 수정 후 회신하기로 했고 이어서 "해당 내용도 수정되었다"고 답했다.
- **01-02 연말 이벤트 조회수 요청**: 에어에서 진행한 "WeZURO SSG 스탬프 이벤트"(173번)의 12/23~12/31 조회수를 요청, 서버 개발 담당이 일자별 조회수를 회신했다(12/31 1,882 / 12/30 1,456 / 12/29 1,709 / 12/28 2,721 / 12/27 1,555 / 12/26 1,022 / 12/25 2,023 / 12/24 1,427 / 12/23 1,244).
- **01-03 에어캠즈 통계 1월분 미조회**: 에어캠즈 통계 전 항목에서 2025년 1월 데이터가 조회되지 않고 24-12-31까지만 보인다는 문의. 서버 개발 담당이 처리 후 확인 요청해 해결.
- **01-06 올해 업데이트 방향성 논의**: 기획 담당이 사업팀과 30분 논의(13:20~13:50)를 제안했다. 이후 개발 담당이 정리한 요청 항목: 설/추석 무료 개방 주차장, 침수피해 상세 안내 추가(1Q), 신호등 서울시 위치 확대(하반기), 블랙아이스 연동(3Q), 아바티(황금티켓) 1월 중 서비스, 광고상품 추가(SKP). 이를 바탕으로 개발 담당이 Plan을 작성해 공유했다(2025-01-14 답글까지). 연간 계획은 [[air-2025-plan]] 참고.
- **01-07 WAS 교체 장비 요청**: AIR WAS OS 업그레이드와 부하 분산을 위해 교체 장비 4대(8core / 16GB mem / 512GB disk) 생성을 인프라 담당에게 요청, 당일 생성 완료하고 서버 정보를 사내 Dooray의 AIR 인프라 목록 문서에 추가했다고 회신.
- **01-08 iOS 15/16 CTT 미표출**: 앱 담당이 iPhone 15/16에서 에어 CTT가 표출되지 않는다고 제보(전날 저녁부터 인식, 첨부 KakaoTalk 이미지 4장). 에어 개발 담당이 원인 파악 후 답변 약속, 곧 정상 표출 확인. 원인 추정: 전일 14시경 CTT 반영 작업이 파일에 제대로 반영되지 않았다가 당일 10시경 재작업으로 정상 반영 ^[inferred]. CTT 반영 작업 후 테스트는 최신 버전 에어로 진행 요청.
- **01-13 POI 입구점 오류**: 택배사 측에서 "우성씨티물류"로 길찾기 시 잘못된 위치로 탐색된다는 이슈가 인입(주소 "청북로 161-18"로 길찾기하면 정상). POI 입구점 확인을 POI 담당 팀장에게 요청했다. POI Plus 팀이 처리를 완료해 01-14 검색서버 반영(실서비스 적용 예정)이라 답했다. 첨부: 우성씨티물류.jpeg, 청북로161-18.jpeg.
- **01-17 2024-12 에어 데이터 통계 공유**: 월간 통계 시트 공유(링크는 제거). "12월 초부터 iOS 광고 미진행"이라는 주석. 사업 담당 답글: 3천원대 편의점 상품들은 1/2 기점으로 빠진 상태이며 1월 통계에서 확인 가능. 첨부 image.png.
- **01-18 iOS 메인 주변 인기장소 클릭 불가**: 사업 담당이 iOS 메인화면에서 주변 인기장소 클릭(길탐색 연결)이 안 된다고 제보(주유소 등은 정상). 에어 개발 담당: AOS는 정상, iOS 앱 이슈로 확인했고 패치 준비 중인 버전에 수정·적용. 사업 담당 추가 제보: 제보하기 메뉴에서 간헐적으로 제보 등록 시 앱이 비정상 종료되는 경우도 있음.
- **01-20** 채널 멤버 1명 퇴장.
- **01-22 앱 신규 버전 검증 완료(AOS 03.05.48 / iOS 03.05.25)**: 업데이트 내용은 아바티 황금티켓 적용, 전기차 할인율 변경, AA/CP 고속도로 팝업 적용, 안정성 개선. 당일 10시경 오픈(Android 85% 출시), 2~3일 모니터링 후 선택업데이트와 공지 등록을 요청하기로 했다. "AA/CP 고속도로 팝업"의 의미는 모바일에서 목적지를 고속도로로 설정하면 맞는지 확인하는 팝업이 뜨는데 AA/CP(안드로이드 오토/카플레이) 길찾기에는 적용돼 있지 않아 이번에 적용했다는 것이다(사업 담당 이해: 안드로이드 오토·카플레이에도 적용). AOS·iOS 모두 100% 출시 후 선택업데이트 요청. 사업 담당이 설 연휴 직전이라 선택 업데이트 시점을 걱정했고 당일 푸시가 있어 오후 늦게나 다음 날 아침에 걸겠다고 했다. 운영 담당이 선택업데이트 등록 완료(2025-01-24 답글).
- **01-24 쇼핑하기 판매 일시 중단 상품 공유**: (1) 가격 인상으로 일시 중단: 스타벅스 아이스 아메리카노 Tall, 버거킹 와퍼세트(2/3 인상 가격으로 재개 예정, 브랜드 사정에 따라 변동 가능). (2) 설 연휴 한정 일시 중단(해킹 예방 차원, 연휴 이후 재개): 올리브영 기프트카드, 배스킨라빈스 5천원권, GS칼텍스/홈플러스 상품권, 현대오일뱅크 모바일주유권.
- **01-24 차로 유도선 안내 개선 요청**: 안내 품질 담당이 고가 진입 구간 안내 이슈를 검토 요청했다. 2차로는 신호 안내를 받아 고가로 진입하는 차로, 3차로는 고가 진입 불가한 옆길 전용 차로인데, 에어는 우회전 안내만 있고 고가 진입 안내가 없어 초행자가 3차선으로 진입해 이탈·우회하는 사례가 있다. 바닥에 차로 유도선이 있으니 해당 링크에 유도선 데이터 추가 가능 여부 확인을 요청(첨부 image.png, 111.jpg, 222.jpg). 유도선 데이터 담당은 해당 지점이 현재 우회전 후 고가 안내를 하고 있고, 컬러유도선 안내는 (1) 우회전 후 고가 안내처럼 우회전하여 고가/옆길 진입하는 사람만 받아야 하는 안내, (2) DB 구축 시 직진해 고가 진입하는 사람도 유도선 안내를 받을 우려가 있는 유형은 자사 안내 사양상 서비스하지 못하는 것으로 알고 있다고 답했다. 안내 품질 담당이 "우회전 안내만 있다"는 설명을 "우회전 직후 고가 진입 안내"로 정정했고, 직진으로 고가에 진입하는 고객에게 잘못된 정보가 제공될 수 있어 엔진이 해당 지점 서비스가 가능해지면 데이터를 구축하겠다고 결론(우선 구축하지 않음). 두 가지 안내안 제시: (1) 진입·진출 모두 고려해 우회전 전 링크에서 우회전 후 고가 진입까지 인지해 안내, (2) 진출만 인지해 데이터에 입력된 마지막 컬러유도 차선만 안내.
- **01-31 쇼핑하기 상품 노출 재개 후 수정**: 괄호 문자 코드 표기 수정을 다시 요청(배스킨라빈스 5천원권, 올리브영 기프트카드 5천원권, GS칼텍스/홈플러스 겸용상품권 1만원권). 일부 상품은 가격 인상 이슈로 여전히 미노출이라 추후 추가 수정 예정. 서버 개발 담당이 수정 후 확인 요청, 배스킨라빈스 5천원권 재수정 요청 후 수정 완료.
- **01-31 배스킨라빈스 쿠폰 구매 오류**: 구매 시 응답이 `ERR12:EVENT_ID 값이 존재하지 않습니다.`로 구매 실패. 쿠폰 업체 측 확인 요청. 운영 담당이 수정 완료·재확인 요청, 인프라 담당은 이후 구매 요청이 없어 오류 발생 시 공유하겠다고 답했다.
- 01-31 채널 멤버 1명(에어 Agent 개발 담당) 입장.

## 2. 2025-02

- **02-06 에어 어드민 쇼핑하기 상품 삭제 기능 요청**: 어드민 앱관리-에어캐시상품에 상품 등록 기능만 있어 삭제 기능 추가를 요청했다. 접속 문제: 개발 어드민 접속이 안 돼 확인하니 http 사용을 하지 말라는 권고에 따라 https 주소로 변경됨(https로 접속하니 정상). 앱 담당이 삭제가 필요한 이유(우선 "미노출"만으로 대응이 안 되는 이유)를 문의했고, 운영 담당은 동일 상품이 여러 개 등록돼 있어 미노출→노출 변경 시 진행 중인 상품 구분이 어렵다(현재는 가격 인상으로 가격이 달라 구분되나 동일 가격이면 어려움)고 답했다. 당장 기능 추가가 어렵다면 필요 없는 상품 데이터를 완전 삭제하고 추후 기능 추가를 고려해 달라고 했고, 앱 담당은 필요성을 인지했으나 급건은 아니라며 서버 개발 담당에게 추가 일정 공유를 요청했다. 사업 담당은 최근 상품 변화가 많아 고려가 필요하다고 했다.
- **02-06 쇼핑하기 상품 노출 재개 수정**: 스타벅스 아이스아메리카노 Tall 괄호 표기 수정 요청 → 즉시 처리됐으나 코멘트를 안 남겼다며 수정 완료 회신.
- **02-06 설 연휴 보고서 통계 요청 및 회신**: 에어 운영 담당이 기간 1/24~2/2의 (1) 에어캐시 적립 유저수/적립량 (2) 에어캐시로 모바일 쿠폰을 구매한 유저수 (3) 연휴 4일 연속 적립 유저수를 요청. 서버 담당 회신(일자 / 유저수 / 적립량): 01-24 4,713 / 213,365; 01-25 4,148 / 179,501; 01-26 3,802 / 164,716; 01-27 3,572 / 170,506; 01-28 3,056 / 144,194; 01-29 3,438 / 175,086; 01-30 3,599 / 170,533; 01-31 4,150 / 192,349; 02-01 3,285 / 119,370; 02-02 3,529 / 145,668. 쿠폰 구매 유저수 110, 연휴 4일 연속 적립 유저수 320. (회신은 2025-02-13 확인)
