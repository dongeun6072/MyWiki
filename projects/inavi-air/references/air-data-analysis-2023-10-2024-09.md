# 에어 데이터 분석 2023.10~2024.09

"에어의 성장" 프로젝트(2024.10~)의 목표 설정 단계에서 만든 1년치 데이터 분석 페이지(2024-11-13 수정)를 거의 그대로 옮긴 문서다. 서버 추출 데이터를 보강한 후속 분석은 [[air-server-data-analysis-2023-11-2024-11]], 이 데이터를 바탕으로 한 목표 설정 회의는 [[air-growth-sprint-minutes-2024-q4]], 요약본은 [[air-growth-strategy-and-metrics-2024]], 캐시 설계 배경은 [[air-cash-reward-design-2023-2024]]를 본다.

## 데이터 기준
- 기간: 2023.10~2024.09 (항목마다 기간이 다르면 개별 표기)
- 출처: 구글 플레이스토어/애플 앱스토어, 에어 캠즈(CAMS)·어드민, 파이어베이스(GA 권한 부여 전), AIR 데이터 통계 현황(사업부 자료), 서버 추출 데이터(추출 전)
- 분석과 인사이트는 서버 데이터까지 확인 후 정리하기로 함
