# 에어의 성장: 앱테크 전략, 사용자 지표, 로그인 유도 실험 (2023~2024)

[[inavi-air]]를 "돈 버는 내비게이션"(앱테크 내비)으로 포지셔닝했지만 지표가 늘지 않아, 2024-10~12 "에어의 성장(AIR x Reboot)" 프로젝트로 데이터를 보고 가설을 세워 검증했다. 구성원은 개발, 기획, 디자인, 번역 담당 7명이다. 에어캐시 설계 자체는 [[air-cash-reward-design-2023-2024]]에 있다.

## 프로젝트 운영 방식

- 기간 2024-10~12. 1주 목표 설정 → 2주 문제 정의와 가설 수립 → 2~4주 핵심 기능 구현 → 2주 가설 검증과 회고. 주 1회 스크럼.
- 목표 후보: 신규 사용자 유입, 리텐션 개선, 광고 매출 증가. 문제 후보: 경쟁사 대비 USP 부족, 바이럴 기능 없음, ASO 미최적화, 사용 불편, 광고 피로, 앱 실행 유도 기능 부족, 광고 노출·전환율 낮음.

## 지표 (2023-10 ~ 2024-09, GA와 서버 데이터)

| 지표 | 값 |
|---|---|
| MAU / WAU / DAU | 2022-10~2023-09 18.1만 / 9.7만 / 3.4만 → 2023-10~2024-09 16.3만 / 8.8만 / 3.3만 (각각 -11%, -10%, -6%) |
| 캐시 적립자 | 일 평균 약 3,900명, 일 DAU의 약 12%. 캐시 적립률 30%(최근 3개월 32%) |
| 신규 설치 | 1년 13.8만 건(AOS 86%, iOS 14%), 일 평균 377건. 신규 설치자 중 SNS 가입 캐시를 적립하는 비율은 6% 안팎(745명 중 45명 등) |
| 스토어 전환율 | 구글 8%(검색 30%), 애플 10.8%(검색 27.3%). 검색어 "아이나비"는 전환 23.8%로 높음. "내비게이션" 계열 검색 순위는 구글 6~7위, 애플 4~5위 |
| 서버 기준 활성(1년) | YAU 76.7만, MAU 21.9만, WAU 13.1만, DAU 6.4만. 로그인 비율은 최근 1개월 27%. 로그인 사용자의 평균 사용 일수는 431일(200일 이상 58%), 남성 97%, 평균 49세(입력자 기준) |
| 캐시·쿠폰 | 로그인 사용자의 40%가 적립 경험이 있고 평균 89회 적립, 누적 평균 3,238원. 쿠폰 구매는 적립자의 8% |
| 코호트 리텐션 | 신규 사용자 1주차 33%, 2주차 25%, 4주차 19%. 고착도(DAU/MAU) 20% |

- 서버는 "과거 특정 기간" 활성 사용자를 뽑을 수 없고 현재 기준만 가능해서, GA와 어드민(Cams) 데이터를 같이 썼다. 세 곳의 수치가 서로 다르다는 점은 해명이 필요하다고 적혀 있다. ^[ambiguous]
- 상관 분석(ChatGPT로 수행한 것으로 적힘): 캐시 적립자가 10% 늘면 DAU는 약 4.5%, 광고 매출은 약 6.6% 늘고, DAU가 10% 늘면 광고 매출은 약 11.2% 늘 것으로 추정했다. 캐시 적립자와 DAU의 상관계수는 약 0.67.

## PRD 두 개

- **PRD v1**: 문제는 "앱테크 내비로 포지셔닝했는데 활성 사용자가 전년 대비 11% 감소". 목표는 주행 외 미션으로 캐시 적립자를 늘리는 것. 타겟은 앱테크에 관심 있는 4050과 경쟁사 내비 사용자. SWOT에서 강점은 국내 유일 앱테크 내비와 충성 사용자, 약점은 모바일 내비 6개사 중 활성 사용자 6위와 리워드 한도(일 50원, 월 1,500원)다. 마케팅 제안은 슬로건 "돈 버는 네비게이션", 신규 가입과 추천인 캠페인, 인플루언서·SNS·플랫폼·커뮤니티 매체.
- **PRD v2**: 범위를 신규 사용자로 좁혔다. 지표는 "신규 캐시 적립률 = 당일 신규 사용자 중 당일 캐시를 적립한 사용자 / 신규 사용자". 기존 사용자는 캐시를 적립하지 않아도 월 35회 앱을 열기 때문에 신규 대상 미션(웰컴 미션)이 더 효과적이라고 판단했다.

## 가설 수립과 검증

- **Phase 1(기존 사용자 DAU)**: 4050 남성은 앱테크에 관심이 적고 SNS 로그인 비율이 낮다(9월 신규의 회원가입 6%, 푸시는 매일 약 4천명 발송에 400명 오픈). 선물하기·응원하기, 자동차 키우기, 하이파이브, 지도에 캐시 뿌리기, 첫 실행 시 SNS 로그인 필수, CRM 푸시 시나리오 등이 제안됐다.
- **Phase 2(타겟 재정의)**: 여성 사용자의 캐시 페이지 전환율이 남성보다 21% 높아 4050 여성, 운전자, 가성비 소비자를 타겟으로 했다. 가설은 ASO 최적화, SNS 가입 허들 낮추기(첫 로그인 시 500캐시), CRM 푸시, 친구 초대(신규 획득 광고비 인당 183원 참고), 리뷰 작성 캐시, 할증 시간대, 상품군 추가, 게이미피케이션이다. 간접 경쟁사는 다른 앱테크 앱(캐시워크, 발로소득 등)으로 봤다.
- **미션 아이디에이션(2024-12-02)**: 웰컴 미션, 캐시 복권, 챌린지, 캐시 소진 아이디어(행운뽑기, 광고 안 보기) 등. 신규 사용자의 에어캐시 페이지 조회는 월 4회로 기존 사용자 48회의 1/10이라는 점이 근거였다.
- **레퍼럴 아이디어**: 개발 없이 수요를 보려고 노션 페이지 링크를 푸시로 보내 '공유하기' 클릭 수를 보는 방법을 검토했다.

### 로그인 유도 실험 결과 (2024-12-20)

가설은 "로그인하지 않은 사용자가 혜택에 계속 노출되면 로그인한다"였다. 행동 목록은 로그인 혜택 만료 푸시(24시간 내 로그인 시 캐시), 메인 로그인 버튼 상시 노출, 캐시 버튼 툴팁, 로그인 페이지 문구 강화였다.

| 지표 | 결과 |
|---|---|
| 활성 사용자의 로그인 비율 +5% | **실패**. 30% → 29%로 오히려 1%p 감소 |
| 신규 사용자의 SNS 로그인 비율 증가 | **실패**. 1주차 +2.8% 후 2주차 -1.4% |
| 기존 사용자의 SNS 로그인 증가 | **성공**. GA 기준 SNS 가입 완료 사용자 +13.2% (기존 로그인 안 한 사용자의 가입 완료 조회 +28.5%) |

관련 앱 변경은 2024-12 패치(로그인 유도 1~3차 리소스 배포, "에어캐시가 소멸되고 있어요" 푸시 문구)에 있다 → [[air-service-stability-release-notes-2023-2026]].

## 경쟁 서비스 조사 (2024-11)

- **티맵**: 종합 모빌리티 플랫폼으로 전환(대중교통, 렌터카, 대리운전). 저탄소 길안내, 다음 여행지 추천. 메인 화면 개편과 안전운전 자동 실행 제거로 불만이 많았지만 MAU는 늘었다.
- **카카오내비**: 전체 경로바와 다양한 TBT 테마, "잘보이기 모드", 개인 맞춤 길안내(이전에 간 길), 월별 운전 챌린지. MAU는 감소 추세.
- **네이버 지도**: 내비, 대중교통, 예약을 합친 슈퍼앱. 경고음 분리와 기준 사용자화.
- **아틀란**: 수입차 내비 장착, 차로 정보를 상단에 두는 UI.
- 에어에 주는 시사점: 앱 실행 후 안전운전 자동 실행은 시도할 만하다, 경고음 기준 설정 검토, 에어는 차로 정보가 타사보다 친절하다는 장점이 있다, 월별 챌린지는 캐시 룰렛과 비슷한 경험이라 로그인 유도에 쓸 수 있다.
- 앱테크 시장 조사: 앱테크 사용자는 여성이 많고 40~50대가 큰 비중, 리워드 광고 참여자는 2023년 약 1,700만 명, 만보기형·미션형·금융형으로 나뉜다.

## 에어 퀴즈 결과 (2023-11-13~30, 약 3주)

메인 화면의 O/X 퀴즈 카드로 에어캐시 인식과 미적립 이유를 조사했다.
- 에어가 리워드 앱이라는 이미지는 잘 전달됐다(97%).
- 에어캐시를 안다는 응답은 로그인 사용자 65~70%, 미로그인 20~25%. 미적립 이유는 "리워드에 관심 없음" 55%.
- 50km에 50캐시라는 적립량에 긍정 반응 85%. 적립하는 사용자는 목적지 도착 후 직접 적립이 78~80%로 능동적이다.
- 참고(MDN 기준): 전체 사용자 40.7만 명 중 로그인 13.1만, 비로그인 27.6만.
- 고도화 필요: 퀴즈 참여 시 보상 연동, 로그 연동으로 정확한 분석, 미로그인 사용자의 로그인 유도, 로그인 사용성 개선.

## 스토어 리뷰 검토 (2022-10 ~ 2024-12 리뷰)

중복 의견 순위: 카메라 경고음 사용자화(5건 이상, 속도 10% 초과 시 경고음), 음성 인식, 뷰모드 오조작, 안내 볼륨, 안전운전 모드 개선과 자동 실행, 로그인 개선(멀티 로그인, 번호 입력, 로그인 풀림), 문의하기 채널, TTS 품질. 즐겨찾기(내 장소) 사용성, 검색 추천어, 경로 탐색 옵션 사용자화, 백그라운드 배터리, iOS 노치 잘림은 개선 완료로 표시됐다.

## 원내비 서비스 종료 대응 계획

경쟁사 원내비의 종료(2025년)에 맞춰 신규 사용자를 끌어오는 계획이다. 앱스토어 광고(구글 일 3만 원, 애플 일 11달러 수준, 키워드 추가 검토)와 보도자료 배포가 액션 아이템이다. 원내비 사용자는 MAU 55만 명, 4050이 64%, 단독 사용은 18.7%다. 원내비 강점(직관적 UI, KT 데이터 무료, 주차장 정보, 편한길, 같이가자)에 에어의 셀링 포인트(유사한 UI, 사용 데이터만큼 캐시 적립, 그룹 주행)를 대응시켰다.
