# 2022년 업무 메일 개요 (받은편지함 정리)

[[이동은]]의 2022년 Outlook 받은편지함(2022-03-16 ~ 12-31)에서 인증·알림·Slack·Notion·Jira와 경영지원 공지를 뺀 업무 메일을 모은 파일(약 9,800줄, 약 200통)이다. 입사 직후인 2022-03 온보딩부터 같은 해 12월까지의 업무가 담겨 있다. 같은 시기 업무 실적은 [[inavi-air-feature-history]]에 있다. **이 위키에는 사람 이름, 연락처, 서버 IP, 공유 폴더·단말 계정 정보를 옮기지 않았다.** 메일에는 그런 값이 평문으로 많이 들어 있다.

## 서버 운영 공지의 규칙

탐색 서버, 검색 엔진, AGENT 서버 작업은 모두 **작업 공지 → 완료 회신** 형식이다. 공지 항목: 목적, 대상 서버, 작업 일시, 작업 내용, 서비스 중단 시간, 작업자.

| 공지 | 내용 |
|---|---|
| `[AIR3/Hybrid]`, `[BM]`, `[AIR3/MapsAPI]` 탐색 서버 작업 | 탐색 서버 재기동, "통제 적용" 등. 보통 자정 전후 20분, 서비스 중단 없음. 2022-03~09월에 수시 |
| **SIRE 검색엔진 패치** `[Hybrid]` | 격주 수요일 14:00~14:30. **통합검색(YR), 추천어(Proposer), 오타보정(TCE)** 인덱스를 패치하고 재기동 시 서비스 순단 |
| 검색엔진 데이터 패치 `[AIR3/Hybrid/MapsAPI]` | 월 1회 수요일. Reverse Geo-Coding 데이터. 클라우드와 센터 서버 각 2대 |
| `[AIR3] AGENT 패치` | 에어용 AGENT 서버 패치(5~7월에 잦음) |
| PND X1 MR 버전 | 매월(22.03a, 22.05a, 22.07a, 22.09a, 22.11a) 비통신형 지도·탐색엔진을 상용 장비에 적용했다고 알리는 메일. 탐색 포트가 버전별로 나뉜다(예: 22.03a → 30014, 22.05a → 30013) |
| 실시간 교통정보 서버, 에어 CAMS 서버 | 작업 공지 |
| 대구 신호등 | 전체 DB를 AGENT가 1시간마다 현행화 |

**서비스 이름 대응**: AIR3는 [[inavi-air]]의 서버 구성(`serviceType=AIR3`), Hybrid는 [[inavi-hybrid-navi]], MapsAPI는 외부 지도 API, BM은 별도 서비스다. 같은 검색·탐색 서버를 세 서비스가 공유해서 공지 제목에 세 이름이 함께 나온다. ^[inferred]

PND X1 MR의 "MR"은 [[inavi-mr-format-spec]]의 MR 지도 데이터 버전이다. 탐색엔진이 월 단위 MR 버전으로 갱신된다는 뜻으로 읽힌다. ^[inferred]

## 아이나비 에어 스크럼

2022-07-05부터 **매주 화요일(가끔 수·목) 정기 스크럼** 회의 초대가 이어진다(12월 27일까지). 메일 본문은 모임 요청뿐이라 안건은 없다. 같은 시기 에어 업무(HUD 연동, 에어캐시 리뉴얼, 신호등 안내)는 [[inavi-air-feature-history]]에 있다.

## BMW ACE3.0 릴리즈 공지(참조 수신)

SW개발본부가 `[BMW] ACE3.0` 계열 펌웨어를 **차수 단위**로 릴리즈하는 공지다. `ACE3.0 PRO`는 27차(v1.06.01, 04-01) → 38차(v1.16.00, 11-24), `ACE3.0`(S)은 33차(v1.13.01, 04-01) → 40차(v1.19.00, 11-03)까지 약 1~2주 간격이다. 해외향 제품이고 이 팀의 업무는 아니며 참조로 받은 것으로 보인다. ^[inferred] 릴리즈 노트는 별도 첨부이고 접속 정보는 적지 않았다.

## 인프라 공지

- SK-IDC 서버 HDD 장애(06-02): 500G 1개 교체는 발주 필요, 노후 서버는 여유 부품 교체. 교체 전에는 I/O가 큰 작업을 피할 것
- PND 비통신형 지도 발행용 서버 일시 정지(03-24, 하드 교체)와 PC 교체(07-22)
- 05월 IPS/WAF 탐지 내역(06-23): IPS는 사내 연동과 외부 정상 연동이라 차단 금지, WAF는 외부 침입이라 차단 유지
- **서초 IDC 메인 DNS 서버 교체**(12-04 일요일 08:00): 1분 정도 순단, 메인 DNS를 쓰는 서버는 **2차 DNS를 필히 입력**
- **본사 건물 정전 대비 서버 전원 OFF**(12-04 06:30~08:00): 12-02 퇴근 전까지 전산실 서버를 끄고, 끄지 않은 장비는 강제 종료 후 부팅하지 않음
- Tlink 라이브 검색 AGENT IP 교체(12-06, 12-07)
- 앱 계정 이관: 구글 플레이 개발자 계정 소유자 정보가 없어 앱 이관(iVolt)이 막힌 건(08-10). 계정 소유자·관리자를 기록해 두지 않으면 이관이 어렵다는 사례다.

## 이 파일로 알 수 있는 업무 흐름

1. 2022-03 온보딩(GPX 산책 코스 앱) → 05월부터 MXI 안내엔진·설정 기능(과속 알림, 데이터 절약) → 06월 현장 대응 → 07월 에어 업무 시작 → 9월 대구 신호등 → 10~11월 MXI 핫패치와 에어캐시
2. 외부 고객 단말(MXI, 아트뷰, 유브릿지) 장애 대응이 절반 이상을 차지했다.
