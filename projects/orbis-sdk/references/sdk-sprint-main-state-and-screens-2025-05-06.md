# 신 NaviSDK 스프린트 상세: 메인상태관리 & 화면구성 #1~#3 (2025-05-12~06-04)

2025년 5월 중순~6월 초의 스프린트 3회다. 목표는 메인 상태 관리, 화면별 GUI 구성(주행 컴포넌트 포함), 초기 지도 다운로드이며, 5/21까지 IPO 실사 대응용 구동 산출물을 준비하는 공통 과제가 걸려 있다. 앞 구간 [[sdk-sprint-engine-api-integration-2025-03-05]], 이후 현황 보드와 2026년 스크럼은 [[sdk-development-progress-board-and-2026-scrums]], 허브 [[sdk-sprints-2024-2025-hub]].

## [5/12] 메인상태관리 & 화면구성 #1 - 플래닝/리뷰 (5/12/2025)

- 스프린트 목표: 메인상태 관리, 화면별 GUI 구성(주행 컴포넌트 구성), 초기 다운로드
- 기간: 2025-05-12 ~ 2025-05-19 (완료/이관 비어 있음)
- 차기 스프린트 기간: 2025-05-19 ~ 2025-05-26
- 요청 사항: 지도, 탐색, 검색 (항목만 있음)

## [5/14] 메인상태관리 & 화면구성 #1 - 스크럼

- 목표: 메인상태 관리, 화면별 GUI 구성, 초기 지도 다운로드
- 공통(~5/21): IPO 실사 관련, Orbis map Navi SDK 진행 관련 설명 및 실사 대응. 산출물은 디자인 포함 workflow와 UI 일부가 포함된 구동 형태.
- 앱 개발자 1: 안내, 메인 상태 관리 정리
- 앱 개발자 2: 하단 뷰
- [[이동은]]: 지도 컴포넌트, 초기 지도 다운로드
- 디자이너: 앱 아이콘/주행/검색 화면 디자인, 집/자주 가는 곳/즐겨찾기/최근 목적지 specout(최근 검색어 유지는 샘플앱에서 개발), 메인 화면 하단바 specout(개발 진행 후 Hidden 처리)
- 번역 담당: 번역 스크립트(한국어/영문 병행, 개발자 검토), 앱 이름 명명

## [5/19] 메인상태관리 & 화면구성 #2 - 플래닝/리뷰

- 스프린트 목표: #1과 동일(페이지 상단 날짜는 5/12로 남아 있음, 복사 흔적) ^[inferred]
- 기간: 2025-05-19 ~ 2025-05-26 (완료/이관 비어 있음)
- 차기 스프린트 기간: 2025-05-26 ~ 2025-06-02
- 요청 사항: 지도, 탐색, 검색 (항목만 있음)

## [5/21] 메인상태관리 & 화면구성 #2 - 스크럼

- 목표: 메인상태 관리, 화면별 GUI 구성, 초기 지도 다운로드
- 공통(~5/21)
  - IPO 실사 대응(구동 산출물)
  - 톰톰 미팅: Workflow, 주요 화면 가이드
  - ppt 1~2장: Workflow 1장, 주요 화면 가이드 1장
- 표: 앱 개발자 2 완료 링크 2/진행 링크 1, [[이동은]] 완료 링크 2/진행 링크 1, 디자이너 진행 링크 2

| 담당 | 완료 | 진행/남은 항목 |
|---|---|---|
| 앱 개발자 1 | 안내(TBT, 경로선 차기/차차기 유도선 표출), 메인 상태 관리 정리 | 경로선 지난 거리 색상 표출 검토(톰톰 자동 on/off vs 자체 % 세팅), 안전운행 API 적용 |
| 앱 개발자 2 | 하단 뷰 | 현위치 로직(Position Manager), 하단뷰 기능 추가 |
| [[이동은]] | 지도 컴포넌트, 초기 지도 다운로드(현재 Android OutputStream으로 다운로드, Ktor/OKIO 검토 필요) | 지도 OrbisMap Style 적용(지도 2개를 띄우고 뒤로가기 시 ANR 발생), 톰톰 지도 캐싱 정책 검토(톰톰 지도 렌더링 속도 문제), TTS 발성 로직 |
| 디자이너 | 앱 아이콘/주행/검색 화면 디자인, 집/자주 가는 곳/즐겨찾기/최근 목적지 specout, 메인 화면 하단바 specout | 경로선, 자차 아이콘 |
| 번역 담당 | 번역 스크립트(한국어/영문), 앱 이름 명명 | 번역본 검수, 음성 발성 조합 |

세부:
- 앱 이름 후보: U-map(you, universal), JellyGO, spongeMap
- 번역본 검수: "단위" 추가, "AM/PM" 확인, m/km/AM/PM 사양 확인(화면별, 기능별)
- 음성 발성 조합: 리스트업. 1은 한국어, 2는 영어, 3은 간체/번체.
