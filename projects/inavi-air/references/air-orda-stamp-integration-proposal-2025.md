# 아이나비 스탬프-오르다 x 에어 서비스 연계 방안 (2025)

이미지형 PDF(6쪽)라 슬라이드를 직접 보고 정리했다. 오르다는 2025년 출시된 여행·관광 특화 아웃도어 플랫폼(여행지 인증, 미션, 보상), 에어는 2012년 출시된 모바일 내비게이션으로 소개된다. 서버의 `/orda/stamp` API와 등산로 지도 레이어는 [[inavi-air-map-style-upgrade-2022]], [[inavi-air-api-detail-spec]] 참고.

## 핵심 메시지

"운전 주행 중에도 여행 콘텐츠를 놓치지 않고, 여행 중에도 내비게이션을 자연스럽게 쓰게 한다." 양쪽의 사용자 유입과 이용 증가를 서로 끌어올리는 구도다.

## 제안 항목

| 영역 | 내용 |
|---|---|
| 에어 사용자 -> 오르다 유입 | 주행 경로 위 또는 목적지 부근에 다다르면 오르다의 관광지와 스탬프 정보를 실시간 시각화(운전 방해 최소화) |
| 오르다 사용자 -> 에어 이용 | 오르다에서 스탬프 투어 코스의 스탬프를 고르면 해당 위치까지 **앱 간 연동(App to App)** 으로 에어 길안내를 바로 시작 |
| 상호 보상(리워드) | 관광지 스탬프 인증 시 에어 캐시 추가 적립(예: 1km당 1캐시를 2캐시로), 일정 거리 이상 주행 시 오르다 스탬프 획득 포인트 추가 적립 |
| 기록 자동화와 공유 | 오르다의 투어 기록 보기와 에어의 주행 기록(GPS 기반 주행선 + 스탬프 획득 위치)을 지도에 합쳐 복원, SNS 포스팅 |
| 신규 사용자 확보 | 에어와 하이핀 등 자사 서비스에서 팝업·네이티브 배너로 오르다 설치 유도 |
| 지도 연계 | 에어 지도 SDK를 쓰는 모든 서비스에서 진행 중인 스탬프 투어 위치를 주기(POI)로 표현. 이를 위해 에어 POI 데이터와 오르다 스탬프 투어 리스트의 **데이터 관계(Relation)** 가 필요(출발·목적지 경로 안내 고려) |
| 기술 차별화 | 다양한 스타일의 지도와 Multi-Modal 경로 탐색·안내 기술 |

## 해석

- 에어의 캐시 정책([[air-cash-reward-design-2023-2024]])과 스탬프 보상을 묶는 안이라, 캐시 적립 규칙이 바뀌면 연계 보상 조건도 영향을 받는다. ^[inferred]
- 구현 일정, 담당, 결정 사항은 문서에 없다. 제안 단계다. ^[ambiguous]
