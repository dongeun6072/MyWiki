# 에어캐시 적립 사용성 개선 방안 협의와 스크럼 (2023-05)

2023년 5월 에어캐시의 "00시 기준 주행캐시 초기화" 문제를 풀기 위해 스탬프형 적립과 유효기간을 도입하기로 한 협의 문서와, 이를 구현한 캐시 적립 스크럼 회의 #1~#2 기록이다. 정책의 요약은 [[air-cash-reward-design-2023-2024]]에 있고, 구현 결과(스토어 문구, 리소스)는 [[air-cash-stamp-release-2023]]에 정리했다. 전체 목차는 [[air-feature-planning-hub]].

## 1. 협의 문서 (마지막 수정 2023-05-17)

### 에어캐시 사용성 이슈
- 00시 기준으로 주행캐시 적립이 초기화되어, 주행을 했어도 캐시를 쌓지 못하는 케이스가 발생한다.

### 사용성 개선 방안
- 캐시 적립 유효기간 도입
  - 스탬프 형태로 유효기간 내 캐시를 적립할 수 있도록 제공한다.
- 한 달에 9일 이상 적립 시 추가 캐시를 지급한다.

### 협의 필요 항목 (초안 값)
| 항목 | 초안 값 | 추가 의견 |
|---|---|---|
| 캐시 유효기간 범위 | 1일 | 에어캐시 유효기간 3일보다 짧은 기간으로 오픈하고 늘려가는 방식으로 했으면 함 |
| 랜덤 캐시 지급 적립 횟수 | 9일 | - |
| 랜덤 캐시 지급 범위 | 20 ~ 50캐시 | - |
| 스탬프 표출 시점 | 익일 스탬프 표출 | - |
| 당일 분할 적립 사용자 스탬프 정책 | 정비 필요 | 예: 15 + 35, 2회 적립하는 경우 당일 스탬프 처리는? |

### 사업팀 의견
| 항목 | 사업팀 의견 |
|---|---|
| 캐시 유효기간 범위 (예: 3일) | 2일(개시지급일 + 1일). 매일 방문을 원하기에 사업에서도 3일은 좀 길지 않을까 함 |
| 랜덤 캐시를 지급할 적립 횟수 (예: 9번) | 9회, 10회차에 보너스 지급. GUI 상으로도 3x3이 적절하지 않을까 함 |
| 랜덤 캐시 범위 (예: 20 ~ 50캐시) | 매월 9회 이상 주행임을 감안했을 때 300 확률은 줄이더라도 50~300(룰렛: 50, 100, 300) 캐시 지급으로 의견 |

### 회의록 (결정 사항)
- 미적립 캐시 유효기간: 당일 제외 1일
- 랜덤 캐시 지급 횟수: 9회
  - 18회 주행 시 랜덤캐시 2회 수령 가능
  - 27회 주행 시 랜덤캐시 3회 수령 가능
- 랜덤 캐시 지급 캐시 범위
  - 사업 의견: 룰렛인 경우 50 ~ 1000, 꽝은 없고 50의 비중이 가장 높음
  - 팝업인 경우 고정 50캐시
- 서비스 이후 상황을 보면서 처리할 항목
  - 매달 초기화
  - 9회 초기화: 2회 주행하는 경우
- 열린 질문: 비즈보드 기타 화면 추가 시 재심사가 필요한지
