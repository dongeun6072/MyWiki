# Slack #10_prj-inaviair 대화 (2022)

아이나비 에어 프로젝트 협업 공개 채널(2022-07-20 개설, 채널 설명 "아이나비 에어 프로젝트 협업 채널")의 2022-07-01~12-31 구간 기록이다. 비공개 채널 기록은 [[air-channel-slack-2022]], 개발자 채널은 [[air-nsdk-dev-slack-2022]], 프로젝트 개요는 [[inavi-air]], 이듬해 버전 정리는 [[air-app-version-notes-2023]]을 본다.

이 구간에는 채널 최초 메시지(2022-07-20 00:16)부터 마지막 메시지(2022-12-29 10:10)까지 메시지 136건과 스레드 답글 537건을 읽었다. 답글이 달린 스레드는 모두 열어 읽었다. 사람 이름은 역할(기획 PM, 사업팀 담당, 사업 임원, 서버 담당, Agent 담당, 앱 담당, 탐색엔진 담당, 검색엔진 담당 등)로 썼고, 호스트·IP·계정·링크·단말 번호는 기록하지 않았다. 각 월 안의 항목은 주제별로 묶었으며 날짜가 정확히 일자순이지는 않다. 첨부 파일은 이름·종류만 적었다(내용 미열람).

- 10/18 신규 검색엔진 전환(검색 품질 이슈와 장애 대응), 10월 말 대구 신호등 연동 후 11/1 시범 제공(AOS v03.05.14 / iOS v03.04.12).
- 9~12월 과속 효과음 개선과 선택 옵션, 온에어(음성 오디오 광고) PoC·시나리오, 12/21 리뉴얼(경로선택·환경설정·에어 연구소) 베타와 추천/대안 경로 정책 조정.
- 앱 배포 이력: AOS 03.05.10/11/12/13/14/15/16/17, iOS 03.04.08/09/10/11/12/13/14/15(세부는 각 월 항목).

## 7월 (7/20~7/31)

- **2022-07-27** 사업 임원이 아이나비 에어에 걸려 있는 삼성화재 배너의 하루 클릭 수와 상품권 받기, 실제 자동차 정보 등록까지 퍼널 분석이 가능한지 문의(자동차 보험 광고 콘텐츠가 가입자 대비 효과가 있는지 확인하려는 목적, 스레드 3건 08-08까지). 같은 날 임원이 기획 PM에게 카울리 담당자와 관련 자료를 메일로 보냈다고 공유(스레드 1건), 전날 저녁엔 "카울리 담당자 내일 오전에 찾아서 보내 줄게. 지금 휴대폰에서는 찾기가 어렵네"라고 언급.
- **2022-07-28** 임원이 딜로(Dilo)에서 제공한 오디오 광고 샘플을 보니, 고객의 오디오광고 수신 동의부터 주행 중 오디오 광고 송출 전 고객 노티·광고 송출에 대해 꼼꼼한 기획 및 UX가 필요해 보인다고 언급(고객이 동의했어도 주행 중 갑자기 오디오 광고가 나오면 당황하거나 불쾌할 수 있어 이를 최소화하고 그 이상의 혜택을 얻는다는 것을 경험할 수 있도록).
- **2022-07-28** 앱 담당이 사업팀 담당에게: 8/3(수) 패치에 메인카드 GUI가 변경되므로 일반공지 이미지도 교체가 필요하다며 8월 3일부터 첨부한 이미지로 공지가 나가도록 이미지 교체 요청(스레드 1건; 이미지 3건 첨부).
- **2022-07-28** 사업팀 담당이 쇼핑하기 쿠폰 업체(즐거운) 측 문의 공유: 에어에서 쿠폰 구매 후 발송되는 문자는 공유해 준 발송 제목·문구 외 업체 측에서 설정한다고 하며, 현재 쿠폰 문구에 업체 측이 설정하는 문구("본 쿠폰은 B2B용 모바일쿠폰으로, 유효기간 연장 및 환불대상이 아닙니다.")가 빠져 있어 우리 쪽에서 설정한 부분이 있는지 확인 요청(스레드 6건, 07-29까지).
- **2022-07-26** 앱 담당이 에어 콘솔 로그에 광고 영역 관련 경고성 로그가 표출되고 있다며 SKP 쪽에 문제 여부 확인 문의(스레드 18건, 08-18까지): [iOS/Android] "Full screen native media view size has been detected to be 134x70 ... too small", "Partial screen native media view size seems to be too small ... media views slots that have a width or height smaller than 120x120 will be demonetized in the future". (답변 내용은 09-23 스레드 참고: 구글에서도 언제 수익화 제한을 할지는 정해지지 않았다고 전달받음.)
- **2022-07-26** 서버 담당이 에어 iOS 확인 중 삼성화재 견적 이벤트 배너가 정상 출력되지 않아 ADMIN을 확인한 결과 배너 이미지는 등록돼 있으나 배너 확장자가 jpg이고 기존 배너 이미지는 png로 확인된다며 확인 요청(스레드 6건, 같은 날까지).

- **(07-26 광고 영역 경고 로그 스레드 상세, 08-18까지)** 사업팀 담당이 SKP 측에 문의한 결과 "네이티브 동영상 광고의 미디어뷰는 최소 120x120dp를 충족해야 한다"는 구글 가이드를 전달. 앱 담당: 모든 디자인을 가이드에 맞춰 바꿀 수는 없으므로 (1) 모든 Native 광고에서 동영상 광고는 노출되지 않게 설정해 이미지 광고만 노출, (2) 앱종료/경로취소 인벤토리는 제외하는 방안으로 진행하겠다고 제안. 사업팀 담당이 설정을 완료했으나 테스트 결과 Native 이미지광고에서도 같은 경고 로그가 발생해 앱 담당이 요청: (1) 경로취소/앱종료 인벤토리를 제외한 모든 인벤토리는 배너 광고만 노출되도록, (2) Native 미디어 광고를 bar 형태로 진행하는 앱이 있는지 확인(광고 가이드 준수 여부 확인), (3) 미디어 광고를 제외한 상태의 수익률 변경 확인(7월 26일과 8월 4일 수익률 비교). 사업팀 담당: 배너 광고만 노출되도록 설정, 최소 120x120dp 충족이 필요하며 가이드에 맞는 미디어뷰 디자인이 필요, 8월 4일 광고 수익 확인 후 안내. 앱 담당 테스트: 경로취소/앱종료 인벤토리에서는 Native 광고에도 경고 로그가 발생하지 않아 문제없음. 사업팀 담당: 경로취소/앱종료 외 인벤토리에 이미지 광고 노출로 설정했으나 광고 수익이 잡히지 않아 미디어 광고로 재설정, 8/12 이후 경고성 로그가 다시 확인되면 전달 요청. 앱 담당이 미디어 광고로 표출되어 경고성 로그가 다시 발생(예: 124.5x70 감지)한다며 SKP 추가 확인 요청 → SKP가 구글에 확인한 결과: (1) 해당 경고성 로그는 수익에 지장이 있을 수도 있다는 경고이며 구글 측에서 추가 확인 중, (2) SKP 내부에서도 동일한 경고성 로그가 확인되어 SKP 측에서도 확인 예정 — 현재 확인되는 경로성 로그는 무시해도 될 것 같다고 안내. 앱 담당: 구글/SKP 답변을 받아봐야 이후 노출광고 디자인을 결정할 수 있고 배너만 표출했을 때 수익이 잡히지 않는 이유 확인이 가능한지 요청.
