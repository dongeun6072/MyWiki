
네트워크 실행 커맨드

순서는 다음과 같음 
1. 네트워크 설정
2. 시간 설정
3. 앱 실행 (이때 유효한 UUID인지 확인 필요)


[네트워크 설정]
1. Linux 환경에서 /etc/lxc/lcp 폴더로 이동
2. mount -o remount,rw /  (읽기, 쓰기 모드로 마운트)
3. mv lcp_eur_net_config lcp_eur_net_config_back 
4. mv lcp_default_net_config lcp_eur_net_config 
5. reboot -f


[시간 설정]
- `date MMDDhhmm[[CC]YY][.ss]`
- e.g. date 12100203.01


[ANA 앱 실행]
1. 최신 APK 다운 (ANA, VilTest)
2. Android 환경에서 APK 설치 
3. am start -S -n com.tomtom.automotive.integration.vehicle.testApp/.VehicleIntegrationTestActivity 
4. cp /data/token.json /data/media/10/Android/data/com.tomtom.automotive.integration.vehicle.testApp/files/token.json
5. token.json 권한 변경해주기 (chmod 777 token.json)'
