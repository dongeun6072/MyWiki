# MXI 현장 장애 대응 이력 (2022)

MXI 단말(서울시설공단, 순천, 경주, 하남 등)에서 2022년 6~11월에 올라온 장애를 정리했다. 제품군은 [[inavi-hybrid-navi]]이고, 배포와 OTA는 [[mxi-where-release-ota-2022]]다. 담당자 이름은 적지 않았다. [[이동은]]은 현장 방문(6월 7일)과 로그 분석, 발행 정보 전달에 참여했다.

## 패턴

1. **앱 전환(FG/BG) 타이밍**이 흑화, 뷰모드, 느린 표시의 공통 배경이다. 콜앱이 수시로 FG로 올라오는 사용 형태가 다른 단말에서 안 보이던 문제를 드러냈다. 팅크웨어도 "MXI를 제외한 Where 제품에서는 2년 이상 흑화가 접수되지 않았다"고 확인했다. ([[map-black-screen-lifecycle]])
2. **저장소 고갈**과 **파일시스템 점검(fsck)**: 소규모 데이터 누적이 재부팅과 시스템 UI 오류로 이어졌고, 펌웨어에서 해결했다.
3. **GPS 값이 null인 순간**을 앱이 다루지 못해 생기는 NPE가 반복됐다(콜앱, Where 모두).
4. 현장 재현이 어려워 **로그 자동 저장 타임락 빌드**를 만들어 배포했다.
