# 에어 기능별 기획/수정 이력 허브

Confluence "아이나비 에어 & NSDK" 스페이스의 에어 앱 기능별 페이지(기획서 수정 이력, 스토어 문구, 리소스 배포 표, 기능별 스크럼)를 기능 단위로 나눠 상세하게 옮긴 페이지들의 목차다. 요약 수준의 기존 문서는 [[air-cash-reward-design-2023-2024]], [[air-service-stability-release-notes-2023-2026]], [[air-confluence-scrum-and-voice-2023-2024]], [[inavi-air-feature-history]]를 본다.

## 페이지 목록
- [[air-cash-accrual-policy-discussion-2023]] — 에어캐시 적립 초기화 문제, 스탬프·유효기간 협의안, 사업팀 의견, 회의록, 캐시 적립 스크럼 #1~#2
- [[air-cash-stamp-release-2023]] — 스탬프 출시 스토어 문구(AOS 03.05.27 / iOS 03.05.04), 리소스 배포 표, 적립 고도화 GUI 반영
- [[air-cash-advancement-planning-history-2023]] — 에어캐시 고도화 기획서 버전 이력, 메인 에어캐시(하단 바·툴팁), 2025-12 UI 개선 문구
- [[air-cash-welcome-mission-table-2024]] — 신규 사용자 2주 웰컴 미션 42개 전체 표
- [[air-point-home-new-cash-button-2023-2024]] — w3w+캐시버튼 출시 문구, 포인트홈(뉴캐시버튼) 스크럼 #1~#5
- [[air-my-places-renewal-2023]] — 내 장소 리뉴얼, 정식 오픈 문구, 내장소 개선/에어 사용자 분석 스크럼 #1~#7
- [[air-lab-and-report-renewal-2023]] — 제보하기 ver.2 수정 내역, 에어 연구소 리뉴얼, 스크럼 #1~#4
- [[air-small-features-and-notices-2023-2025]] — w3w 시나리오, AI 횡단보도, 후면 단속 카메라, 홍수 경보, 음성 변경, 황금티켓 등

## 의도적으로 뺀 항목
- 스크럼 참석자 이름과 임원 이름은 역할로만 표기했다.
- 리소스 배포 표의 날짜 칸은 원본에 링크로만 있어 날짜가 없다.
- 피그마/문서 공유 링크는 `<링크 생략>` 처리했다.
