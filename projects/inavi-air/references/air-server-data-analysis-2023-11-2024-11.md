# 에어 서버 데이터 분석 2023.11~2024.11

GA/캠즈로는 볼 수 없던 "로그인 사용자" 중심의 누적 지표를 서버에서 추출해 정리한 페이지(2024-11-12 수정)다. 일별 상관분석 표는 [[air-server-data-correlation-analysis-2024-09]]로 분리했다. 앞선 1년 분석은 [[air-data-analysis-2023-10-2024-09]], 이후 목표 설정 회의는 [[air-growth-sprint-minutes-2024-q4]], 요약본은 [[air-growth-strategy-and-metrics-2024]]를 본다.

## 분석 기준
- 기간: 2023-11-06 ~ 2024-11-06
- 활성사용자 정의: 해당 기간 1회 이상 에어에 접속한 사용자. 그 활성사용자의 누적 데이터(가입일~11/6)를 집계
- 추출 기간: YAU 2023-11-06~2024-11-06(1Y), MAU 2024-10-07~11-06(1M), WAU 2024-10-30~11-06(1W), DAU 2024-11-06 10:50 ~ 11-07 10:50(1D)
- 캠즈/GA 데이터와 값이 다른 이유는 서버 개발자가 확인 후 공유하기로 함

## 요약
- 활성 사용자: YAU 766,873 / MAU 219,504 / WAU 130,609 / DAU 64,093
- 로그인 비율: 로그인 27%, 비로그인 73% (최근 1개월 활성 사용자)
- SNS 계정 연동: 로그인 사용자는 Private Key 1개당 평균 1.01개 SNS 계정
- Private Key 생성일: 활성 사용자의 40.43%는 2024년에 처음 이용, 28%는 2019~2022년에 처음 이용한 것으로 추정
- 로그인 활성 사용자의 평균 사용일수 431일(약관동의일~마지막 접속일): 0일 10%, 100일 미만 21%, 200일 미만 10%, 200일 이상 58%
- 성별·연령: 남성 97%, 여성 3%(입력 524명), 평균 연령 49세(입력 489명)
- 누적 주행: 로그인 사용자 중 80%(104,768명)는 1회 이상 주행. 로그인&주행 사용자 중 36%(52,252명)가 캐시를 1회 이상 적립. 로그인&주행 이력 없는 사용자 20%(26,912명) 중 캐시 적립자 3%(889명), 쿠폰 구매자 0.1%(32명)
- 누적 캐시 적립 횟수: 로그인 사용자 131,680명의 40%(53,140명)가 적립 경험, 평균 적립 횟수 89회
- 누적 캐시 적립 금액: 적립 사용자 53,139명의 평균 3,238원. 33%는 1,000원 미만, 43%는 1,000~2,000원 미만
- 누적 쿠폰 구매: 적립 사용자 53,139명 중 8% 미만(4,016명)이 쿠폰 구매, 구매자 평균 2.6회
- 누적 쿠폰 구매 금액: 구매 1회 이상 4,011명의 평균 14,508원, 5,000~10,000원대 구간 29%로 최다
- 상관관계(2024-09 한 달, ChatGPT 질의) 결론은 [[air-server-data-correlation-analysis-2024-09]]에 있다.

### 약관동의 시점
- 앱 실행 후 약관동의 시 Private Key가 생성되고, 다른 기기에서 접속하면 Private Key가 추가 생성된다. SNS 계정 연동일은 확인 불가.
- 2024년 약관동의 40.43%, 2019~2022년 28%
