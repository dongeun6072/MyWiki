# 아이나비 에어 운영 메일 (2026)

2025년은 [[air-operations-2025]]에 있다. 에어는 [[inavi-air]] 프로젝트다.

## 통합회원

- **해외 로그인 변경(03-05)**: 커넥티드 통합회원의 해외 로그인 URL(ROUTE_CD 값)이 바뀌었으나, 에어는 변경된 URL이 이미 반영돼 문제가 없다고 확인했다. 01-16에는 "에어는 해외 이용이 없다는 전제로 전환을 진행"하기로 정리됐다.
- **통합회원 분리 방안(04-10)**: 에어는 통합회원의 **고유 ID**를 받고, 커넥티드에 필요한 사용자 정보 API가 제공되면 큰 문제가 없다는 의견이다. 에어는 각 SNS 로그인의 고유 ID(거의 변하지 않는 값)로 별도 에어 회원 체계를 관리한다. 카카오·구글은 ID가 바뀔 수 있어 SNS 가입자에 대한 사전 고려가 필요하고, 해외 Connected에서도 국내처럼 전화번호 같은 고유 정보를 받는다면 그것으로 해결할 수 있다.
- **개인정보 활용 현황(04-22)**: 서버플랫폼셀 답변은 웹 로그인 뒤 통합회원 멤버코드를 받아 조회하고, 성공하면 멤버코드를 자체 회원으로 DB에 저장하며 이메일은 저장하지 않는다는 것이다.

## 앱 품질·보안 이슈

- **삼성 크래시 리포트(03-13)**: 삼성전자 쪽 리포트의 에어 앱 크래시는 DP 엔진 초기 다운로드 중 앱이 종료될 때 발생한 **double free**로 분석됐다. DP 엔진을 수정해 배포했고 3월 에어 패치에 적용해 출시하기로 했다.
- **구글 API 키 노출 경고(03-09)**: 구글이 에어 앱의 Google Cloud 프로젝트에 연결된 API 키가 공개 저장소에 올라간 APK에서 발견됐다고 알렸다. 키 값은 위키에 없다. 조치 결과는 메일에 없다.
- **ANR 확인 요청(07-24)**: INaviEngine 관련 ANR 스택트레이스 첨부. 본문은 짧다.
- **Google Play API 수준 요구사항(07-22)**: 요구 수준 대응 기한을 11월 1일로 연장 신청했다.
- **16KB 페이지 대응**: 01-30 맵매칭 라이브러리 재배포 때 NDK 설정 실수로 누락됐다([[orbis-taiwan-development-2026]]).

## 파트너 SDK·광고·운영

- **아바티 포인트홈 개편 협조(02-02, 03-11, 07-29, 10-19)**: 포인트홈 최신 버전 업데이트를 반영한 APK를 회신해 달라는 요청이 반복되고, 개발 가이드(AOS·iOS)가 공유됐다. 10-19 메일에서는 AppLovin 13.6.2로 빌드해 특별한 문제를 못 찾았고, 적용 앱은 10월 중순 서비스를 목표로 했다.
- **핀크럭스 연동 테스트(04-02)**: 포스트백 URL과 유저키를 전달해 상대 서버 적용 후 테스트 로그를 받기로 했다.
- **배너 아웃링크(05-14)**: 어드민에 URL과 사용 Flag를 추가하고, Agent가 앱에 전달하며, 앱이 브라우저로 연결하는 구조면 개발 가능하다고 답했다.
- **클라우드 비용 절감(03-20)**: Grafana에 사업 요청을 수용하고, 웹서버·DB 서버 제거 비용을 확인해 기존 데이터를 엑셀로 제공할지 사이트를 유지할지 판단하라는 지시가 공유됐다.
- **ETA 문의(05-21)**: 같은 재탐색 시각(04-16 07:18:16)인데 탐색 로그와 이벤트 로그의 남은 거리(25,103m 대 21,318m)·소요시간(2,460초 대 2,172초)이 크게 달라 원인 분석을 요청했다. 결론은 메일에 없다.

## 안전운행 데이터

- **업데이트 주기 변경 검토(03-25)**: 안내서버가 CDN의 `new_guide_point` 경로를 참조해 갱신하는데, 안전운행 모드의 기존 `guide_point` 경로(에어, 하이브리드, 토요타)도 바꿔야 하는지 서버플랫폼셀이 문의했다. 토요타는 `new_guide_point` 디렉터리가 없고, `updatedVersion` 파일이 빠진 곳이 있으며, TCON은 별도 서버 업로드 후 동기화하는 구조이고, KGM은 2주 단위 갱신 정책 유지 여부를 확인해 달라고 했다.
- **KGM/TMC 통합(09-15)**: 에어와 KGM·TMC 안전운행 데이터를 통합하는 안내.
- **신규 카메라 유형(10-12)**: 구간 Flag가 추가된 신규 카메라 데이터를 담아 안전운행 데이터 파일명을 **`CameraGuidePoint.zip`**으로 바꾸고 프로젝트별로 순차 확대한다. 다음 에어 패치에 선반영하며, Hybrid·TMC 통신형은 `Ssangyong.zip`(Flag 미적용)과 `CameraGuidePoint.zip`(적용)을 같은 CDN 폴더에 동시 업로드한다. 파일명 변경 영향도 체크리스트가 첨부됐다.
- **어린이 보호구역(09-17)**: TMC에서 어린이 보호구역 회피 사양 문의가 와서 에어 경로선택 화면의 보호구역 마커 표시 사양을 확인하라는 요청이 있었다.

## 지도 발행·행정코드

- 2605a 에어·하이브리드 지도에서 MR과 SMR의 Mesh 개수 불일치로 모의주행이 안 되던 문제는 `numOfMesh`를 5668로 맞춰 해결했다(04-06).
- 2607a 지도 일정(06-09): 행정코드 변경 테스트용 앱 패치를 6/24 이전에 발행하고, 행정코드 변경 데이터와 검색엔진 패치가 통신형 26.05 데이터를 쓰는 KGM·TMC 검색에 영향이 없는지 검토한다. 통신·비통신 지도가 함께 제공되면 통신형 우선 제공이 문제없는지도 확인한다. → [[inavi-hybrid-navi]]
- 07-08: 영업소 요금 조정에 따른 요금 테이블 반영과 탐색 서버 재기동 요청.
- 10-26: 에어 맵매칭 엔진 개선 버전 배포 메일(본문 없음).
