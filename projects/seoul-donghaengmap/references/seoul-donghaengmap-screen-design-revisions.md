# 서울동행맵 화면기획서 개정 이력 (v0.7 → v1.0)

[[seoul-donghaengmap-screen-design]]은 v1.0의 **결과 구조**를 다룬다. 이 페이지는 거기까지 오는 **변경 과정**이다. v0.8 이후 파일에는 문서 안에 개정 이력표가 있고(작성자는 2명, 이름은 적지 않는다), v0.7 첫 파일에는 이력표가 없어 텍스트를 비교했다. 문서 번호 체계(`0-x` 온보딩, `1-x` 홈, `2-x` 길안내, `3-x` 마이페이지)는 처음부터 같다. 프로젝트는 [[seoul-donghaengmap]]이다.

## 파일과 버전 대응

| 파일 일자 | 문서 버전 | 성격 |
|---|---|---|
| 08-24 | v0.7 (이력표 없음) | 구조 재편 전. 메뉴 구조도에 콜택시, 음성 전용 모드가 따로 있다 |
| 08-27 r1 | v0.7 | 개정 이력표 신설, 구조 재편본(약 40% 분량 증가) |
| 09-03 | v0.8 | 첫 v0.8. 이력표에 "md 대조 반영" 항목이 있다 |
| 09-04 | v0.8 | 길안내 경유지·실내 내비·마이페이지 비회원 등 반영, 회원가입 서술 보강 |
| 09-08 | v0.8 | 저상버스 "승차 예약" 4단계 반영 |
| 09-14 | v0.8.1 | 상세경로·도착 정보 정책, 예약 화면 폐기 |
| 09-28 | v1.0 | 전 화면 정비, 개정 이력이 3쪽으로 늘어남 |

v1.0 개정 이력표의 일자는 09-28이다. [[seoul-donghaengmap-screen-design]]은 09-30 파일을 읽은 것이라 며칠 뒤 수정본이 따로 있다. 이 7개 파일 사이에 09-23 공유 PDF와 09-30 PPTX가 있다. ^[inferred]

## 단계별 변경

### v0.6 → v0.7 (08-19 → 08-24 → 08-27)

- **08-24 본**: 홈은 편의시설(1-2), 콜택시(1-3, 4종 하위), 버스정류장(1-4), 지하철역(1-5), 불편신고(1-6), **음성인식 시작하기(1-7)**로 구성됐고, 음성은 별도 "음성 전용 모드"(진입, 챗봇형 대화창, 기능 실행·응답, 긴급 안내 우선 표출)였다. 서비스 정보(3-4) 아래에 공지, 이용약관이 있었다. 저상버스는 "승하차 예약"(2-6)이었다.
- **08-27 본**: 대메뉴를 홈, 길찾기, 마이페이지 3탭으로 고정하고 **홈 6메뉴**로 개편(마이페이지·서비스 정보를 빼고 버스정류장·지하철역을 추가). 서비스 정보는 마이페이지 하위로 이동. 표지 제목을 "서울동행맵 고도화"로 바꾸고 문서 개정 이력과 변경 페이지 라벨을 도입했다. 택시 호출 하위 4종 중 장애인 콜택시, 복지콜이 서울엄마아빠택시 앞으로 올라왔다.

### v0.7 → v0.8 (08-27 → 09-03 → 09-04 → 09-08)

- **09-03**: 탭바 순서를 공공 디자인 시스템(KRDS) 기준으로 홈 최좌측에 둔다. **경유지 최대 2개 → 1개**. 버스정류장 검색 필터(전체/내 주변 300m). 마이페이지 **글자 크기 2단**. 홈 버튼을 버스·지하철·택시 순으로 바꾸고 번호를 재부여(버스 1-4→1-3, 지하철 1-5→1-4, 택시 1-3→1-5). 즐겨찾기는 "집" 1슬롯 고정 + 사용자 지정 2슬롯. 인근 편의시설 순서를 교통약자 유형별로 개인화. 지도 컨트롤 2종("내 위치" 3상태, 정북 복원). 장표에서 "미결·검토 중" 행을 제거했다(잔여는 별도 md·ADR로 관리).
- **09-04**: 지하철역 검색 필터. **실내 내비 2-4-2 장표 신설**(전맹 외/전맹). 불편신고 "기타" 유형 제외. **비회원** 마이페이지 분리(닉네임 수정 불가, 마일리지·즐겨찾기는 로그인 팝업). 즐겨찾기 이름 변경 바텀시트. 회원가입에서 시각장애 유형은 **저시력/전맹 2분기**로 한다(시각장애 등급이 진단서로 정해지는 행정 등급이라 사용자가 스스로 판단하기 어렵다는 이유). 애플 로그인은 iOS에만 노출. 비회원이 가입하면 닉네임을 승계하지 않고 새로 입력한다.
- **09-08**: 불편신고 입력 3종(유형·내용·사진) 확정, 위치는 GPS 현위치 + 지도 핀. 마이페이지 레이아웃 재편(유형 인라인 + 변경 버튼, 마일리지·즐겨찾기 카드형, 서비스 정보 중간 메뉴 폐기, 번호 3-4~3-7). **저상버스 "승하차 예약" → "승차 예약"**과 4단계: ① 예약(앱 보관, 시간·거리 제약 없음) ② 예약 확정(정류장 반경 50m + 2정거장 전 조건 충족 시 **앱이 자동으로** 관제 연계 시스템에 발신) ③ 탑승 준비(관제 푸시) ④ 탑승 완료(탑승 확인 팝업, 예약 1건당 1회, 반경 재진입 시 재표출 없음).

### v0.8.1 (09-14)

- 실내 내비: 하단 버튼 2종을 바텀시트 안으로, 경로 단계 목록만 영역 내 스크롤.
- 상세경로: 구간 타임라인 보강(방면, 빠른환승/승강장, 차기·차차기 도착, 구간 요약과 경유역 펼침). **도착 정보 표기 정책**: 10초 자동 갱신 + [새로고침] 2채널, 표기 3단(곧 도착 / N분 N초 / N분). 경로·구간 구성은 갱신 대상이 아니다. 노선 상세에도 새로고침 추가.
- **저상버스 예약 2-6 폐기**, 노선 상세에서 신청, 예약 내역은 마이페이지 3-4로, 홈에 예약 현황 위젯. 전맹 낭독 순서, 지도 핀 음성 안내, 역명 그룹 라벨. 마이페이지 번호 3-4~3-8로 재부여.

### v1.0 (09-28)

개정 이력 3쪽에 걸친 전면 정비다. 핵심만 모으면 다음과 같다. 구조 결과는 [[seoul-donghaengmap-screen-design]]에 있다.

- **신설**: 장소 검색 2-1, 경로 편집 2-9-1, 최근 도착지 편집 2-0-1, 역 정보 1-4-1, 시간표 1-4-2, 불편신고 1-6-1/1-6-2, 공지 상세 3-5-1, 오픈소스 3-7, 언어 변경 3-10(5개 언어), 내비게이션 **가로 화면**(회전 시 상태 유지).
- **독립/분리**: 경로 리스트 2-9 독립, 버스정류장 1-3 / 2-5 / 2-5-1, 지하철역 1-4 / 1-4-1 / 1-4-2를 분리. 인근 편의시설의 장소 상세는 2-2로 통합. 로그아웃 3-8, 회원 탈퇴 3-9로 번호 이동.
- **폐기**: 「차기·차차기」, 「전역 도착」, 「경유」 문구, 검색 필터 칩, [>] 상세보기, 음성인식의 텍스트 입력(마이크 권한 필수), 택시 하위 번호(4종은 카드), 실내 내비 전맹 [다시 듣기].
- **정책 추가**: 택시 호출에 자격 고지와 바우처 신청, 불편신고 상태 4종과 수정 모드, 마일리지 내역 3분할과 유효기간·만료 표기, 저상버스 예약 내역에 하차 정류장 지정(선택)과 [탑승 확인], 상세경로의 [승차 예약]은 2-5-1로 이동, 실내 내비 컨트롤 5종([새로고침] → [재탐색]).

## 흐름 요약

1. **08월 말**: 구조(IA)를 3탭·홈 6메뉴로 확정.
2. **09월 초**: 기능 정의의 구체화(필터, 즐겨찾기, 비회원, 개인화)와 문서 정합(별도 요구 문서와 대조, 미결 행 제거). 한 주에 3번 개정되는 일 단위 중간본이 이 시기에 몰린다.
3. **09월 중순**: 예약 흐름을 "별도 화면" → "노선 상세 + 앱 자동 발신"으로 정리하고 실시간 도착 정보 정책을 정한다.
4. **09월 말**: 사용자 흐름을 화면 단위(경로 리스트, 편집, 장소 검색)로 쪼개 번호를 재부여하고 전역 용어를 통일한다.

번호가 여러 번 재부여되므로(택시 1-3→1-5, 버스 1-4→1-3, 마이페이지 3-4 → 3-4~3-9) **과거 문서·메일에서 화면 번호를 인용할 때는 버전을 먼저 확인**해야 한다. ^[inferred]
