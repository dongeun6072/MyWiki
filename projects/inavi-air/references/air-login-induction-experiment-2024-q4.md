# 로그인 유도 실험 2024 Q4

가설 수립 스프린트([[air-hypothesis-phase1-phase2]]) 결과 "선택 로그인 유도"를 첫 실험으로 정해 2024-11-11~12-20에 진행한 기획, 개발, 배포, 검증 기록이다. 상위 회의 흐름은 [[air-growth-sprint-minutes-2024-q4]], GA 이벤트 정의는 [[air-ga-logging-events]], 후속 미션 논의는 [[air-mission-ideation-and-referral-2024-12]]를 본다.

## 1. 로그인 유도 Action List
로그인하지 않은 사용자 대상:
- **앱푸시**: "로그인 혜택 만료 알림 24시간 내 로그인 시 최대 10,000원(캐시) 지급" → 클릭 시 로그인 페이지로 이동
- **메인페이지**
  - "로그인하고 최대 10,000원 적립받기": 로그인하고 즉시 500원, 주행하고 1,500원
  - 로그인 유도 버튼을 주 1회 노출에서 상시 노출로 변경
  - 로그인 유도 문구·디자인을 "진짜 로그인하면 안 될 것처럼" 자극적으로 만들기
- **캐시 버튼**: 툴팁 "로그인 후 첫 주행 +1,000캐시"
- **캐시 페이지**: 누르면 로그인 페이지로 이동
- **로그인 페이지**: 로그인 혜택을 더 자극적으로. 캐시 페이지 로그인에서 복권을 조금 긁어 놓고 "로그인하고 내가 받는 금액 확인하기" 표시, 로그인하면 복권을 긁을 수 있음

## 2. 스프린트 기록
### 11/13 ~ 11/20 스크럼 (로그인 유도 & 로그 분석 스프린트)
자세한 영역별 표는 [[air-growth-sprint-minutes-2024-q4]]의 11월 스크럼 절을 본다. 핵심만:
- 11/13: 기존 혜택(로그인 시 500원)만으로는 비로그인 유저를 유도하기 어려움 → 로그인+게이미피케이션 접목, 추가 미션이 있음을 암시하는 방식 검토. 1차 와이어프레임 후 금요일 공유
- 11/20: 디자인 중간 리뷰에서 메인은 시안 2로 결정(캐시 관련 키컬러 통일), 운행 중은 검정 배경으로 메인과 통일, 로그인 화면은 문구를 메인과 통일하고 카카오 로그인을 메인으로 크게+나머지 로그인 옵션 작게. 크리스마스 앱 아이콘 추가 공유. 가로 모드 안드로이드용 사이즈 별도 제공. 500캐시 서버 연동은 차주 서버와 논의

## 3. 가설과 검증 지표 정의 (12/15 지표 결과 템플릿)
- 메인 가설: 로그인 기능 업데이트 후 로그인 비율이 5% 이상 증가할 것이다
  - 검증: 로그인 비율 5% ≥ {(업데이트 전 SNS 로그인 활성 사용자 / 업데이트 전 전체 활성 사용자) - (업데이트 후 동일 비율)} × 100 (원문 식 그대로, 부호 방향이 직관과 반대 ^[ambiguous])
- 참조 가설: 로그인 기능 업데이트 후 캐시 적립 비율이 증가할 것이다. 검증식은 같은 형태(캐시 적립 활성 사용자 기준)
- 측정 기간: 업데이트 전 12/2~12/8(7일), 업데이트 후 12/9~12/15(7일). 기존/신규 사용자 × (전체 활성, SNS 로그인 활성, 캐시 적립 활성) 표는 값이 비어 있는 템플릿

### 용어
- 전체 활성 사용자: 해당 기간 앱에 접속한 모든 사용자
- SNS 로그인 활성 사용자: 접속한 사용자 중 SNS 로그인을 완료한 사용자
- 캐시 적립 활성 사용자: 접속한 사용자 중 캐시를 적립한 사용자
- 기존 사용자: 해당 기간 전에 Private Key를 생성한 사용자
- 신규 사용자: 해당 기간 내에 Private Key를 생성한 사용자

## 4. 12/20 가설 검증 결과
- 가설: **로그인하지 않은 사용자는 로그인 유도 혜택에 지속적으로 노출되면 로그인할 것이다.**

| 검증 지표 | 결과 |
|---|---|
| 활성사용자의 로그인 비율 5% 증가 | **실패**: 업데이트 이전 비율 대비 1% 감소 |
| 신규 사용자의 SNS 로그인 비율 증가 | **실패**: 업데이트 1주차에 전주 대비 SNS 회원가입 비율(가입/설치) 2.8% 증가했으나 2주차에 1.4% 하락 |
| 기존 사용자의 SNS 로그인 비율 증가 | **성공**: GA 기준 SNS 가입 완료 사용자 13.2% 증가 |

### 실패 원인 분석 요청
