# 원내비 서비스 종료 후 아이나비 에어 유저 유입 Plan

2024-11 스크럼에서 "원내비가 종료하는데 데려올 수 있는 방법이 없을까?"라는 문제 제기([[air-growth-sprint-minutes-2024-q4]]의 11/13 스크럼)가 나온 뒤 작성된 계획 문서다. PRD의 기회 요인(원내비 2025년 1월 종료)과 연결된다([[air-prd-v1-v2-app-tech-navigation]]). 경쟁 서비스 조사는 [[air-competitor-service-research-1-2]]를 본다.

## Action Item
### 앱스토어 광고 집행 (현재 진행 중)
원내비 종료 후 앱스토어에서 "네비게이션"을 검색하는 사용자 대상 광고 노출.

| 매체 | 예산 | 기존 키워드 | 추가 제안 |
|---|---|---|---|
| 구글 애즈 | 30,000원/일 | 확인 불가 | 키워드 플래너 제안 키워드로 추가 가능한지 확인, 원내비 종료 전까지 1일 예산 증액 |
| 애플 애즈 | $11/일 | 네비게이션, 네비, 내비게이션, 카플레이, 애플 카플레이, 앱테크 | 키워드 플래너 제안 키워드 참고해 추가 고려(추가 키워드 목록은 외부 링크) |

### 보도자료 배포
타사 사례와 같은 맥락으로 보도자료 배포.

## 배경과 목적
원내비 서비스 종료에 따른 아이나비 에어 신규 사용자 유입.

## 리서치: 경쟁사 서비스 종료 후 신규 유저 획득 사례
| 서비스 | 방식 | 상세 |
|---|---|---|
| 식신 플레이트 | 신규 회원 모집 캠페인 | 망고플레이트 종료 후, 신규 가입 후 첫 리뷰를 등록한 전원에게 커피 교환권, 추첨 1명에게 아이폰15프로 증정 기사 배포 |
| 뽈레 | 사업 제휴로 데이터 이전 지원 | 망고플레이트와 제휴해 유저의 저장 맛집 POI 매핑, 이미지, 리뷰 콘텐츠를 그대로 쓸 수 있게 이전 |
| 핀플 | 공식 블로그 안내 | 경쟁사 서비스가 종료되니 대체 서비스로 자사를 추천 |
| 아이쉐어링 | 뉴스 기사 보도자료 | 경쟁사 종료를 키워드로 자사 홍보 |

## 원내비 분석
### 데이터 (IGA웍스)
- MAU 55만 명(2023.11~2024.10), 신규 설치 1.2만 건(2024.10, 1개월)
- 유저: 4050 비율 64%, 남성 53%:여성 46%, 페르소나 관심사 식료품점 쇼퍼 5.8%·보험가입자 6.1%, 라이프 스테이지 초등학생 부모 18.5%·신생아/유아 부모 13%
- 지도/내비 앱 사용 수: 2개 39.8%, 3개 25%, **원내비 단독 18.7%**
- 원내비 사용자가 가장 즐겨 쓰는 지도/내비: 네이버지도 50.5%, **카카오맵 22.5%**

### 원내비의 강점
- 직관적인 UI
- KT 이용 고객은 데이터 비용 무료
- 목적지 정보: 영업시간, 휴무일, 전화번호, 목적지 주변 주차장 정보를 통계적으로 확인
- 초보자 길안내(편한길 찾기): 블라인드 등 커뮤니티 댓글 캡처로 근거 제시
- 같이가자(그룹 주행)

### 원내비 강점에 대응하는 에어의 셀링 포인트
| | 원내비 | 아이나비 에어 |
|---|---|---|
| UI | 직관적인 UI | 원내비와 뿌리(팅크웨어)가 같아 유사한 UI로 빠르게 적응 가능 |
| 데이터 무료 | KT 요금제 사용자는 데이터 무료 | 데이터 사용량만큼 캐시 적립. 1개월 최대 1,500캐시 = KT 150MB 데이터 구매 가능 |
| 그룹주행 | 친구야 같이가자 | 그룹 주행 |
| 초보자 길안내 | 편한길 경로 탐색 | 큰길 위주 경로 탐색 |

## Plan (예산과 가능한 안을 검토해 상세 플랜 수립 필요)
### 데이터 이전 지원
- 대상: 원내비 기존 유저 전체
- 내용: 원내비 협조로 백업한 데이터를 에어에 등록해 주행이력, 내 장소 등 기존 내비 데이터를 업로드할 수 있도록 지원

### 내비 변경 보상 프로그램
- 대상: 신규 에어 SNS 가입자. 기존 에어 사용자는 제외(Private Key의 휴대폰 번호로 필터 가능)
- 기간: ASAP ~ 2025-01-30(원내비 종료 달까지). 종료 후 보상액을 낮춰 상시 진행 가능
- 내용: 경쟁사 내비 사용자가 에어에 신규 가입하면 추가 캐시 보상
- 혜택: 가입 보상 캐시 최소 1,000 ~ 최대 5,000캐시 랜덤 지급. 가입자 추첨으로 로봇청소기 1대 같은 미끼 상품 추가
- 참여 방법: 신규 SNS 회원가입 완료. 기존 유저의 휴대폰 번호와 매칭되면 500캐시만 지급. 경쟁사 내비 사용 이력 인증은 없음. 완료 즉시 랜덤 보상 확인 가능
- 채널: 뉴스 기사 보도자료, 기타 매체 광고(인스타그램, 밴드 등)

### SNS 바이럴
- 대상: 신규 내비 UI/UX 적응이 불편한 사용자
- 내용: 뿌리(팅크웨어)가 같아 원내비와 에어의 UI·유저 플로우가 유사
- 바이럴 메시지: 원내비 종료 소식, 원내비와 에어의 뿌리가 같다는 정보, 원내비 강점에 대응하는 에어 셀링 포인트
- 채널: 바이럴 업체 활용. 자동차 커뮤니티, 인스타그램, 블로그

## 고객 구매 여정
### 여정 1: 기존 원내비 데이터(주행 이력, 자주 가는 곳)가 필요한 사용자 (데이터 이전 지원 대상)
| 스테이지 | 원내비 종료 인식 | 설치 및 사용 | 소개 |
|---|---|---|---|
| 사용자 행동 | 원내비 앱에서 종료 소식 확인, 에어로 데이터 이전용 백업 파일을 지원함을 인지 | 에어 설치 후 백업 파일 이용, 유사한 사용성에 만족 | 커뮤니티·지인에게 데이터 백업/이전 가능함을 소개 |
| 만족도 | 불만 | 만족 | 만족 |
| 페인 포인트 | 기존 내비 대체의 불편, 자주 가는 곳·주행 이력 필요 | 데이터 이전 과정의 불편 | |

### 여정 2: 48세 남성, 가성비 소비·절약형 (내비 변경 보상 프로그램, SNS 바이럴 적합)
| 스테이지 | 원내비 종료 인식 | 신규 내비 탐색 | 에어 앱스토어 방문 | 설치 및 사용 | 소개 |
|---|---|---|---|---|---|
| 사용자 행동 | 원내비 앱에서 종료 소식 확인 | 지인에게 내비 추천 요청해 에어를 추천받음 / 포털 "네비게이션 추천" 검색 후 커뮤니티·뉴스·블로그로 추천받음 / 앱스토어 "네비게이션" 검색으로 발견 | 원내비와 에어 UI가 유사함을 인지, 내비 변경 보상 프로모션 확인 | 설치 후 신규 SNS 가입 시 보상 프로모션에 자동 참여해 추가 캐시 적립, 유사 사용성에 만족 | 커뮤니티·지인에게 추천 |
| 만족도 | 불만 | 불만 | 보통 | 만족 | 만족 |
| 페인 포인트 | 기존 내비 대체의 불편 | 적합한 내비 찾기 어려움 | 신규 내비 사용성 적응 부담, 데이터 사용 부담 | | |

## Appendix
### 원내비 장점 목록 (참고 링크 생략)
KT 고객 데이터 비용 무료, 친구야 같이가자, 타임머신, 직관적 UI, 기가지니 음성 검색, 운전면허시험 코스 안내, 실시간 사고/공사 안내, 전기차 충전소·약국 정보 등 제공, 초보자용 편한길 안내, 도보지도, 제주도 관광지 특화 서비스. 경쟁사 데이터 사용량 비교 자료는 외부 링크만 있음.
