# Slack #10_prj-inaviair 대화 (2025 하반기)

아이나비 에어 프로젝트 공개 채널 #10_prj-inaviair의 2025-07-01~12-31 기록이다. 프로젝트 개요는 [[inavi-air]], 같은 해 버전 기록은 [[air-app-version-notes-2025]], 운영 이슈는 [[air-operations-2025]], 비공개 채널 쪽 기록은 [[air-channel-slack-2025-h2]]를 본다. 이 채널은 앱 개발 리더(출시 담당)가 신규 버전을 공유하고, 서비스 운영·서버·안내/탐색 엔진·POI·웹서비스·제휴 담당이 이슈를 주고받는 곳이다. 사람 이름은 역할로 적었다.

이 구간에서 메시지 44건(입장·퇴장 알림 포함)과 스레드 답글 153건을 읽었다. 첨부는 파일명·종류만 기록했다.

## 1. 7월

- **2025-07-02 고객사 CCTV 미출력 문의**: 고객사 문의 건으로 인터넷은 연결되나 내비게이션 CCTV 화면이 출력되지 않았다. 담당자가 아이나비 에어와 아이나비 3D를 직접 실행해도 동일 증상이 재현됐다(스크린샷 2장 첨부). 서버 담당자 답변: 국가교통정보센터가 보안 모의 훈련 중 NHN 클라우드 IP를 일본 IP로 탐지해 차단한 상태였다. 센터 담당자와 논의했고 보안 장비 예외 처리 신청서를 작성해 전달했다. 보안 처리 절차가 강화되어 시일이 걸리고 있어 고객사에 양해를 요청했다. 같은 날 15:14 국가교통부(국가교통정보센터)에서 연락이 와 복구된 것을 확인했고, 에어 서비스를 통해 CCTV가 노출됨을 확인했다.
- **2025-07-03~04 에어 x 오르다 연계 통계 문의**: 에어 x 오르다 서비스 연계가 약 1개월 진행되어 연계 시나리오의 유의미 여부 판단용 정량 지표를 문의했다. 항목은 (1) 공지/배너: 에어 홈 팝업 배너 클릭 후 공지/이벤트 페이지 이동 수, 공지/이벤트 페이지에서 앱 설치 스토어 이동 수, 오르다 앱 설치 수, (2) 목적지 도착 시 앱 연동 시나리오: 도착 시 앱 연동 팝업 클릭 수, 오르다 앱 설치 수.

## 2. 8월

- **2025-08-08 탐색 서버 타임아웃**: 서버 담당이 16:23경부터 에어/IX Agent에서 탐색 엔진 연동 요청 시 간헐적으로 타임아웃 에러가 발생한다고 알렸다. 탐색 엔진 담당 확인 결과 탐색 서버 3대 중 3번 서버가 동작 이상이어서 재기동했고 정상 확인. 1, 2번 서버에 할당된 요청은 정상이고 3번 서버로 간 요청이 타임아웃을 겪은 것으로 보인다. 서버 엔진 동작 이상의 원인은 로그 분석 후 재공지 예정. 16:45 이후 에러는 발생하지 않는다.
- **2025-08-12 서버 통신 장애 원인 분석 중**: 탐색 담당이 이슈 재현 포인트를 확인했고, 주행 중 특정 지점(이슈 포인트)에서 스마트 재탐색 요청 시 발생한 건이라고 1차 공유했다. 후속(2025-09-11): 이슈 원인은 스마트 재탐색 시 특정 지점에서 노드 정보를 확인하면 발생, 수정 내용은 예외 처리 로직 추가, 적용은 에어 2510a 가오픈 포트에 09-22 적용 예정.
- **2025-08-20 SKP 연동 에어캐시 적립 API 에러**: 제휴 연동 담당이 에어 SKP 연동 에어캐시 적립 API에서 에러가 발생한다고 공유했다. 원인은 기존에 요청되던 파라미터 형식과 다른 형식으로 요청된 것이다. 기존은 `point`, `event_at`, `data`(암호화 문자열) 필드 구조였고, 에러 케이스는 `transaction_id`, `user_id`, `private_key`, `point`, `action_type`, `title`, `unit_id`, `event_at`, `extra` 필드가 평문으로 전달됐다(값은 미수록). 서비스 운영 담당은 확인 및 조치 가능한 부분이 없어 보인다며 어디에 컨택해야 하는지 문의했고, 추가 확인으로 기존에는 data가 암호화되어 전달됐으나 에러 케이스는 암호화 없이 전달되는 것으로 확인됐다. 서버 담당이 오퍼월 관련 SKP에 연락을 요청했다.
- **2025-08-26 이벤트 NO.192 게시글 안드로이드 미표출**: 공지/이벤트 NO.192(포인트 쌓아 에어캐시로 전환하는 꿀팁) 게시글이 안드로이드 단말에서만 정상 표출되지 않고 아이폰에서는 정상이었다. 웹서비스 담당은 모바일 웹으로는 정상이라 앱 쪽 확인이 필요하다고 답했다. 앱 개발자 확인 결과 해당 웹페이지에 로드할 수 없는 이미지가 적용되어 에러 페이지가 표출된 것이며, 이미지 등록 과정에서 CDN의 `202508wakeup1.jpg` 이미지가 등록되어 있는지 확인을 요청했다. 서비스 운영 담당이 조치 완료. OS별 차이 문의에 앱 개발자 답변: OS 및 버전과 각 OS의 에러 처리 방식에 따라 다를 수 있고, 이번 건은 OS별 웹뷰의 에러 전달 기준이 달라 발생했다.
