# 에어 AOS 작업 이력 2023 하반기

본인이 작성한 iNavi AIR Android 앱(Bitbucket `inaviair_aos`) 커밋 601건(2023-07 ~ 2023-12)을 주제별로 묶은 이력이다. 주요 주제: 제보·에어연구소, HUD 연결, 보행자 신호등·AI 횡단보도, 에어캐시 UI, Android Auto. 전체 허브는 [[air-aos-commit-history]], 서비스 개요는 [[inavi-air]], 기능 연표는 [[inavi-air-feature-history]]를 본다.

> [!warning] 커밋 메시지 기준, diff 미검증
> 이 페이지는 커밋 메시지만 근거로 한 요약이다. 메시지와 실제 변경이 다를 수 있다. 주제 분류는 메시지 키워드와 Jira 키로 한 1차 분류라 경계 사례가 있고 ^[inferred], 메시지가 모호한 커밋은 별도 섹션에 모았다 ^[ambiguous]. 각 항목의 해시로 `git show <해시>`를 실행해 확인한다. 동기와 효과는 메시지에 있는 것만 적었다.

근거는 커밋 메시지뿐이다(diff·코드 미확인). 총 601건, 월별 건수는 07월 68, 08월 91, 09월 123, 10월 135, 11월 158, 12월 26건이다.

## 기간 개요

커밋 메시지상 2023-07 ~ 2023-12 기간에 601건이 있으며, 월별로는 68 → 91 → 123 → 135 → 158 건으로 11월까지 늘다가 12월에 26건으로 줄어든다(12월 마지막 커밋일은 2023-12-20). 메시지에 가장 자주 나오는 주제는 제보하기·에어연구소(118건, 08~09월 집중), 내장소·최근장소(133건, 10~11월 집중), HUD(로드피아) 연결(72건, 11~12월)이다. 7월에는 에어캐시 메인 UI·보행자 신호등 관련 메시지가, 8~9월에는 폰트 교체(AIR-1284)와 제보하기 관련 메시지가 많다. 이 외에 버전코드 갱신·이미지 리소스 추가 같은 반복성 커밋이 각각 36건, 45건 있다. 아래 건수 합은 주제 14개 588건 + 모호 13건 = 601건이다(분류는 메시지 키워드 기준이라 경계 사례는 한쪽에 배정한 것이다).

## 1. 제보하기·에어연구소

- 기간: 2023-08 ~ 2023-11 / 건수: 118 (08월 45, 09월 58, 10월 8, 11월 7)
- Jira: AIR-1253(에어연구소), AIR-1257, AIR-1275(제보하기), AIR-1365, AIR-1280(제보 지도 SDK 관련 2건)

커밋 메시지상 에어연구소 화면(AIR-1253: 미리보기, 탐색 옵션 변경, 상세페이지 GUI)과 제보하기 화면(AIR-1275: 신규 제보 작성, 임시저장, 제보내역 목록, 위치지정 화면) 관련 작업이 08월 중순부터 09월 초에 몰려 있다. 09월에는 제보 상세 유형 팝업, 임시저장 문구·날짜 포맷, 제보내역 TextStyle 같은 세부 UI 조정 메시지가 이어진다. 10월 말에는 검색 결과 없음 화면에서 제보하기로 연결하는 작업(AIR-1365)과 제보 지도를 Maps SDK로 바꾸는 작업이 있고, 11월 초에는 에어연구소 제보하기 ver.2 제거 관련 커밋이 있다.
