# 아이나비 에어 제휴·광고·운영 연동 (2023)

에어 앱 쪽 외부 협력과 운영 이슈다(비즈그룹, C.P사업팀, 고객센터가 개발 쪽에 요청한 건). 기능 이력은 [[inavi-air-feature-history]], API는 [[inavi-air-api-detail-spec]]다. 사용자 식별자, 쿠폰 코드, 담당자 이름은 적지 않았다.

## what3words(w3w)와 최적지점

- **w3w 협의**(03-28): 입력 UX 조정(키보드에 마침표 아이콘 등)과 Autosuggest API 호출 타이밍. 영어는 축약형에서도 구두점을 쓰므로 **마지막 단어가 입력된 시점에 처리**하는 것이 좋다는 의견. 현재는 마지막 입력 전에도 호출해 축약 언어에서도 시도된다. `///` 입력 없이 w3w 추천어를 주는 방안은 검토 중
- **최적지점(최적 목적지) API**(05-31): 티머니 Onda에 제공 중인 "최적지점 검색"의 엔진 프로토콜과 외부 API를 에어에 적용하는 안. 결정된 내용: Agent는 **w3w 검색 결과에 최적 목적지 좌표를 포함해 앱에 전달**하고, 앱이 "최적지점검색" API를 호출할 수 있게 Agent 인터페이스를 추가. 앱 길찾기에서는 방안 1(첫 최적 목적지 좌표 사용) 대 방안 2(좌표 배열을 **다중 입구점**으로 사용)가 후보였고, 공유하기 시 어떤 좌표를 쓸지는 결정이 필요했다. ([[inavi-routing-neon-protocol]]의 다중 입구점 탐색과 연결) ^[inferred]
- 에어 앱의 w3w 기능은 2026-04 앱에서 제거됐다. ([[inavi-air-feature-history]])

## 캐시 적립·광고·쿠폰

| 주제 | 내용 |
|---|---|
| 아바티 캐시버튼 | 사업 제휴 제안(05-11). 아바티 개발팀 확인: **`UserID`가 바뀔 수 있어 정확한 회원 확인이 어려워 채널링 서비스 적용이 어렵다.** 대안은 현재의 기본 캐시버튼에서 **사용처를 제거할 수 있는 신규 SDK**. 아이나비 쪽 판단: 기존 소스를 유지하고 업체가 신규 SDK를 배포하면 안정성과 공수 면에서 유리. `app-ads.txt` 업데이트 요청(09-15)도 있었음 |
| 오퍼월 어뷰징 점검 | 핀크럭스 요청(07-04): 무료 충전소(오퍼월) 의심 유저 확인. **패턴**: 약관 동의 → 오퍼월 참여 → 쿠폰 구매(스타벅스) → 탈회가 **수 분 안에 연속**되고, 사용자 정보 `update` 시각이 가입 직후라서 실사용자로 보기 어렵다. 일부는 동일 snsId 중복(응답 코드 11). 에어 캐시 정합성 실패 코드 `970`("어뷰징 의심")과 같은 맥락 ([[inavi-air-api-overview]]) |
| 주행 중 광고 PoC | 멜로펀치 CM 광고 테스트(07-11). A타입은 미개발이라 **개발 완료된 "주행 중 광고"** 로 PoC. 발화 조건: 도착 안내 후 2초, 정차(속도 0이 5초 이상), 직진(차기 5km 이상), 정체(20km/h 이하로 60초 이상). **기본값이 Off**라 성과가 걱정됨. 15초 소재 3종 제작, 테스트폰에 온에어 기능을 켜서 전달 |
| SKP 구글 광고 | 에어 앱 내 **외국어 광고** 노출 문의(07-21): 지역 선택 기능이 없고, SKP가 "지역 타겟팅으로 한국만 지정 가능"하다고 안내 |
| 모바일 교환권 | 12-20 SKP 1500C 교환권 3만 개 발급, 테스트용 추가 코드 제공, **500C 발행 중 착오로 5만 개가 발행되어 20만 개 재발행**하고 첫 문서는 폐기. 에어 이벤트 API 규격서에 "모바일 교환권 캐시 적립 API" 추가(`/event/cash/voucherExchange`, [[inavi-air-api-detail-spec]]). 코드 목록 자체는 위키에 두지 않았다. |
| 쿠폰 재전송 | 전화번호 마지막 자리가 보이지 않고 번호 변경이 안 된다는 대표전화 문의(08-11) |

## 앱 운영 이슈

- **배너**(08-01~09): 표출 순서는 기획상 실행 시 **랜덤**. iOS는 랜덤, AOS는 **고정 순서**여서 AOS를 수정. AOS에서 **"일주일간 보지 않기"** 가 안 보이는 문제도 문의
- **10월 패치**: Push와 하단 팝업(배너) 신규 기능(외부 브라우저 연동, 상세 공지/이벤트 연동). 두 항목은 앱 패치로 가능하지만 **Push → 상세 공지/이벤트 페이지 연동은 Admin 수정이 필요**. Admin 개발은 다음 주 진입, 금요일까지 완료
- **iOS 단축어** 지원 문의(고객 만족, 11-10)

## 에어 CAM(제보하기) 처리 기준

고객센터가 제보 이관 처리 중 **완료되지 못하고 삭제도 안 되는 누적 건**(No. 1~6)을 건의했다. 답변과 결정: 같은 사용자의 중복 제보는 현재 "확인불가"로 처리하고(기확인도 캐시가 지급되기 때문), 이후 **"중복" 버튼**을 추가한다. 중복 처리는 **같은 사용자의 제보에 한정**하며 **캐시 미지급, Push 없음**. 예) 유효 제보 3건 중복: 확인 + 중복 + 중복, 확인불가 3건 중복: 확인불가 + 중복 + 중복. (예전 방식: 같은 내용이 2회 이상 오면 포털과 에어 검색으로 확인한 뒤 1회만 반영 요청)

## 기타 제휴

- **인천국제공항 주차 내비게이션**(07-14): 주차 관제 업체(watchmile) API를 Agent로 연계하는 검토. 전체 주차장 목록을 받아 키로 특정 주차장을 조회하는 형태라, **사용자 좌표를 넘기면 가장 가까운 주차장 데이터를 주도록** API를 바꾸는 것이 좋다고 의견. 롯데백화점 관련 SDK(베스텔라랩)는 APK 용량 증가와 서비스 영향 검토가 필요했다.
