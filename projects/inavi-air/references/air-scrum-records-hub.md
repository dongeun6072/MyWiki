# 에어 스크럼 기록 허브 (2023~2026)

에어팀 Confluence 스페이스의 주제별 스크럼 회의록과 관련 기록을 압축 없이 옮긴 상세 문서의 목차다. 스크럼은 모두 Agenda / Done & Doing / ToDo / Issues / Request 템플릿이고, 참석자 이름은 쓰지 않았다. 요약본은 [[air-confluence-scrum-and-voice-2023-2024]], 프로젝트 허브는 [[inavi-air]]다.

## 이 묶음에 없는 스크럼 주제 (다른 묶음/원본 미포함)
캐시 적립 스크럼, 내장소 개선/에어 사용자 분석, 제보하기/에어 연구소 리뉴얼, 서비스 안정화(23년 12월), HUD(로드피아) 연동 스크럼, 포인트홈(뉴캐시버튼) 스크럼은 이 묶음 목록에 포함되지 않았다. ^[inferred]

## 이 묶음에서 의도적으로 뺀 항목
- 참석자 멘션 목록(이름): "참석 N명" 정도만 기재
- 음성 담당 성우 이름, 외부 링크(Notion, 스토어, Jira): 미수록
