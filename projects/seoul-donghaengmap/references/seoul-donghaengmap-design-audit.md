# 설계단계 감리수행결과보고서 (2026-10)

㈜티머니가 계약(2026-08-07)한 감리법인이 아로정보기술 컨소시엄의 **설계단계**를 점검한 보고서다(v0.90, 2026-10-xx 제출 예정본). 관리번호와 감리원 이름은 옮기지 않았다. 감리 영역은 사업관리·품질보증, 응용시스템, 데이터베이스, 시스템 구조·보안이고, 붙임은 정보시스템 구축·운영 지침 기술적용계획표 점검과 감리계획서다. 같은 폴더에 v0.84도 있다. 프로젝트는 [[seoul-donghaengmap]]이다.

## 종합 총평

- 사업은 분석·설계를 통합 수행 후 **1단계(2026.07~2027.01)** 개발과 시범 서비스, **2단계(2027.01~06)** 구현·검증으로 계획되어 있다.
- **전체 공정 13.72%, 공정준수율 100% 보고**(2026-10-02 주간보고 기준)이나 모든 공정의 실적이 계획과 같게 기재되어 실제 진척 파악이 어렵다. ([[seoul-donghaengmap-wbs]])
- 일정에 영향을 주는 미해결 이슈: **데이터센터 입주, 하드웨어 가격 급등, 티머니GO 마일리지 연동** → 조속히 전체 일정 재수립 필요

## 영역별 권고 (모두 "필수")

| 영역 | 주요 지적 | 시점 |
|---|---|---|
| 사업관리·품질보증 | ① 주간·월간 진척률이 계획과 동일, 보고서끼리 마일스톤이 다름 ② WBS에 관리자 페이지, 외부 연계, 품질보증·감리, 성능·보안·인수 테스트 누락 ③ 교육훈련 내역서 미작성, 사용자·운영자 교육 일정 미확정 ④ 요구사항 **138건** 관리는 일관되나 추적 매트릭스의 설계 추적 누락과 검사기준서 미작성 ⑤ **변경관리대장과 변경요청/승인서 미작성**(대가 지급 조건 변경, 요구사항 삭제 10건·부분변경 5건, 특별제안 2건 삭제, WBS 전면 수정이 회의록만 근거) ⑥ 회의록 후속조치(Action Item) 추적 불가 ⑦ **위험관리대장과 이슈관리대장 미작성**(데이터센터, H/W 가격, 실내지도 범위·예산, 측위 정확도, BMS 3기 연계, 티머니GO 연계, 자문단 미구성) ⑧ 품질보증 결과물 미제출(품질 목표: 요구사항 반영률 99% 이상, 결함률 2% 이하, 시정조치율 100%) | 단기 |
| 응용시스템: 대중교통·버스 | 부분수용·미수용 요구사항의 변경·삭제 사유와 협의 범위 불명확, 요구사항 ID가 설계 산출물에 미반영, 핵심 기능 설계 매핑 누락 | 단기 |
| 응용시스템: 앱·실내 내비 | 일부 산출물 매핑 누락. 적용 대상 산출물 11종 중 8건 제출(업무흐름도, 테스트계획서 누락). 단위시험 시나리오 필요. **실내 내비 인터페이스 설계서 현행화** | 단기 |
| 응용시스템: 실외 내비 | 요구사항 13건 중 1건 변경수용. 화면 ID·단위테스트 ID 오기·누락. **길 안내 화면의 자문단 사전 검토** 필요. SDK 오류를 호출 프로그램에 전달하는 기본 구조 설계 필요 | 단기 |
| AI 음성 안내 | AI 모델·솔루션의 검토·설계·검증·**오픈소스 라이선스** 산출물과 수행계획 미흡, 적용 모델 상세 버전 불명확 | **장기** |
| 데이터베이스 | 요구사항 반영은 적정하나 컬럼 반복으로 **1NF 위배**(감리 중 조치), 시설 구분 부재, FK 미선언, 여부 코드 Y/N 외 값 사용, 공통코드 중복과 길이 오류, 언어코드에 국가코드 사용 | 단기 |
| 시스템 아키텍처 | 미수용 요구 근거 보완, AI 추론·학습 서버 구성이 RFP와 일부 불일치, **상암 데이터센터 입주와 운영환경 구성 방안 미확정**(1단계 시범 일정 영향), 시스템·성능 테스트가 WBS에 없고 테스트 계획서 미작성 | 단기 |

중요도가 높은 항목과 발주기관 협조가 필요한 항목은 데이터센터 입주와 일정 재수립이다.

## 데이터 표준 점검

컬럼정의서 312컬럼(24테이블, 역 정보는 API 수신이라 제외)을 공통 표준 → 기관 표준사전 순서로 비교했다. 1차 공통 표준 137개(43.9%) 준수, 공통 표준에 없는 175개는 2차 기관 표준사전에서 확인되어 **표준 용어 100% 준수**로 판정됐다. ([[seoul-donghaengmap-backend-env]])

## 산출물 제출 현황 (v0.84 본문 기준)

- **개발 산출물**: 설계단계까지 41종 중 미적용 3종을 제외한 38종 가운데 29종이 제출(대체 산출물 포함), 2종은 미도래, **7종 미제출**(인터뷰 결과서, 업무흐름도, 품질활동계획서, 테스트 계획서, 부적합 관리대장, 시정조치 보고서, 동료검토 결과서). 용어정의서(정제)는 "표준사전정의서"라는 다른 이름으로 제출돼 목록과 불일치.
- **관리 산출물**: 36종 중 제출 13, **미작성 12**, 미도래 11. 액션아이템 관리대장, 이슈·위험, 품질검토, 교육훈련, 변경관리, 형상관리 산출물이 없고 월간 인력투입현황도 빠졌다.
- **품질보증**: 분석단계 종료(2026-09-11)와 설계 완료 시점의 품질 활동 근거가 제출되지 않았다.
- 회의록에 결정사항과 후속조치(담당자·기한)가 없어 BMS 연계 시험 일정 공유, 데이터센터 요구사항 수령 같은 후속 이행을 추적할 수 없다. 특별제안 2건(현행 GTFS 경로 데이터 수정, 자문단 활용)이 기술협상에서 삭제됐고 **교통약자 자문단이 미구성**(서울시가 구성 중)이라 길 안내 화면의 자문단 사전 검토가 지연 요인이다. 관련 화면 사양은 [[seoul-donghaengmap-screen-design]]과 [[seoul-donghaengmap-screen-design-revisions]]에서 볼 수 있다.
- 데이터센터는 소유권 이전 후 입주만 허용하고 요구사항 자료를 공유하지 않아 운영환경 구성과 1단계 오픈이 지연될 수 있다는 점이 위험 항목으로 적혀 있다.

## 해석

감리 지적은 두 갈래로 나뉜다. **관리 산출물의 부재**(변경·위험·이슈·검사기준 대장 등)는 문서만 보완하면 되지만, **외부 의존 이슈**(데이터센터, GPU 가격, 티머니GO, BMS 3기)는 일정 자체를 흔든다. 두 번째가 [[seoul-donghaengmap-rfp]]의 외부 시스템 연계 구조에서 나온 것이다. ^[inferred]

## Open Questions

- v0.84(작성 기준 2026-10-02 주간보고)와 v0.90은 종합의견·권고 구조가 같다. v0.84를 읽어 확인한 주요 수치(아래 "산출물 제출 현황")는 v0.90 요약과 일치하며, 문구 단위 차이는 비교하지 않았다.
- 상세 점검 결과와 붙임(기술적용계획표, 감리계획서)은 분량이 커서 요약하지 않았다.
