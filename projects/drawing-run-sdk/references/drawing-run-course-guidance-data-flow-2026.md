# 드로잉런 코스 등록 안내데이터 생성과 주행 전체 플로우 (2026-06-11)

2차 개발의 중심 설계 문서다. 어드민에서 GPX 코스를 등록해 **코스 따라가기 주행**이 일어나기까지의 흐름을 삼성생명과 아이나비의 역할로 나눠 정리했다. API 호스트와 인증 정보는 이 문서에 없다(경로와 필드 명세도 아직 없음).

## 전체 플로우 (15단계)

| # | 흐름 | 주체 | 결과물 |
|---|---|---|---|
| 1 | 코스 정보와 GPX 등록 | 삼성생명 어드민 | 코스명, 설명, GPX 원본 |
| 2 | 기본 정보와 GPX 저장 | 삼성생명 서버 | 코스 ID, GPX 파일, 상태값 |
| 3 | 안내데이터 생성 요청 | 삼성생명 서버 → 아이나비 API | 아이나비 작업 ID |
| 4 | GPX 검증과 엔진 처리 | 아이나비 서버, 엔진 | 상태 "생성 중" |
| 5 | 안내데이터 생성 | 아이나비 엔진 | 코스 경로, 안내 지점, 거리 정보 |
| 6 | 처리 상태 확인 | 삼성생명 서버 → 아이나비 | 생성 중 / 완료 / 실패 |
| 7 | 생성 결과 조회 | 삼성생명 서버 → 아이나비 | SDK용 안내데이터 |
| 8 | 안내데이터 저장 | 삼성생명 서버 | 코스와 안내데이터 저장 완료 |
| 9 | 코스 노출 설정 | 삼성생명 어드민 | 앱 노출 여부 |
| 10 | 코스 목록·상세 조회 | 삼성생명 앱 | 목록, 상세 |
| 11 | 코스 시작 | 삼성생명 앱 | SDK에 넘길 코스 데이터 |
| 12 | SDK에 안내데이터 전달 | 앱 → SDK | 주행 세션 시작 |
| 13 | 코스 주행 처리 | 아이나비 SDK(단말 GPS) | 진행률, 이탈, 안내, 완주 판단 |
| 14 | 주행 이벤트 전달 | SDK → 앱(콜백/리스너) | 안내, 이탈, 복귀, 완주 이벤트 |
| 15 | 주행 화면 표출 | 삼성생명 앱 | 지도, 거리, 안내 문구, 완주 화면 |

## 필요한 API와 기능

**삼성생명 내부**: 코스 등록, 코스 수정(이름·설명·노출), 코스 상태 관리(생성 중·완료·실패), 코스 목록 조회, 코스 상세 조회, 안내데이터 조회(앱이 코스를 시작할 때 SDK용 데이터 제공).

**아이나비 제공 API**

| API | 시점 | 목적 |
|---|---|---|
| 안내데이터 생성 요청 | GPX 저장 후 | GPX로 생성 시작 |
| 처리 상태 조회 | 생성 상태 확인 | 완료/실패 |
| 결과 조회 | 생성 완료 후 | SDK가 읽을 안내데이터 전달 |
| 재생성 | GPX 수정 또는 실패 | 다시 생성 |
| 오류·실패 코드 | 실패 시 | 어드민에 실패 사유 표시 |

**아이나비 SDK 인터페이스**: 코스 주행 시작, 일시정지/재시작, 종료, 안내 이벤트(문구와 타입), 이탈·복귀 이벤트, 진행률 이벤트(남은 거리), 완주 이벤트, 오류 이벤트(GPS 또는 데이터 오류).

## 책임 구분

| 영역 | 삼성생명 | 아이나비 |
|---|---|---|
| 어드민 화면, GPX 원본 저장, 앱 코스 조회, 주행 화면 UI | 담당 | |
| 안내데이터 생성 요청 | 호출 | API 제공 |
| GPX 분석, 안내데이터 생성, SDK 주행 처리, SDK 이벤트 제공 | | 담당 |
| 안내데이터 저장 | 담당 | 결과 제공 |
| SDK 이벤트 | 수신과 표출 | 제공 |

## 상태 관리 권장 흐름

코스 등록 완료(어드민 저장) → 안내데이터 생성 중(생성 요청) → 안내데이터 생성 완료(처리 완료) → 검수 완료(운영자 확인) → 배포 완료(앱 노출).

## 해석

1차 SDK(기록 중심)와 달리 이 흐름은 **서버 API(안내데이터 생성)와 SDK(주행 판정)가 모두 아이나비 책임**이라 2차 개발이 사실상 서버 + SDK 개발이다. 단, 이 문서만으로는 지도·안내 엔진이 무엇인지 알 수 없다. ^[inferred]

정책 미정 항목(이탈 기준, 완주 기준, 생성 실패와 GPX 오류 처리)은 [[drawing-run-phase2-voice-guidance-and-meetings-2026]]에서 이어진다. 안내데이터는 외부 서비스 사례 [[plus-run-external-tech-review-2026]]의 "사전 등록 코스 안내" 방식과 같은 계열이다. ^[inferred]
