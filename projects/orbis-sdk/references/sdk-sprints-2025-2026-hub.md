# SDK 스프린트 상세 허브 (2025-06 ~ 2026-07)

Confluence "아이나비 에어 & NSDK" 스페이스에서 2025년 6월부터 2026년 7월까지 진행된 SDK 관련 스크럼 49페이지를 단계별로 상세 정리한 문서 묶음의 목차다. 요약본은 [[navisdk-confluence-sprint-timeline-2024-2026]]이고, 프로젝트 허브는 [[orbis-sdk]]이다. 문서 안의 담당 표기는 역할(앱 개발자 1~4)이며 4는 [[이동은]]이다. 런 SDK 관련 맥락은 [[drawing-run-sdk]], 트럭 경로는 [[vehicle-restriction-routing]]을 참고한다.

## 단계별 페이지 (시간순)
- [[dp-mmc-engine-maplibre-scrums-2025]] — 2025-06~09 DP엔진 & MMC 엔진 #1~#13(플래닝 포함), MapLibre 자체 구축, 안전운행, 도로명, TomTom 연동, Kdoc
- [[demo-exhibition-app-scrums-2025]] — 2025-09~10 DEMO/전시회 앱 기능 고도화 #1~#4, 교통정보, 멀티 경로, 전시회 항목
- [[navisdk-commercialization-scrums-2025-2026]] — 2025-10~2026-01 NaviSDK 상품화 #1~#11(일부), iOS, 야간 지도, 회전교차로, 로드맵
- [[map-sdk-commercialization-scrums-2026]] — 2026-01~03 Map SDK 상품화 #1~#6, 접두어, Style.json, 통계
- [[navi-sdk-truck-scrums-2026]] — 2026-03 Navi SDK Truck향 #1~#2, 에어 3월 패치
- [[navi-sdk-improvement-scrums-2026]] — 2026-03~04 Navi SDK 개선 #1~#4, 코드 개선, Flutter Step 1 시작
- [[sdk-maintenance-scrums-2026]] — 2026-04 및 07 SDK 유지보수(Flutter Step 2 준비, Orbis 신규 탐색엔진, 에어 방안 3)
- [[sdk-flutter-scrums-2026]] — 2026-05~06 SDK Flutter 대응 #1~#8, Flutter 일정 변화, 에어 패치
- [[sdk-scrum-common-items-2026]] — 로드맵, 접두어, Style.json, 통계, 미완 항목, 에어 패치 교차 정리
