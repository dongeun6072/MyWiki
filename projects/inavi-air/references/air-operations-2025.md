# 아이나비 에어 운영·제휴 메일 (2025)

[[air-operations-2024]]에서 이어지는 2025년 에어 메일이다. 지도·안내 기능 변경은 [[nav-service-features-2025]]에 따로 모았다. **로그인·인증·인증서·계정 관련 메일과 서버 주소, 고객 식별 정보는 옮기지 않았다.**

## 스토어 정책과 앱 호환

- **Google Play 정책 조치**: 01-14 사진·동영상 권한 정책 준수 안내, 02-21 정책 미준수 조치 요청, 07-02 **대상 API 수준** 요구사항 영향 알림이 왔다. 07-02 건은 스토어 API 레벨 확인을 요청하는 것으로 이어졌다.
- **Native 16KB 대응**(07-08): 64비트 기기는 **16KB 메모리 페이지**를 지원해야 한다는 Google 정책에 따라 광고 파트너 SDK 안의 네이티브 라이브러리가 4KB 정렬(2^12)인 것을 찾아 파트너에 일정을 물었다. 파트너가 이미 이 지원을 넣은 버전(포인트홈 Android, 광고 미디에이션 3.0.0.x대)을 배포한 상태라 업데이트하면 된다고 답했다.
- **파트너 SDK 크래시**(02-19): 미디에이션 라이브러리 2.1.0.22에서 특정 광고 매체(AppLovin) 크래시가 나서 해결판 **2.1.0.23**으로 올리기로 했다. 08-25에는 포인트홈 최신 버전 적용 요청이 있었다.
- **지도 서비스 이관**(06-19): NHN Cloud Maps 프로젝트 비활성화를 앞두고 확인했다. 에어는 **iMPS(자사 지도 SDK 0.20.0)**로 전환을 마쳤고, 해외향 커넥티드 서비스는 iMPS를 쓰지 않는다.
- 01-31 고속도로 목적지 사양 개선과 엔진 문의, 포인트홈 신규 기능(황금티켓) 적용 요청은 본문이 비어 있다.

## 제휴·서비스 연계

- **아이나비 스탬프 - 오르다**(03-31 론칭, 04-01 사내 안내): 스탬프 투어 여행 앱으로 스탬프 투어 운영 업체와 함께 만들었다. 04-04 콘텐츠사업팀이 에어와의 **상호 연계안**을 제안했다. 비즈그룹 의견은 ① 노출보다 **앱 투 앱** ② 여행지 검색부터 멀티모달 ③ 오르다로 넘어가는 버튼·배너 클릭 시 **에어캐시 적립을 프로모션 형태로** 검토, 순서는 '에어→오르다' 우선이다. 에어 PM 쪽은 ① 배너·공지 등 **지금 가능한 방법** ② 스탬프 장소 주변 목적지 설정 시 푸시 연계 ③ 앱 내 연계 기능 신규 추가(업데이트 시점)로 나누고, 구현 리소스가 들어가므로 **정량적 기대 효과**를 먼저 보자고 했다.
- **다울지오인포**(04-29): 외부 업체에 제공하는 경로탐색에 새 도엽 16개가 추가돼, 에어 개발 서버에 sMR 포함 데이터를 먼저 배포하고 QA가 시험일을 정하기로 했다.
- **국토지리정보원 항공사진**(03-21): 항공사진 서비스를 쓰려면 표기 요건이 필요한지 법무 검토를 요청했다. 지도 위 오버레이가 필요 없으면 에어는 환경설정 > 정보제공처 화면에 문구를 넣는 방식이 가능하다고 봤다.

## HUD

- **네비코리아 외부포팅 단말(AOS) HUD**(03-13): 하이브리드 PND 안드로이드 단말에 에어에 쓴 외주사 HUD 라이브러리와 연동 샘플을 가져가 **개발 공수**를 줄이려는 건이다. Galaxy S25 Ultra(Android 15, One UI 7.0)에서 블루투스 **연결 후 해제 반복**이 보고됐다. 2024년에 HUD 메시지 전송 주기는 200ms에서 **1초**로 바뀌었다.
- **이미지 전송**(05-08): 에어-HUD 이미지 전송 개발 자료를 업체가 보냈고, 자체 개발이 가능한 부분은 별도 외주가 필요 없다고 판단했다.
- 04-01 **허드 라이브러리 개발 계획서**도 전달됐다(상세는 첨부).

## 지도 데이터와 네트워크

- **2505a 도엽(MESH) 오류**(04-08, 통신형 지도 한정): 7월 지도 대상으로 신규 카페리 항로를 위해 도엽 16개를 넣은 도엽 인덱스를 5월 MR 생성에 그대로 써서 **모의주행 이슈**가 생겼다. 내부 탐색 검증은 정상이라 발행됐다. 조치는 입력 파일의 도엽 번호를 롤백하고 MR을 재전달하는 것이다.
- **CDN Origin 이관**(09-30 공지): 아이나비매니저로 지도·내비 콘텐츠를 받는 CDN의 Origin을 10-15에 **기존 업체에서 SKB로 이관**한다. 도메인은 그대로이고 DNS CNAME만 바뀐다. KGM 내비, PND, 하이브리드, 외부포팅 단말이 영향 대상이다. 각 부서는 10-02까지 다른 사용처를 회신하라는 요청이었다.
- **MMC 이슈**: 11-28 에어 맵매칭 이슈 메일이 있었다(본문 없음). 개발 측 원인은 [[orbis-navisdk-development-2025]]의 맵매칭 라이브러리 항목과 같은 계열로 보인다. ^[inferred]
- 06-04 **소프트웨어 현황 리스트 작성** 요청이 왔다(사내 취합).

## 통신형 단말·VoC

- **아이나비M VoC**(10-17, 11-12): 아이나비 모빌리티(택시 기사앱 쪽)의 요구로 DP 엔진에서 아파트 동·호수와 아파트명 POI 주기를 같이 표출하는 방안 → [[nav-service-features-2025]]
- 08-19 통신형 내비 **스마트 재탐색** 개선 요청, 11-06 소수점 단위 교통 속도 → [[nav-service-features-2025]]
