## 1. 전역 구조·제약

- **지도 기반 단일 화면 + 바텀시트**: 카카오맵 위에 상단 검색바 + 가로 스크롤 필터 칩, 좌·우 플로팅 버튼 열, 하단에 메뉴 바텀시트. 최하단 탭바 4개 = **홈 · 교통약자서비스 · 엄마아빠서비스 · 즐겨찾기**.
- **서비스 지역 = 서울 한정**: 서울 밖에서는 하단에 "**서울 외 지역에서는 서비스가 제공되지 않습니다**" 토스트(튜토리얼 홈 화면 판교 위치에서도 노출). 근처 정류장·역 목록이 비고, **경로 탐색도 출발·도착이 모두 서울 안일 때만** 결과가 나온다(서울 밖 출발지는 무결과).
- 데이터가 **서울시 공공데이터**라, 실기기 위치(판교)에서는 근처 목록이 비어 검색으로 서울 지점을 지정해야 정보가 표출됐다.

### 좌측 플로팅 버튼 열
- **[구 이름] 버튼**(실측 시 "광진구" — 구 단위 특화 레이어): 경사로 설치 상점 · 장애인 복지시설 · 전기 휠체어 충전소 3종 토글. **데이터가 해당 구 한정**이라 타 지역 뷰에서는 마커 없음.

## 5. 길안내 (경로 탐색)

### 이용자 프로필 3종 (상단 탭, 전환 시 즉시 재탐색)
| 프로필 (앱 표기) | 안내 방식 |
|-----------------|----------|
| **노약자, 임산부**(에스컬레이터) | 지하철역 **에스컬레이터·엘리베이터**로 안내 |
| **휠체어, 유모차**(엘레베이터) | 지하철역 **엘리베이터**로 안내 + **보행불편 보도 우회** 안내 |
| **비장애인** | 일반 대중교통 안내 |

- 앱 표기는 프로필 탭에서 "**엘레베이터**", 필터 칩·시설 아이콘에서 "**엘리베이터**"로 화면마다 다르다.
- 우상단 **X**로 길안내 모드를 종료한다.

### 화면 구성 (실측)
- **출발지·도착지 입력**: 출발지는 현위치 자동 입력(지번 주소 역지오코딩, 실측 "경기 성남시 분당구 삼평동 678"). 각 필드에 **X**(개별 초기화), 우측에 **출발↔도착 스왑**과 **검색(돋보기)**.
- **정류장·역 상세의 `출발`·`도착` 버튼으로도 지정된다**(§6·§7). 실측 경로: 정류장 상세 → `출발` → 길안내 화면의 출발지가 그 정류장 주소로 채워짐.
  - 길안내 화면을 나갔다 다시 들어오면 **출발지는 현위치로 초기화**되고 도착지는 유지된다.
- **검색 화면**: 상단 칩 **최근검색어 / 집 / 회사 / 즐겨찾기**. 이력은 항목별 상대시각("3시간 전")과 개별 **X**(삭제), 우측 상단에 전체 X. 이력 아이콘이 종류를 구분한다 — **핀 = 확정된 장소**(예: "시청역 1호선"), **돋보기 = 입력한 검색어**(예: "시청역").
- **경로 결과는 후보 목록**이다(스크롤). 각 후보 = 총 소요 + `(도보 N분 소요)` + **구간 바** + 요약 타임라인(승차 정류장 · 노선 · 도착 예정 · 도착지).
  - 실측(시청역 1호선 → 홍제동 459-3, 노약자·임산부): ① **38분**(도보 17분) 도보 10분 / 708번 버스 16분 / 도보 7분 ② **41분**(도보 16분) 790파주번 버스 16분 ③ **41분**(도보 12분) 종로11 → 790파주 **환승**.
  - **노선 유형 배지 색**: 간선 파랑 · 지선 초록 · 마을 초록 · **기타 회색**(경기 버스 등 서울 유형 밖).
  - 도착 예정에 **혼잡도**가 함께 표기된다 — 실측 "4분8초후[1번째 전] **(여유)**".
- **후보 탭 → 경로 상세**: 상단 **X** + "**다른 경로 선택**". 아래 타임라인이 구간별로 펼쳐진다.
  - 출발 핀(지번 주소, 실측 "서울 중구 정동 5-8")
  - 도보 구간 "도보, 서울신문사까지 걷기 / 약 10분, 386m 이동"
  - 승차 "서울신문사 승차" + 노선 배지·번호·도착 예정·혼잡도
  - "**6개역 이동 (16분 소요)**" + **▼ 확장** → 중간 정류장 전체 목록(KT광화문지사·경복궁역1번출구·사직단.어린이도서관·독립문역.한성과학고·무악재역)
  - **승하차예약 버튼(보라색)** — 대중교통 구간마다 1개. §6 규칙 적용
  - 하차 "인왕산.홍제원아파트 하차" → 도보 구간 → 도착 핀
  - 지도에는 경로 폴리라인과 경유 정류장이 함께 그려진다.
- 도보 단일 경로면 대안 없음. 서울 밖 출발지는 경로 미생성(실측: 출발지가 판교면 결과 0건).

## 6. 버스정류장 정보 · 저상버스 승하차 예약

### 조회 (비회원 가능)
- **근처 정류장**: 헤더 "근처 버스정류장 정보 / **내 위치에서 반경 200m**". 반경 안에 없으면 "**결과가 없습니다.**"
- **검색**: 필드 안내문 "**정류장/역 이름을 검색해주세요**" — 전국 데이터, **현위치 기준 거리순**, 정류장명 + ID + 거리(km) 표기.
  - 검색은 **이름만** 대상이다. 정류장 ID를 그대로 넣으면(실측 `02135`) 결과 0건이다.
- **정류장 상세**(실측 `시청.서소문청사 02135`): 정류장명·ID / **저상버스만 표시 토글(기본 ON)** / **출발**·**도착** 버튼 / **실시간 버스정보**(조회 시각 `08/06 12:19` + 새로고침 아이콘).
  - 노선별로 **도착 예정 2건**을 보여준다 — "**곧 도착**", "**7분후 (2번째 전)**". 각 건에 **저상**(청록) / **일반**(회색) 배지.
  - 토글 OFF 시 일반 버스까지 나온다(실측: 706 간선·일반 / 709 간선·일반 / 7019 지선·저상). 토글은 **정류장을 새로 열면 다시 ON**으로 초기화된다.
- **노선 상세**: 노선 배지·번호 / "**현위치: [정류장명]**" / "**현재 N대 운행중**" / 실시간 버스정보(조회 시각 + 새로고침) / 정류장 타임라인.
  - 타임라인 위에 **실시간 차량**이 차량번호와 함께 얹힌다 — `서울74사9358(일반)`, `서울74사9329(저상)`. **저상 차량은 붉은 글씨**로 강조된다.
  - 정류장마다 **▼ 확장** 아이콘이 있다.

### 승차예약 (회원 전용)
- **버튼 위치**: 정류장 상세가 아니라 **노선 상세**의 타임라인에서, **"현위치"로 잡힌 그 정류장 행에만** `승차예약` 버튼(파란색)이 붙는다. 다른 정류장 행에는 없다.
  - 여기서 "현위치"는 GPS 위치가 아니라 **사용자가 검색해 들어온 정류장**을 뜻한다. 실기기가 판교에 있고 해당 정류장이 **21.6km** 떨어진 상태에서도 버튼이 노출됐다.
- **확정 규칙**(튜토리얼): "버스정류장 내에서 버스예약 버튼을 누르거나, 버스예약 버튼 누르고 **버스정류장 50M 이내 접근 시 승차예약**됩니다."
- **취소 가능 시점**: ① 버스정류장에 50M 접근하기 전 ② 승차하려는 저상버스가 전 정류장 도착하기 전.
- "**승차예약 후 30분 이내** 버스정류장 50M 이내 접근하지 않을 경우 **예약은 자동 취소**됩니다."
- 앱 안내 문구: "무분별한 예약은 대중교통 운영에 차질이 생깁니다."

### 하차예약 (튜토리얼 6p)
- 승차예약 완료 알림: "승차 예약이 완료되었습니다. 승차 정류장에서 기다려주세요."
- 노선 타임라인의 하차 정류장(예: 충정로역2호선 13137)에 **하차예약** 버튼(주황색).
- "승차 예약 후 하차 예약이 가능합니다. 하차 예약은 승차 예약과 같이 해주세요."
- **예약 메시지 발송 전이라면** 승·하차 예약 취소 가능(승차 정류장·차량번호 카드에 "예약취소").

### 예약 현황 위젯 (튜토리얼 7p)
- "**472번 예약중** / 현재 예약대기 상태 / 대기시간 **29:59**(카운트다운) / 예약취소". 승차지·하차지 표기.
- "예약 대기 상태에서는 **앱을 실행하셔야 메시지가 발송**돼요. 앱을 종료하거나 휴대폰 화면을 끄면 예약이 안 될 수 있어요."
- "예약 대기 중 앱 종료 후 다시 실행하면 예약 진행됩니다. 노선 정보 또는 메인 화면에서 예약 현황 확인·취소 가능."

### 예약 내역 (실측)
- 설정 > 저상버스 > **저상버스 예약 내역** → 빈 상태 문구 "**예약 내역이 없습니다.**" (헤더 좌측 "뒤로가기" 텍스트 버튼)

> **미확인 범위**: 승차예약·하차예약 버튼을 실제로 누르는 동작은 수행하지 않았다. 위 하차예약·예약 현황 위젯·완료 알림·취소 동선은 튜토리얼 5~7p 근거다.

## 7. 지하철역 정보

- **근처 역**: 내 위치 반경 **1.5km** 리스트. 검색 시 호선 배지 + 거리 + **지도 이동 아이콘 + 전화(역무원 연결) 아이콘**.
- **역 상세 시트**: 호선·역명 / **"교통약자 내부환승 가능"** 표시 / 편의시설 아이콘(엘리베이터·에스컬레이터·수유실·휠체어 충전 등) / **방면별 실시간 도착**(예: 광운대행 "시청 출발", 인천행 "시청 도착", "22번째 전역") / 출발·도착 지정 / **역무원 전화** 버튼.

## 8. 교통약자서비스 탭 (7메뉴)

1. **버스정보** — §6과 동일.
2. **장애인 콜택시 예약** — 홈과 동일 외부 연계(1588-4388 / SFMC 앱 / sisul.or.kr).
3. **장애인 복지콜 예약** — 홈과 동일 외부 연계(1600-4477 / KBUCALL 앱 / kbucall.org).
4. **지하철 도우미** — 근처 지하철역 **안전도우미 콜** 목록(역별 전화). 근처 역 없으면 빈 시트.
5. **휠체어 길안내** — 길안내의 **휠체어·유모차 프로필**로 바로 진입.
6. **청계천 이동약자 시설물** — 지도가 청계천 구간으로 이동, 시설물 마커(화장실·계단·경사로·장애인 시설). 마커 탭 → 상세: **시설물 종류 / 이동약자 이용가능여부(가능·불가능) / 관리주체(민간·공공) / 장애인화장실 유무 / 운영시간 / 세부위치 / 청계천 구간(시점부 등) / 유수방향 기준 위치(우안·좌안)** + 출발/도착. (실측 예: "[화장실] 시그너스빌딩 — 이용가능여부 불가능·관리주체 민간·운영 07:00~19:00·중구 무교로28·시점부·우안".)
7. **이동약자 접근성 정보** — 서울시 소유 공공시설 접근성 정보안내도. "**접근 가능**"/"**접근 어려움**" 마커 → 탭 시 상세: 시설명 · **사진 캐러셀** · 주소 · 건축물 품질기준([건물이용정보] 출입구 이용 가능 등 / [기타시설정보] 기저귀교환대 등) + 기준 시점(예: "2021년 9월 기준"). (실측 예: "시청광장지하도상가(시티스타몰) — 태평로1가 31·출입구 이용 가능·기저귀교환대".)

## 9. 엄마아빠서비스 탭 (5메뉴)

1. **버스정보** — 공통.
2. **서울엄마아빠택시 타다(TADA) 예약** — 외부 연계.
3. **서울엄마아빠택시 파파(PAPA) 예약** — 외부 연계.
4. **지하철 내 수유실** — 수유실 운영 지하철역 목록(근처 역 기반). 근처 역 없으면 빈 시트.
5. **유모차 길안내** — 휠체어·유모차 프로필 길안내 진입(교통약자 탭 5번과 동일 기능, 라벨만 다름).

> 필터 칩도 탭별로 노출이 다르다 — 엄마아빠서비스 탭에서는 "역 내 수유실 · 장애인 이용 가능 화장실" 등 육아 관련 칩이 앞으로 온다.

## 10. 즐겨찾기 · 설정(햄버거)

- **즐겨찾기 탭**: **회원 전용**. 비회원 진입 시 로그인 다이얼로그.
- **로그인 상태 실측 구성**: 상단 칩 **집 · 회사 · 편집** + 우측 **닫기**, 아래 검색바 "장소를 검색해주세요", 목록 영역에 빈 상태 "**저장한 즐겨찾기 내역이 없습니다.**"
- **집·회사 칩 탭** → 하단 시트에 두 행(집 / 회사)이 뜨고 각 행에 "**주소를 등록하려면 클릭해주세요.**" + 연필 아이콘. 즉 집·회사는 **고정 2슬롯**이고 나머지는 일반 즐겨찾기다.
- 여기 등록한 값이 §3 검색 화면·§5 길안내 검색의 집/회사 바로가기와 **집으로** 버튼의 소스다.
- **설정 화면**: §3 햄버거 참고(로그인 상태 전체 실측).

## 11. 커뮤니티맵 통행 불편 신고

회원 전용. 설정 > 커뮤니티 맵 > **교통약자 통행 이용 불편 신고**(헤더 "커뮤니티 맵"). 아래는 로그인 상태 실측이며, 제출(신고하기)은 수행하지 않았다.

### 화면 구성 (실측)
- 안내문: "**교통약자 통행 이용 불편 및 공사 현황 등을 신고하여 이용자가 함께 만들어가는 교통약자 서비스 입니다.**" — 공사 현황도 신고 대상에 포함된다.
- **지도**: 현재 위치에 초록 핀 고정(스케일 20m). 핀을 옮길 수 없다 — 신고 위치는 "현재 나의 위치"로 고정된다.
- **주소 2줄**: `주소`(지번) + `도로명`을 함께 표시. 실측 "경기 성남시 분당구 삼평동 678" / "경기도 성남시 분당구 판교역로 240".
  - 서울 밖(판교)에서도 화면이 열리고 주소가 채워진다. 이 화면에서는 §1의 서울 외 지역 토스트가 뜨지 않는다.
- **신고 사항 (라디오 4종, 앱 문구 그대로)**:
  - 단차 (보도, 횡단보도 턱 등 **높이 2cm 이상**)
  - 경사 (급경사 및 **경사도가 1/8 이상** 지점)
  - 보도폭 (도보, 지작물 등으로 **보도폭 1.2m 이하**)
  - 기타
- **상세 내용 입력**: 라벨 "상세 내용 입력", placeholder "내용을 적어주세요. (예시: 보도폭이 좁아 휠체어 이용이 어렵습니다.)"
- **사진**: 카메라 아이콘 버튼 1개. 앨범 선택 경로가 없다(튜토리얼의 "카메라로 촬영한 사진만" 규칙과 일치).
- **신고하기** 버튼: 하단 고정. 초기엔 **비활성(회색)**, **라디오 1개만 고르면 활성(초록)**으로 바뀐다.
  - 활성 조건은 **라디오 선택 1건**뿐이다 — 사진·상세내용이 비어 있어도 활성된다(제출 시 서버 검증 여부는 미확인).

### 권한 (실측)
- 카메라 버튼 첫 탭 시 **카메라 권한 → 이어서 마이크(오디오 녹음) 권한**을 연달아 요청한다.
- 권한 거부 시 토스트가 영문으로 뜬다: "`Camera access permission was denied.`"

### 내역
- 설정 > 커뮤니티 맵 > **통행 이용 불편 신고 내역**(헤더 "신고 내역") → 빈 상태 "**신고내역이 없습니다.**"

> **미확인 범위**: `신고하기` 제출과 그 이후 화면(접수 결과·검토 상태 표기).
