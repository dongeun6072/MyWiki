# 이미지 HUD 검토: 티맵 HUD 사양과 에어 변경 필요 사양 (2025-04)

2025-04-30 수정된 검토 문서로, 티맵 HUD가 이미지로 안내 요소를 표출하는 방식과 에어의 현재 HUD(로드피아) 연동 사양을 항목별로 비교해 변경 필요 사항을 도출한다. 기존 연동 배경은 [[air-hud-integration-2023]], 정식 서비스는 [[air-hud-launch-stabilization-scrums-2024]], 목차는 [[air-scrum-records-hub]]다.

## 1. 티맵 HUD 사양 검토

| 항목 | 내용 |
|---|---|
| TBT | 데이터 전달 방식 / HUD에 전달된 이미지 표출 / 턴 정보 전체 표출 |
| 안전운행 | 데이터 전달 방식 / HUD에 전달된 전용 아이콘 이미지 표출 / 구간 등 전체 표출 가능 |
| 추천차로 | 데이터 전달 방식 / HUD에 bus 차로 등 전달된 이미지 및 데이터 표출 / 추천차로 전체 표출 가능 |
| 확대도 | 이미지 전달 방식(bitmap) / 이미지 사이즈 등은 확인 필요 |

## 2. 에어 현 사양 및 변경 필요 사양

### TBT
- 현 사양
  - 데이터 전달 방식: 아이나비 규격을 로드피아 HUD 규격으로 변경하여 통신
  - HUD에 표출 가능한 턴 코드로만 규격 정의
- 변경 및 전달 필요
  - 에어 전체 턴코드를 받을 수 있도록 규격 변경
  - 턴 이미지 전달
  - TBT 배경 이미지 전달

### 안전운행
- 현 사양
  - 데이터 전달 방식: 아이나비 규격을 로드피아 HUD 규격으로 변경하여 통신
  - HUD에 표출 가능한 안전운행 코드만 규격 정의
- 변경 및 전달 필요
  - 에어 전체 안전운행 종류를 받을 수 있도록 규격 변경
  - HUD 전용 아이콘 전달

### 추천차로
- 현 사양: 표출 사양 없음
- 변경 및 전달 필요
  - 신규 규격 정의
  - 버스 전용차로, 포켓 차로 등 이미지 전달
  - 배경 이미지 전달

### 확대도
- 현 사양: 표출 사양 없음
- 변경 및 전달 필요
  - 이미지 신규 전송 규격 필요
  - webp 지원 가능한지 확인 필요 — 지원 불가 시 이미지 타입 및 사이즈 확인 필요

### 기타
- GPS, BLE 연결 상태 등도 이미지로 처리되는 것으로 보여 이미지 전달 필요

## 3. 결론
1. 기존 BLE 통신 규격 변경 및 턴 타입 등 단말과의 규격 관련 추가 협의가 필요해 보인다.
2. HUD 전용 이미지가 필요할 것으로 보이며, 표출에 필요한 이미지 리스트 확정 및 단말과 협의가 필요하다.
3. 확대도 이미지 전송 로직이 필요하며 webp 지원 가능 여부를 확인해야 한다.
4. 티맵 HUD 기준으로는 특정 앱을 통해 티맵 데이터를 전달하는 방식으로 확인되며, 이 사양 때문에 Android에서만 지원하는 것으로 보인다. 차량 시동 시 HUD 자동 연결 등의 사양이 있으며, 동일 사양이 필요하면 내부 검토가 필요하다.

문서 끝에 "참조)" 항목이 있으나 내용은 이미지/링크 항목으로 비어 있다.

## 비교 요약표

| 항목 | 티맵(이미지 방식) | 에어 현재 | 필요한 변경 |
|---|---|---|---|
| TBT | 이미지 표출, 전체 턴 | 로드피아 규격 변환, 표출 가능 턴 코드만 | 전체 턴코드 규격, 턴·배경 이미지 |
| 안전운행 | 전용 아이콘, 구간 등 전체 | 표출 가능 코드만 | 전체 코드 규격, 전용 아이콘 |
| 추천차로 | 이미지+데이터(bus 차로 등) | 없음 | 신규 규격, 차로·배경 이미지 |
| 확대도 | bitmap | 없음 | 신규 전송 규격, webp 확인 |
| GPS/BLE 상태 | 이미지 | 이미지 전달 필요 | 이미지 추가 |
